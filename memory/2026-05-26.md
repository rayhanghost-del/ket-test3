### 【问题案例1】搜索曝光排名下降：不是商品问题，而是数据架构断裂
**场景描述**：卖家商品已注册、评论已积累，但搜索曝光不出现，或曝光后点击率极低，季节性商品也无法产生销售。
**问题分析**：2026年Coupang算法不再单纯看评论数量或价格，而是评估「搜索→点击→停留→购买→复购」5步数据流是否连贯。许多卖家将初始数据、流量、评论分别独立运营，导致数据无法连接，算法已将该商品判定为低质量。
**解决方案**：
1. 以关键词为基础设计搜索流入路径，优化过滤搜索
2. 设计CTR结构，强化详情页停留时间
3. 构建购买流程，将评论与复购结构连接
4. 确保「搜索→点击→停留→购买→复购」5步数据流无断裂
**关键要点**：
- 单纯降价或堆评论已无效，必须有「能连接到购买的数据结构」
- 季节商品分初期/中期/后期运营，初期靠结构取胜而非广告
- 商品名需简洁：品牌名+核心关键词+特征+规格，避免关键词堆砌

### 【问题案例2】直权退款导致钱货两空：卖家如何应对Coupang「保障退款」政策
**场景描述**：卖家发现退货商品未被收回，但系统已自动退款给客户，导致钱货两空。这是Coupang「保障退款」政策导致——客户退货申请后60小时（营业日）内未完成退款，系统将自动退款。
**问题分析**：很多客户其实已改变主意不想退货，但未取消退货申请；或客户故意利用系统漏洞。Coupang使用安全号码保护客户隐私，退货问题发生时安全号码已过期，卖家无法直接联系客户。
**解决方案**：
1. 通过Coupang客服获取客户真实号码：拨打1600-9879 → 输入企业代码 → 1号（市场咨询）→ 2号（安全号码咨询）→ 1号（同意个人信息使用）→ 输入订单号 → 1号（收件人真实号码）
2. 直接与客户沟通，说服取消退货或单独退款、收回商品
3. 若客户不接电话也不退货：在订单/配送→退货管理→入库单号→注册回收运单，同时在咨询板请求「回收支持」
4. 若仍无法回收，Coupang会进行重新结算
**关键要点**：
- 必须在退款完成后尽快联系客服获取真实号码，延迟则无法联系
- 保留所有沟通记录和回收请求记录，作为后续申诉证据
- 对于高频退货品类（如服装、饰品），需将退货成本计入定价

### 【问题案例3】广告费白白燃烧：自动广告依赖导致ROAS仅80%
**场景描述**：某卖家每月投入300万韩元自动广告，但ROAS仅80%（即投入100万仅收回80万），持续亏损。
**问题分析**：自动广告会向无关关键词投放（如卖「皮鞋」却匹配到「运动鞋」），且无法直接设置排除关键词。AI自动添加的关键词可能与商品完全无关，导致大量无效点击。
**解决方案**：
1. 定期检查自动广告的「关键词报告」，找出点击多但转化率为0的关键词
2. 将无效关键词转为手动广告，并设置为「排除关键词」
3. 品牌关键词与一般关键词分离运营，品牌词可用较低竞价
4. 时间分段预算：下午6-9点集中150%预算，凌晨降至50%
5. 竞价按利润率设置：30%利润率商品，CPC控制在售价10%以下
**关键要点**：
- ROAS 100%以下关键词应立即排除，它们只在消耗广告费
- 同一关键词不要对多个商品同时投放，会导致自我竞价、成本上升
- 医疗/保健品类绝对避免使用「治疗」「功效」等词汇，否则可能面临3个月广告禁令

### 【问题案例4】2026年实际费用高达13-18%：卖家必须掌握的真实成本计算
**场景描述**：很多卖家以为Coupang销售手续费最高仅10.9%，但结算时发现金额远低于预期，实际负担达13-18%。
**问题分析**：2026年费用结构已变为三大组成部分：①类别基本销售手续费（4~10.9%）②支付手续费2.9%（2026年新增独立项目）③增值税10%（在①+②基础上计算）。此外还有物流费、保管费、月服务费等。例如1万韩元时尚商品：手续费1050韩元+支付费290韩元+增值税134韩元=总费用1474韩元（实际负担14.7%）。
**解决方案**：
1. 使用逆算定价法：目标利润率+所有费用率→倒推定价
2. 免运费设置需谨慎：免运费额外增加3.3%手续费
3. 月销售额超100万韩元需缴纳55,000韩元服务费，测试期可控制销量规避
4. 实时用Wing卖家中心计算预计费用后再入库
**关键要点**：
- 绝对不能只看名义手续费率定价，必须包含支付费和增值税计算
- 免运费不是必选项，低客单价商品免运费可能直接亏损
- 利润计算：售价-进货价-销售手续费-支付费-物流费-广告费=净利润
**原文链接**：https://oscsnm.com/coupang-seller-fee-2026/

### 【问题案例5】入库数量争议与CS视频证据：出入库管理不善导致损失惨重
**场景描述**：品牌B公司通过Coupang物流销售，明确发送100件商品，但Coupang物流中心入库记录显示98件，2件不知所踪。过去量少时忽略不计，但量大后损失累积严重。
**问题分析**：Coupang作为中介平台，在卖家与物流/消费者之间缺乏直接管控。入库数量差异、退货商品损坏或缺失、恶意退货等问题频繁发生，而卖家往往缺乏客观证据。
**解决方案**：
1. 在发货/包装环节引入视频记录系统，拍摄打包全过程
2. 发货时精确清点数量，保留书面/电子记录
3. 与物流公司交接时要求签字确认数量
4. 退货商品入库后立即检查状态，72小时内完成申诉
5. 将打包视频作为品牌信任资产：发送给客户时可降低取消率
**关键要点**：
- 入库数量差异必须从源头解决，不能靠「差不多」心态
- 视频证据不仅是纠纷防御工具，也可用于品牌营销（某品牌发送打包视频后咨询处理时间减少、客服人工成本降低20%）
- 高客单价商品务必逐一拍摄开箱/打包视频

### 【问题案例6】详情页优化后转化率提升30%：一个被忽视的免费增长杠杆
**场景描述**：某健康食品品牌通过优化详情页，4周内点击率上升26%，转化率提升15%；某化妆品品牌通过优化详情页和移动端适配，6个月销售额增长280%。
**问题分析**：Coupang上70%购物发生在移动端，但许多卖家仍用PC思维设计详情页——文字过多、图片横版、按钮过小、加载速度慢。此外，商品名堆砌关键词被AI判定为垃圾信息。
**解决方案**：
1. 商品名结构：品牌名+类别核心关键词+主要特征+规格/数量（控制在85字以内）
2. 首屏必须包含：成分信息、功效摘要、核心卖点
3. 添加客户FAQ 5个以上，预先消除购买疑虑
4. 移动端优化：竖版图片、文本缩短40%、按钮最小44px、加载速度2秒内
5. 设置20个标签（tags）作为免费流量来源：补充商品名未覆盖的搜索词
**关键要点**：
- 详情页是「销售员」，不是「说明书」——先讲客户问题，再讲产品解决
- 标签（tags）是Coupang给卖家的唯一免费广告位，20个必须填满且与商品相关
- 修改详情页太频繁（超过每周1次）会导致临时曝光不稳定
**原文链接**：https://oscsnm.com/coupang-detail-page-strategy/

### 【运营技巧】长尾关键词蓝海策略：新手如何避开大词红海
**适用场景**：新上架商品或评论数少于500的商品，无法与大企业/高评论商品在核心词上竞争时。
**具体操作**：
1. 在Coupang搜索框输入核心词，按空格查看自动补全词——这些是真正的需求词
2. 观察PC端和移动端的关联搜索词差异（90%用户在移动端购物）
3. 将商品名按「长尾关键词80%+核心词20%」比例组合
4. 占领10个竞争弱的长尾词，积累销量后，核心词排名会自然上升
5. 用Coupang搜索框的关联搜索词洞察客户真实购买意图
**效果预期**：长尾词搜索者购买意图明确，转化率可比大词高10倍以上；销量积累后AI会判定商品质量高，从而提升整体排名。
**注意事项**：
- 切勿在商品名中重复同一关键词，AI视为垃圾信息降权
- 标签必须与商品相关，无关标签带来高跳出率会反噬排名
- 不要只依赖搜索量工具，Coupang搜索框的自动补全才是最准的需求数据
