# 2026-05-13 日志

## Coupang 广告诊断日

今天集中分析了三个品类的广告报表，发现数据推翻了之前的部分判断。

### 1. 广告运营SOP分析（用户分享8张韩国大卖SOP截图）
- 核心结论：0评论不开广告、ROAS 500-700破冰、不要频繁开关、CTR高CVR低=详情页接不住——基本全对
- 用户反馈：风扇衣主图因模特+风扇配件被标记违规，但竞品也在用类似图，大概率是被举报/抽查

### 2. 风扇衣广告（5.5-5.13）— 表现最差
- **整体ROAS 256%**，3/4广告被标记"违反图片指南"
- 非搜索区域CTR 0.22%，搜索区域CTR 1.45%（6.6倍差距）
- 核心问题：无评论导致系统降权分配到劣质流量
- **否定词已加**：작업조끼, 배달조끼, 낚시조끼, 에어조끼, 팬 재킷
- **行动**：关闭受众通加、修复图片、尽快弄到10条评论

### 3. 吸尘器广告（4.25-5.13）— 中等
- **整体ROAS ~4.5**，非搜索区域ROAS 5.63（主力盈利），搜索区域ROAS 2.67（烧钱）
- 搜索区域问题：关键词太泛+竞品词乱烧
- **否定词建议**：소형 무선청소기, 가정용 미니청소기, vacuum cleaner wireless, C핀 무선청소기, 초강력 유선청소기 + 竞品品牌词
- **金矿词**：먼지흡입기(ROAS 29.4), 핸디형 청소기(26.29), 청소기(21.14)

### 4. 露营椅广告（5.6-5.13）— **明星产品**
- **整体ROAS ~7.5**，非搜7.18，搜索8.76
- **关键发现：遮阳相关词是最高转化驱动力**
  - 경량 접이식 캠핑의자 햇빛가리게 → ROAS 84.62
  - 캠핑의자선쉘터리클라이너 → ROAS 209.77
  - 캠핑체어 → ROAS 73.49
- **重要修正**：之前建议删除标题中的"그늈막"是错误判断。数据证明搜遮阳相关词的用户转化率是普通词的5-10倍。
- 用户已修改标题加入그늈막：선쉘터 그늈막 캠핑의자 부착 접이식 휴대용 캠핑체어 야외 낚시용
- **否定词建议**：네이쳐하이크 캠핑의자, 헬리녹스 네이버후드 체어, Teenyyou..., 버팔로..., 캠핑 흔들의자, 바다낚시의자, 갯바위의자
