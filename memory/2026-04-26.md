## Coupang广告数据讨论

### 用户质疑数据来源
- 用户问我的广告合格线数据（CTR 1.5%、ROAS 3.0等）是否来自Coupang官方
- 我坦诚回答：不是官方数据，来源是跨境电商通用经验、韩国卖家社区讨论、代运营公司分享
- Coupang官方没有披露过明确的CTR/CVR合格标准
- 更靠谱的标准是"自己账户内部对比"——同产品不同时间段、同类产品横向比、加预算前后变化
- 用户接受了我的坦诚，没有进一步质疑

#### 数据2：按天+关键词报告（2026/4/15-4/22）
关键趋势：
- 4/15-4/17：CTR极低（0-0.11%），零转化
- 4/18：CTR跳到0.58%（展示7,612，点击44），但仍零转化
- 4/19：展示9,501，点击46，CTR 0.48%，14天销量4，CVR 8.70%，ROAS 24.22 ⭐ 黄金日
- 4/20：展示24,875，点击119，CTR 0.48%，14天销量5，CVR 4.20%，ROAS 12.41 ⭐ 黄金日
- 4/21：展示24,341，点击100，CTR 0.41%，零转化 ❌ 断崖
- 4/22：展示暴涨到77,752，点击154，但CTR暴跌到0.20%，14天销量仅1，ROAS 1.98 ❌ 恶化

#### 核心发现
1. 4/19-4/20是风扇衣的黄金窗口，但只持续两天，之后断崖式下跌
2. 4/22展示暴涨3倍但CTR暴跌，说明自动广告匹配到了大量不相关展示位置
3. 搜索区域总共只有90个展示、10个点击，CTR 11.11%但零转化——搜索需求存在但几乎没抢到
4. 风扇衣的转化率（2-2.56%）其实比露营椅（1.52-2.03%）还好，问题只是CTR太低

#### 给出的建议
1. 立刻检查4/22展示暴涨原因——去Coupang后台看是否自动匹配到新的大流量位置
2. 降低4/22这种低效曝光预算——CTR 0.2%的位置在亏钱
3. 单独给风扇衣开个搜索广告——搜索CTR 11%，比非搜索高30倍，但展示量只有90
4. 回头看4/19-4/20做了什么对的——是否有促销、主图调整、关键词匹配变化？复现那个条件
5. 暂时不要加预算——先稳定CTR在0.4%以上再说

#### 用户提到的"之前只有4个转化，现在新开了广告"
- 从数据看，4/19-4/22累计14天归因有10个转化
- "4个"可能是单日数据或1天归因数据
- 风扇衣的转化窗口确实很短，4/22已经在恶化

### 方法论反思
- 当用户问数据来源时，必须第一时间诚实说明，不要含糊
- "行业benchmark"在没有官方数据源的情况下，价值有限
- 基于用户自己的账户数据做"内部对比"分析，比套用外部标准更有说服力
- CTR/CVR的绝对值意义不大，趋势变化和相对对比才是关键
