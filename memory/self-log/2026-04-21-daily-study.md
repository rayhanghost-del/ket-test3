### 【问题案例1】卖家责任退货的完整处理流程
**场景描述**：新手卖家收到"卖家责任"退货通知，原因是商品尺码标注模糊导致客户误购，需要承担退货运费，不知所措。
**问题分析**：
- 商品详情页尺码标注不清晰（"女性M/L，男性XL"这种模糊表达）
- 客户基于错误理解下单，实际收到商品后发现尺码不符
- 卖家分不清这是"单纯变心"还是真正的"卖家责任"
**解决方案**：
1. 判断责任归属：商品描述存在歧义 → 属于卖家责任
2. 在Coupang卖家后台确认退货商品信息
3. 向供应商（如도매매）申请退货，退货原因选择"商品与描述不符"
4. 获取供应商的退货运单号，在Coupang退货管理中登记
5. 供应商安排快递上门取件，卖家等待退款
6. 同步修改商品详情页，添加实测尺码图，避免再次发生
**关键要点**：
- 描述模糊时优先承认卖家责任，避免客户纠纷升级
- 向供应商申请退货时，写明"商品自身尺码标注问题"比"卖家误标"更容易获批
- 处理完必须立即修改详情页，这是防止复发的核心动作

### 【问题案例2】卖家评分突然归零的恢复方法
**场景描述**：一直维持100分满分的卖家评分，某天发现配送评分突然变为0分，实际已按时发货，但物流延迟导致。
**问题分析**：
- Coupang系统自动将物流延迟计入卖家评分
- 即使卖家按时发货，快递公司延迟也影响卖家评分
- 这种评分机制导致大量不必要的申诉流程
**解决方案**：
1. 登录Coupang卖家后台，找到相关订单记录
2. 截取自己按时发货的凭证（发货时间截图）
3. 通过专门链接提交评分排除申请：https://helpseller.coupang.com/hc/ko/requests/new?ticket_form_id=360000545712
4. 填写订单号、箱号ID，附上发货时间截图
5. 等待处理结果（通常1-3天内回复）
**关键要点**：
- 申诉前务必保存发货凭证，这是唯一有效证据
- 这种申诉本应由系统自动识别，但Coupang目前没有这种功能，必须手动申诉
- 每月定期检查评分变动，发现问题立即申诉

### 【问题案例3】曝光商品ID不一致导致销量下滑
**场景描述**：同一商品的多个选项被分配到了不同的曝光商品ID页面，客户无法在同一页面选择所有选项，严重影响销量。
**问题分析**：
- Coupang系统自动合并/分离商品ID时出错
- 同一商品的5个选项被分到2个不同页面
- 更严重的是，自己的选项可能被合并到别的卖家商品页面
**解决方案**：
1. 在Coupang WING > 商品管理 > 商品查询/修改 中检查各选项的"曝光商品ID"
2. 发现ID不一致时，准备"等同一商品"合并申请
3. 通过在线客服提交申请：商品管理 → 商品修改请求 → "等同一商品，请合并为一个商品ID"
4. 填写销售者代码（右上角名字点击可见）
5. 使用Excel批量合并功能处理大量商品
6. 处理时间最长8个工作日
**关键要点**：
- 这是Coupang系统bug导致的问题，不是卖家操作失误
- 需要卖家主动发现并申请修复，系统不会自动修正
- 定期检查新品上架后的ID分配情况，越早发现越好处理

### 【问题案例4】客户纠纷导致销售暂停的紧急恢复
**场景描述**：因与一位客户的争执，Coupang突然发出销售暂停通知，所有商品停止曝光，收入瞬间归零。
**问题分析**：
- 客户与卖家的纠纷升级，Coupang为保护消费者权益暂停卖家销售
- 即使纠纷很小，一旦触发系统规则就会立即执行
- 暂停期间所有商品搜索排名会大幅下降，恢复后需要1周以上才能恢复
**解决方案**：
1. 立即停止与客户的对抗，转为全力配合态度
2. 准备两份文件：
   - Coupang承诺书：承诺不再与客户发生争执
   - 态度改善计划书：具体说明如何改进客服系统和应对流程
3. 通过邮件发送给Coupang负责人
4. 同步在Coupang客服热线说明已发送文件，请求加快处理
5. 联系涉事客户，无条件满足其要求，尽快结案
6. 等待销售恢复（案例中2天内恢复）
**关键要点**：
- 与Coupang和客户的沟通都要以"快速结束事态"为唯一目标
- 恢复销售后至少1周内每天检查搜索排名，记录恢复进度
- 建立客服应对手册，设定赔偿权限上限，避免情绪化决策

### 【问题案例5】2025年Rocket Growth费用改革后的应对
**场景描述**：2025年1月起Coupang Rocket Growth物流费用全面改革，原有3档尺寸变为6档，免费保管期从60天缩短到30天，导致成本大幅上升。
**问题分析**：
- 入出库/配送费用：3档→6档细分化，大尺寸商品费用暴涨
- 保管费：一般品类30天免费（原为60天），服饰/鞋类45天
- 新增费用：退货回收费、再入库费、反出库费（每月各20件免费）
- 物流费用平均上涨20-30%，大件商品甚至50%以上
**解决方案**：
1. 重新计算每个SKU的物流成本，按6档尺寸分类
2. 优先销售40cm以下的小件商品（长+宽+高），物流费最低
3. 设定30天内售罄的入货量，避免长期保管费
4. 对25天未售出的商品立即启动促销清理库存
5. 每月控制退货/反出库在20件以内，超出部分会产生额外费用
6. 大件商品考虑捆绑销售或附加服务提高客单价
**关键要点**：
- 改革后的费用体系对小件商品更有利，大件商品需要重新评估利润
- 30天库存周转是硬性要求，不是建议
- 所有费用优惠促销活动有效期至2026-2027年，注意时间节点
**原文链接**：[https://www.sellerking.io/blog/쿠팡-셀러-필독-로켓그로스-비용-개편](https://www.sellerking.io/blog/%EC%BF%A0%ED%8C%A1-%EC%85%80%EB%9F%AC-%ED%95%84%EB%8F%85-%EB%A1%9C%EC%BC%93%EA%B7%B8%EB%A1%9C%EC%8A%A4-%EB%B9%84%EC%9A%A9-%EC%B2%B4%EA%B3%84-%EA%B0%9C%ED%8E%B8-%EC%B4%9D%EC%A0%95%EB%A6%AC-35321)

### 【问题案例6】广告费浪费在无关关键词上
**场景描述**：使用Coupang自动广告后发现，AI匹配的关键词与商品完全无关（如卖"皮鞋"却匹配"运动鞋"），每月浪费大量广告费。
**问题分析**：
- Coupang自动广告AI会添加与商品无关的关键词
- 除手动广告外，所有自动广告都需要单独设置"排除关键词"
- 调查显示卖家平均浪费广告费最高可达1900万韩元
**解决方案**：
1. 定期（建议每2周1次）检查关键词报告
2. 找出CTR高但CVR低的关键词 → 考虑排除
3. 找出ROAS低于100%的关键词 → 立即排除
4. 排除竞争品牌关键词（如自己不是Dr.Jart产品，排除"Dr.Jart"）
5. 排除"免费、白送、价格比较"类意图关键词
6. 使用第三方工具（如세이비）批量分析并排除低效关键词
**关键要点**：
- 自动广告不是"设置后就不管"，必须定期维护
- 大流量关键词如果转化率低，排除它不会显著减少总流量
- ROAS 100%以下意味着广告费比销售额还高，必须立即处理
**原文链接**：[https://moneymastering.tistory.com/m/entry/쿠팡-광고-키워드-최적화](https://moneymastering.tistory.com/m/entry/%EC%BF%A0%ED%8C%A1-%EA%B4%91%EA%B3%A0-%ED%82%A4%EC%9B%8C%EB%93%9C-%EC%B5%9C%EC%A0%81%ED%99%94-ROAS-%EB%82%AE%EC%9D%80-%ED%82%A4%EC%9B%8C%EB%93%9C-%EC%A0%9C%EA%B1%B0-%EB%B0%A9%EB%B2%95)

### 【运营技巧】详情页快速优化3步法
**适用场景**：使用供应商提供的通用详情页，需要快速差异化提升转化率
**具体操作**：
1. **翻译成韩语**：将中文供应商详情页全部翻译为韩语，尤其是成分表、使用说明、注意事项。韩语详情页能大幅提升客户信任度。
2. **首图加钩子文案**：在详情页第一张图上添加1-2句简短有力的文案，如"连续30天销量第一"、"韩国消费者满意度98%"等，让客户产生继续下滑的兴趣。
3. **添加紧迫性理由**：在详情页中间或末尾，明确说明"谁需要这个商品"和"为什么现在就要买"。用具体场景替代笼统的"请购买"。
**效果预期**：仅做这3项修改，CTR可提升20-30%，转化率可提升15%以上
**注意事项**：
- 首图文案要短，不能超过2句话，否则移动端阅读困难
- 紧迫性不是"限时特价"这种套路，而是让客户感觉"这正是我现在需要的"
- 修改后观察1周数据，不要频繁改动

### 【运营技巧】30天库存零保管费周转法
**适用场景**：使用Coupang Rocket Growth仓储服务的卖家，希望将保管费降至零
**具体操作**：
1. 分析过去30天销售数据，计算日均销量
2. 入货量 = 日均销量 × 30天 × 1.2（20%安全库存）
3. 入货后第20天检查库存余量：
   - 如果剩余量 > 10天销量：立即启动限时折扣（10-15%）
   - 如果剩余量 < 5天销量：准备补货
4. 第25天：如果还有未售出库存，启动Coupang Deals特卖或Gold Box活动
5. 第28天：无论价格多低，全部清仓（避免30天后产生保管费）
**效果预期**：保管费从月均数万韩元降至接近零，库存周转率提升2倍以上
**注意事项**：
- 季节性商品需在季节结束前2周就开始清仓
- 每月初检查Coupang官方促销活动日历，提前报名
- 宁可低价清仓也不要交保管费，因为保管费是持续的

### 【运营技巧】CS响应速度提升与差评预防
**适用场景**：1人卖家或小型团队，每天花大量时间在客服上，且因响应慢导致差评
**具体操作**：
1. 建立20个最常见问题的FAQ模板（配送、退换货、尺寸、使用法等）
2. 将FAQ放在商品详情页顶部，让客户自助解决问题
3. 设置自动回复：收到咨询后5分钟内自动发送"已收到，正在确认，2小时内给您答复"
4. 对情绪激动的客户，优先用文字沟通（有记录可查），避免电话
5. 对持续骚扰的客户，向Coupang申请"销售妨碍客户"登记
6. 每月分析退货原因标签，反向优化详情页（如退货原因是"尺寸不符"就加尺码表）
**效果预期**：客服时间减少50%以上，差评率下降30%，卖家评分提升
**注意事项**：
- 自动回复不能替代真实回复，必须在承诺时间内给出实质答复
- 永远不要与客户争吵，即使客户完全错误
- 设置每月CS预算上限（销售额的1-5%），超出上限的不合理要求可以拒绝

- **核心洞察**：
