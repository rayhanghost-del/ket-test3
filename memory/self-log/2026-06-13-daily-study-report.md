## 一、韩国电商学习要点

**1. Coupang 运营核心数据**
- 实际手续费 = 名义(4~10.9%) + 结算手续费(2.9%) + 附加税(10%) + 物流费 + 免费配送费(3.3%) = **13~18%**
- 搜索曝光 **70% 由商品名决定**：品牌名 → 子关键词 → 主关键词 → 容量/构成
- 初期 **30 个评论是必选项**，超过后自然曝光急剧增加，广告依赖度降低

**2. 物流与仓储**
- 火箭成长(로켓그로스)免费保管期从60天缩短至 **30天**，超期后保管费几何级增长
- 退货回收再入库费新设，服装/化妆品卖家实际利润率从8%跌至3%
- 库存周转天数控制在28天以内是核心策略

**3. 认证与合规**
- KC认证：强制性安全认证周期4-6周，费用$3,000~$10,000+
- 2026年新增：充电桩、智能家电、无线充电设备等强制品目
- 中韩税收协定：股息/利息/特许权使用费预提税上限 **10%**（股息可低至5%）

**4. 入驻路径**
- 跨境店：中国大陆企业可入驻，佣金5-15%，无月租
- 本土店：需韩国公司主体，佣金更低(5-10%)，流量支持更多
- 三种清关模式：DAP（消费者自付）→ DDP（卖家预付）→ 本地履约（Rocket Growth）

**5. 客服与评分**
- CS应对速度直接影响卖家分数 → 搜索排名 → 销售额
- 24小时内回复为算法评估标准
- 退货预备费建议预留销售额的 **1~5%**

## 二、自媒体学习要点

**1. 平台算法核心（2026最新）**
- **抖音**：从「猜你喜欢」→「算你喜欢」，提前72小时预测需求，分发精准度提升40%
- **小红书**：CES评分=点赞×1 + 收藏×1 + 评论×4 + 转发×4 + 关注×8，评论权重最高
- **视频号**：社交裂变+私域联动，2026算法权重进一步向社交信号倾斜
- **YouTube**：从「观看时长至上」→「用户满意度优先」，Shorts与长视频算法分离

**2. 内容创作框架**
- **3秒定生死**：前3秒必须用反常识+悬念抓住注意力
- **黄金结构**：痛点强化(0-3秒) + 场景化解决方案 + 反向提问(引导评论)
- **三线交织**：故事线 + 知识线 + 互动线 → 完播率比普通文章高40%

**3. 变现模式阶梯**
| 模式 | 门槛 | 适合阶段 |
|------|------|---------|
| 平台广告分润 | 500-1000粉丝 | 起步期 |
| 品牌合作/业配 | 1万+粉丝 | 成长期 |
| 带货（电商） | 200有效粉丝 | 任何阶段 |
| 知识付费 | 需专业积累 | 成熟期 |
| 私域/会员订阅 | 需忠实粉丝 | 成熟期 |

**4. 跨平台飞轮（2026最强闭环）**
抖音种草 → 小红书搜索补强 → 视频号信任背书 + 私域转化

**5. 关键认知**
- 没有万能策略适用所有平台，必须针对性调整
- 2026年算法从「快爆」变「慢热」，急躁反而有害
- 内容质量是所有算法的最大公约数

## 三、今日学习总结与思考

**核心洞察**

1. **韩国电商的「隐藏成本」陷阱**：名义手续费4~10.9%只是冰山一角，实际综合成本13~18%+。定价时必须用逆算法：成本 + 所有手续费 + 广告费 + 30%以上利润 = 售价。低于30%利润率投广告=立即亏损。

2. **评论是电商的「冷启动燃料」**：30个评论是临界点，是自然曝光从0到1的开关。与其盲目加广告预算，不如先通过体验团/MN协作搞定30个评论，再谈规模化。

3. **自媒体算法进入「精准预测」时代**：抖音提前72小时预测、小红书向量检索精度提升——算法越来越聪明，投机取巧空间越来越小。老老实实做内容，反而成为最高ROI策略。
