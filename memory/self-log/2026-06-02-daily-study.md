### 【问题案例1】搜索不曝光：数据连接结构断裂
**场景描述**：某卖家商品已注册、评论已积累，但搜索不曝光、点击率不出、季节性商品也不出销售。经过分析发现这不是商品问题，而是数据连接结构断裂。
**问题分析**：
- 许多卖家将初期数据、流量、评论分别管理，数据未连接
- 2026年Coupang算法同时评估：搜索→点击→停留→购买→复购，任一环节断裂则曝光无法维持
- 商品名SEO、关键词部署、CTR结构未优化
**解决方案**：
1. 商品名采用「品牌名→子关键词2-3个→主关键词→容量/构成」结构，100字以内
2. 部署搜索→点击→停留→购买→复购的完整数据流
3. 关键词基于实际搜索词，使用Naver关键词工具和Coupang自动补全功能
4. 高转化率关键词适度溢价，无关关键词排除
**关键要点**：
- 2026年Coupang算法将「数据连接结构」作为核心评估标准
- 商品名中关键词顺序直接影响搜索排名
- 评论+复购连接是关键，而非单纯追求评论数量

### 【问题案例2】自动退款后商品未回收：Coupang「保障退款」政策陷阱
**场景描述**：某卖家发现退货未回收但已自动退款，原因是Coupang「保障退款」政策——客户退货申请后60小时（营业日）未完成退款，Coupang将无条件先行退款。客户拿到退款后商品未退回，卖家钱货两空。
**问题分析**：
- 保障退款是Coupang保护消费者的政策，但对卖家极为苛刻
- 很多客户其实没有退货意愿，只是忘记取消退货申请
- 安全号码在退货问题发生时已失效，无法直接联系客户
- 即使Coupang三次回收失败，自动结算也不总是自动执行，需要卖家主动申请
**解决方案**：
1. 通过Coupang客服中心（1600-9879）获取客户真实号码：
   - 업체코드 입력 → 1번(마켓플레이스 문의) → 2번(안심번호 문의) → 1번(개인정보 동의) → 주문번호 입력 → 1번(수취인 실번호) 또는 2번(주문자 실번호)
2. 直接联系客户协商退款或安排退货
3. 若客户不接电话也不退货：
   - 在「주문/배송→반품관리→입고 송장번호」中注册回收运单
   - 在咨询板申请回收支援，Coupang会联系客户确认回收
   - 若仍无法回收，Coupang将重新结算
4. 回收支援对象退货件，Coupang最终会重新结算
**关键要点**：
- 保障退款执行后，必须主动申请回收支援，不能等待自动处理
- 客户真实号码需要通过客服中心专门流程获取
- 保留发货照片、运单、通话记录等证据，用于后续争议

### 【问题案例3】AI广告关键词错乱：「皮鞋」匹配「运动鞋」
**场景描述**：某卖家使用Coupang AI自动广告（AI智能广告、销售优化广告），发现AI自动添加的关键词严重不匹配——卖「皮鞋」匹配到「运动鞋」，卖「衬衫」匹配到「圆领卫衣」。更糟的是，除了手动广告外，其他广告类型都需要单独设置关键词排除，导致大量广告费浪费。
**问题分析**：
- Coupang 2025年起AI自动关键词优化比重大幅扩大，但AI匹配准确率并不理想
- 卖家依赖AI自动添加关键词，没有定期审查和排除
- 据调查，卖家因AI错配关键词平均浪费广告费高达1,900万韩元
- 大关键词曝光多、点击多但转化率低，直接排除可惜，保留又拉低ROAS
**解决方案**：
1. 每周至少一次审查AI自动添加的关键词列表
2. 使用第三方工具（如세이비）进行「吞钱关键词」筛选和自动排除
3. 区分三类关键词：高转化词（溢价）、探索词（观察）、无效词（立即排除）
4. 广告开启后3-5天内必须完成首次关键词排除工作
5. 关键词排除后观察2周，若ROAS仍低于300%则重新调整
**关键要点**：
- AI自动广告≠无需管理，反而需要更频繁的人工干预
- 商品名优化是广告成功的70%，关键词优化是剩下的30%
- 2026年Coupang缩略图政策强化，白色背景+无logo/营销文案是强制要求

### 【问题案例4】Rocket Growth费用计算失误：卖家以为赚钱实则亏损
**场景描述**：某食品品牌卖家只看基础销售手续费（5.5-8%）定价，未将物流费、仓储费、退货费、附加服务费等全部计算在内，结果实际利润率几乎为零，差点导致经营失败。
**问题分析**：
- Rocket Growth费用不仅是销售手续费，还包括：入库/出库配送费、仓储费、退货回收/再入库费、附加服务费、免费配送服务费（3%）
- 2025年仓储免费期从60天缩短至30天，长期仓储费累积压力增大
- 退货费用新增：月免费额度（5件）超出后需支付退货回收+再入库费
- 入库被拒时反送费（2,000韩元+/件）由卖家承担
**解决方案**：
1. 完整计算成本结构：销售手续费（5.5-10.8%）+ 支付手续费（3.3%）+ 配送费（2,000-5,000韩元/件）+ 仓储费（30天后日25-50韩元/CBM）+ 退货费 + 广告费
2. 总费用占销售额约15-25%，定价时必须预留足够毛利空间
3. 高回转商品选择Rocket Growth，低回转/不确定商品先以普通配送测试
4. 设定内部回转率基准：月1次检查SKU退货率，超过3-5%优先检查
**关键要点**：
- 月销售额超过100万韩元（数码类500万）时另加月服务费55,000韩元
- 免费配送服务看似吸引客户，但配送费3%服务费也要计入成本
- 入库前务必确认：条码粘贴、包装规格、保质期70%以上、数量一致、标签信息正确

### 【问题案例5】客户响应分数下降：24小时回复率不达标影响搜索排名
**场景描述**：某卖家因一个人运营，客户咨询回复经常延迟，导致「卖家分数」下降，进而搜索排名下滑。Coupang将客户响应质量和速度直接纳入卖家评分体系，评分下降后即使商品本身不错，曝光也大幅减少。
**问题分析**：
- Coupang卖家分数包含：客户响应速度、客户不满率、退货率、评论管理
- 响应延迟不仅导致分数下降，还直接转化为低评分和负面评论
- 重复性问题（配送、退换货、使用方法）如果没有FAQ和模板，每次都要重复处理
- 客户响应不足会触发「自动退款/退货」偏向客户的不公平裁决
**解决方案**：
1. 建立FAQ自动回复系统：整理20个核心问题（配送、退换货、支付失败、优惠券使用等）
2. 使用标准响应模板，确保24小时内回复率95%以上
3. 电话优先用短信/公告板回复（便于记录管理），避免情绪化冲突
4. 对于持续骚扰的客户，向Coupang客服中心申请「销售妨碍客户」登记
5. 退货/换货处理SOP：
   - 每天检查「出停止请求/退货管理」
   - 出前立即取消，出后安排回收
   - 商品回收后检查状态，确认不良后处理退款或换货
**关键要点**：
- 负面评论必须24小时内回复，解决问题而非辩解
- 客户响应速度和质量直接影响搜索排名和购买转化率
- 卖家可删除的评论类型：辱骂、诽谤、虚假信息、无关内容、个人信息泄露

### 【问题案例6】「自费退款」新时代：部分品类无需回收即可退款
**场景描述**：从2025年12月起，Coupang在部分品类（特别是生鲜食品）引入「无回收退款」机制。客户申请退款后，Coupang不回收商品，客户直接获得退款。这导致部分恶意客户利用政策反复申请退款，而卖家承担全部损失。
**问题分析**：
- 生鲜食品不回收的原因是回收后也无法再销售，反而产生废弃处理费用
- 客户利用「无回收退款」政策，反复购买生鲜后申请退款，商品自行处理
- 2020年已有客户利用此政策获取800万韩元不当利益，被Coupang以「业务妨碍罪」起诉
- 对于其他品类，Coupang也在推进类似的「自费退款」机制
**解决方案**：
1. 对退货申请24小时内响应，拖延等于默认接受
2. 发货时保留包装照片、运单、商品状态视频，作为争议证据
3. 对恶意客户，向Coupang客服中心申请「客户行为审查」和黑名单登记
4. 退货率异常高的SKU（月3-5%以上），优先检查：广告文案、选项描述、包装状态
5. 对无理由退货，学会区分「可拒绝」和「不可拒绝」的情形，避免盲目拒绝导致纠纷升级
**关键要点**：
- 发货照片和视频是防止恶意退货的唯一有效证据
- 商品页面详细说明使用方法和注意事项，可减少误解型退货
- 内部设定退货率警戒线，超过3-5%即启动产品/页面/包装检查

### 【运营技巧】广告预算优化：从日预算10万到3万的ROAS逆袭
**适用场景**：广告费天天烧但销量不见涨，ROAS长期在300%以下徘徊，或者预算增加后效率反而下降
**具体操作**：
1. **关键词筛选（核心）**：
   - 从所有关键词中筛选出「转化率>3%」的核心购买关键词20个
   - 将预算从分散投放集中到这些关键词
   - 无关关键词全部排除（特别是AI自动添加的错配词）
2. **时段集中策略**：
   - 商品注册后5-7天内利用「最新性评分」集中投放，小预算也能获得大曝光
   - 下午6-9点黄金时段集中预算，ROAS平均提升30%
   - 季节性商品在需求高峰期前2周开始增投
3. **出价差异化**：
   - 高转化关键词：逐步上调出价，保持竞争力
   - 探索关键词：平均出价观察，2周后决定去留
   - 品牌词：适度出价，避免被竞争对手抢占
4. **每日检查清单**：
   - 检查昨日ROAS是否达标（300%+）
   - 检查哪些关键词消耗了预算但无转化
   - 检查缩略图是否符合新政策（白色背景、无营销文案）
**效果预期**：
- 实际案例：某化妆品品牌从日预算10万韩元降至3万韩元，ROAS从300%提升至1,200%
- 广告费70%节约，同时销量维持
- 2个月内ROAS从320%提升至400%
**注意事项**：
- 避免「预算增加=销量增加」的误区，先优化再增投
- 商品页面/评论未准备好时投放广告是浪费
- 出价调整幅度每次不超过20%，避免系统重新学习导致波动

### 【运营技巧】Rocket Growth入仓规范：避免被拒损失
**适用场景**：准备使用Rocket Growth服务的卖家，或已有入仓被拒经历需要改进
**具体操作**：
1. **入仓前5项检查**：
   - 条码粘贴：40x20mm或100x150mm，平整粘贴、不褶皱
   - 包装规格：符合Coupang标准，破损箱会被拒收
   - 保质期：剩余70%以上（食品/化妆品等）
   - 数量一致：箱内商品数量与申报一致
   - 标签信息：产品信息、成分、原产地等完整
2. **箱内文件配置**：
   - 箱体上表面：条码标签
   - 箱内：包装明细表
   - 箱体侧面3面：入仓标识文件
3. **物流选择**：
   - 推荐韩进快递一键注册
   - 提前选择入仓物流中心，确认入仓预定日期
4. **成本模拟**：
   - 计算完整费用：销售手续费+入出库/配送费+仓储费+退货费
   - 30天仓储免费期后的日仓储费：25-50韩元/CBM
   - 确保定价留有足够毛利
**效果预期**：
- 入仓一次成功，避免反送费（2,000韩元+/件）
- 流程标准化后，入仓准备时间缩短50%
- 减少因入仓问题导致的销售延迟和损失
**注意事项**：
- 入库被拒后重新准备比第一次更耗时，务必一次性做到位
- 仓储免费期从60天缩短到30天，周转慢的商品需特别注意
- 首次入仓建议少量（5-30件）测试，确认流程后再大量入仓

### 【运营技巧】卖家快速结算（Seller Wallet）活用
**适用场景**：资金周转紧张的卖家，或需要快速回笼资金用于采购的卖家
**具体操作**：
1. **申请条件**：Coupang卖家均可申请，无额外手续费或利息
2. **结算机制**：
   - 前一天购买确认的销售额的90%，次日早上即可使用
   - 通过Coupang与韩亚银行合作发行的专用支票卡（Seller Wallet卡）充值
   - 剩余10%按原有结算周期后续入账
3. **使用方式**：
   - 直接使用支票卡支付供应商货款、采购原材料
   - 未使用的余额在结算日转入卖家银行账户
4. **资金规划**：
   - 将90%快速结算资金用于采购和库存补充
   - 10%后续资金用于覆盖退货、争议等不确定支出
**效果预期**：
- 资金回转速度从平均19-60天缩短到次日
- 消除「资金梗阻」现象，无需依赖贷款或信用卡分期
- 供应商也更愿意接受手续费更低的支票卡支付
**注意事项**：
- 快速结算不是额外贷款，只是提前使用已确认的销售款
- 需确保商品质量和退货管理良好，否则快速结算后发生大量退货会资金紧张
- 适合销售稳定、退货率可控的卖家，新品测试阶段建议谨慎使用

### 【今日总结】

#### 核心洞察
1. **数据连接结构决定搜索生死**：2026年Coupang算法不再只看单一指标，而是评估搜索→点击→停留→购买→复购的完整数据流。商品名、关键词、页面、评论、广告必须形成闭环，缺一不可。
2. **费用计算必须全面**：只看销售手续费（5.5-10.8%）定价的卖家必死。Rocket Growth实际费用占销售额15-25%，包括配送、仓储、退货、广告、服务费等。精确计算是盈利的前提。
3. **客户响应是搜索排名的隐藏变量**：24小时回复率、退货处理速度、评论管理直接影响卖家分数，进而影响搜索曝光。这不仅是服务质量问题，更是流量获取问题。

#### 实操建议（明天可立即应用）
1. **检查当前广告关键词列表**：今天就开始审查AI自动添加的关键词，排除与商品无关的匹配词，特别是大类错配（如皮鞋→运动鞋）。预期可节省10-30%无效广告费。
2. **建立退货处理SOP**：在Coupang Wing中设置「退货管理」每日检查提醒，准备标准回复模板，确保24小时内响应。同时整理发货照片存档流程。
3. **重新计算主力SKU的真实利润率**：将配送费、仓储费（按30天免费期后）、退货预留（销售额的3-5%）、广告费（销售额的10-15%）全部纳入，确认每个SKU是否真的有利润。没有利润的SKU立即调整价格或停售。
