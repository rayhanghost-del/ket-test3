## 一、核心法律框架

### 1.1 主要法规

| 法律名称 | 作用 | 关键要点 |
|---------|------|---------|
| **《电子商务消费者保护法》** (E-Commerce Act) | 韩国电商基本法 | 2025年12月30日通过重大修订，预计6个月后生效（代表人制度12个月后生效） |
| **《对外贸易法》** | 外贸管理基本法 | 与《外汇交易法》《关税法》构成外贸管理法规体系 |
| **《个人信息保护法》(PIPA)** | 个人信息保护一般法 | 规范收集、使用、第三方提供和跨境传输 |
| **《电信业务法》(TBA)** | 电信服务监管 | 设施/增值电信服务商注册/报告要求 |
| **《垄断规制与公平交易法》** | 竞争保护 | 禁止平台垄断、算法合谋、数据驱动价格操纵 |
| **《网络法》** | 信息通信网络安全 | 技术/行政安全要求，禁止非法信息分发 |

### 1.2 2025-2026重大法律修订（⚠️ 重点）

#### 电商法修订核心变化（2025.12.30通过）

1. **强制任命韩国境内代表人**
   - 适用范围：达到一定销售额或韩国用户数的外国电商企业
   - 功能：处理消费者投诉、争议解决、配合KFTC调查（含提交数据）
   - 生效时间：**修订颁布后12个月**
   - 风险：代表人失职 = 外国企业直接责任，可面临整改令或行政罚款

2. **C2C交易平台加强监管**
   - 平台对C2C交易的责任增加
   - P2P平台卖家认证：仅需手机号+邮箱（减少不必要个人信息收集）

3. **临时停运令门槛大幅降低**
   - 针对欺诈性网站的行政禁令，自2016年以来仅使用3次
   - 修订后门槛显著降低，KFTC可更频繁使用

4. **在线平台公平交易法提案**
   - 强制结算周期、利息罚金、托管/保险要求
   - 商家有权组建平台用户协会（集体谈判权）
   - 销售额10%或最高50亿韩元行政罚款

5. **处罚力度加重**
   - 累犯罚金最高增加50%（4次以上最高100%）
   - 自愿整改减免上限从30%降至10%

## 三、清关实务

### 3.1 个人通关代码 (pUNI-PASS)

- **格式**：P + 12位数字（P+发行年份2位+授权号9位+校验码1位）
- **用途**：韩国消费者必填，用于识别真实收货人
- **申请**：https://p.customs.go.kr
- **注意**：
  - 同一SKU不超过3件，带电货物不超过1件（否则被判定为非自用）
  - 通关号、收件人姓名、电话号码必须与注册信息一致
  - 外国人可用护照号/外国人登记号替代

### 3.2 清关模式选择

| 模式 | 适用场景 | 要点 |
|-----|---------|------|
| **一般贸易 (0110)** | 大宗B2B | 免抵退政策 |
| **跨境直邮 (9610)** | B2C小包 | 有票退税 / 无票免税 |
| **海外仓 (9810)** | 备货模式 | 离境即退税/预退税 |
| **市场采购 (1039)** | 小额多品种 | 免征免退，无需进项发票 |
