## 一、市场概况

韩国是全球电商渗透率最高的国家之一，互联网渗透率达 **97%**，电商市场规模 **超千亿美元**。

**主要平台格局（2024-2025）：**

| 平台 | 地位 | 佣金 | 月活/特点 |
|------|------|------|----------|
| **Coupang** | 绝对老大，年销售额破300亿美元 | 5%-15%（跨境店5-10%） | 3325万月活，火箭配送次日达 |
| **Gmarket** | 第二大综合平台 | 7%-13%（ESG跨境部分类目降至7%） | 690万月活，2024 GMV破13万亿韩元 |
| **11Street** | 前三强 | 5%-10% | 923万月活，连续13年满意度第一 |
| **Naver Plus Store** | 搜索+电商生态 | — | 752万月活 |
| **Temu** | 新晋搅局者 | — | 2024年韩新增下载1804万，全年龄段第一 |
| **AliExpress** | 中国平台出海 | — | AliExpress+Temu合计1650万月活 |

**关键趋势：**
- Temu正在构建综合物流系统，直接进军韩国
- Coupang计划2025-2026年追加2.4万亿韩元投资物流，目标2027年火箭配送覆盖5000万人
- 但Coupang也是2024年被罚款最多的企业（1401.78亿韩元），涉及延迟支付卖家货款等争议

## 二、法律法规框架

### 核心法律

| 法律 | 适用范围 | 关键要点 |
|------|---------|---------|
| **《电子商业基本法》** (2002) | 电子商务全局 | 电子信息、数字签名、电子认证、消费者保护、行业标准 |
| **《电子商务法修订案》** (2024.8) | 境外电商强制要求 | **总部在境外的电商必须在韩国指定境内代理人**，处理消费者纠纷 |
| **《消费者保护法》** | 消费者权益 | 产品信息、价格、退货政策必须清晰展示，禁止误导性广告 |
| **《个人信息保护法》(PIPA)** | 数据隐私 | 用户数据收集、存储、使用合规 |
| **《电子金融交易法》** | 支付与金融 | 支付网关(PG)、电子预付手段需注册电子金融业务 |
| **《海关法》** | 进出口 | 商品申报、关税缴纳、禁止危险品通关 |
| **《大型流通业公平交易法》** | 平台与卖家关系 | 禁止平台滥用优势地位，结算期限≤40天 |

### 2024-2026 最新监管动态

1. **强制国内代理人制度**：境外电商必须在韩国指定代理人，否则KFTC可处罚。门槛取决于月均访问用户数或KFTC要求。

2. **结算期限收紧**：电商公司和支付代理商的结算期限缩短至 **40天以内**，并引入销售收入分开管理制度。

3. **罚款力度加大**（2026.3 KFTC新规）：
   - 再次违法：罚金最高增加50%
   - 违法超四次：罚金最高增加100%
   - 主动纠正减免上限：从30%降至10%

4. **消费者保护加强**：
   - 删除未获KC认证产品的销售信息
   - 禁止非法产品和假冒产品分销
   - 建立国内客服中心/热线

5. **二手平台身份验证简化**：仅需核对手机号和邮箱，无需多项详细信息。

### 注意事项
- 韩国实行 **KC认证制度**，部分商品（电子、儿童用品等）必须通过认证
- 食品、化妆品销售需额外许可
- 医药品、武器、烟草等为禁售品类

## 三、税务条款详解

### 税种总览

韩国税务体系分为 **国税**（中央政府）和 **地方税**（省、市、县三级）。

#### 1. 增值税 (VAT / 附加价值税)

| 项目 | 规定 |
|------|------|
| 标准税率 | **10%** |
| 出口 | 零税率（可退税） |
| 进口VAT | 10%，可抵扣销售环节VAT |
| 申报周期 | 季度（小微企业）；零税率企业需按月申报以尽快退税 |
| 发票要求 | **强制电子增值税发票**，未开具/未申报将处罚金 |
| 免税门槛 | **2021年7月起取消**——所有进口商品均需缴纳VAT |

**⚠️ 关键提醒：**
- 进口时缴纳的VAT可在销售环节抵扣（流转税特性）
- **不走包税清关**：包税不使用你的韩国公司抬头，缴纳的VAT无法在后续销售抵扣
- 货款和清关成本必须一致，韩国税务监管严格

#### 2. 企业所得税 (法人税)

| 应税利润区间 | 税率 | 含地方税 |
|-------------|------|---------|
| ≤ 2亿韩元（≈110万RMB） | **9%** | +0.9% |
| 2亿 - 200亿韩元 | 1800万韩元 + 超过部分19% | +10%地方税 |
| 200亿 - 3000亿韩元 | 37.8亿韩元 + 超过部分21% | +10%地方税 |
| > 3000亿韩元 | 625.8亿韩元 + 超过部分24% | +10%地方税 |

- 国内公司：**全球收入纳税**
- 外国公司：**仅韩国来源收入纳税**
- 中小企业另有替代性最低税优惠

#### 3. 关税

- 根据商品 **HS编码** 和原产地不同，税率各异
- 价值低于200美元的商品曾有免税政策，但**特定类目（食品、化妆品）即使低于限额也可能征税**
- 进口关税 **不可抵扣**，是成本而非流转税

#### 4. 其他税种

| 税种 | 说明 |
|------|------|
| 个人消费税 | 酒精、烟草、奢侈品等特定商品 |
| 地方所得税 | 企业所得税的10%附加 |
| 财产税 | 土地、建筑、住宅等 |
| 购置税 | 财产取得时缴纳 |

### 跨境税务合规策略

1. **在韩国税务局注册企业**，获取纳税人识别号
2. **税务登记**：增值税 + 企业所得税双重注册
3. **季度申报增值税**，年度申报企业所得税
4. **保留完整财务记录**：收入、成本、物流、平台费用、广告费
5. **利用中韩税收协定**：韩国已缔结超70个税收协定，中韩协定可降低双重征税风险
6. **咨询本地税务专家**：韩国税法复杂，强烈建议聘请当地税务顾问

## 四、主要平台运营要点

### Coupang（酷澎）

**入驻条件：**
- 跨境店：中国大陆/港澳台企业营业执照（个体户不支持）
- 本土店：需注册韩国本地公司

**费用结构：**
- 注册费：免费
- 保证金/月租：无
- 佣金：按品类5%-15%（跨境店一般5-10%）
  - 3C电子：5-8%
  - 服饰：10%
  - 服装类最高15%
- 广告：CPC，0.1-1美元/点击
- 物流：CGF/CGF Lite（威海仓、东莞仓），按重量尺寸计费

**物流模式：**
- **CGF（Coupang Global Fulfillment）**：入仓后平台负责配送，类似FBA
- **CGF Lite**：跨境直发，时效3-7天
- 本土店可使用 **Rocket Delivery**：12点前下单当日达/次日达

**2025新变化：**
- CGF运费补贴取消
- 东莞仓库额外加收4.5人民币/件
- 威海仓库前3个月佣金优惠3%

### Gmarket

- 入驻费：3000元（代入驻）
- 无月租、年费、保证金
- 佣金：7%-12%（品类差异）
- 2025.6起ESG跨境卖家三大类目佣金从13%降至7%
- 收款：对公美金账户 / 第三方支付
- 禁售：医药品、武器、烟草、含尼古丁产品等

### 11Street

- 入驻费：3000元
- 无月租、年费、保证金
- 佣金：5%-10%
- 支持多种付款方式
- 自发货无限制
- 入驻周期：7-10个工作日

## 五、物流与支付

### 物流

| 方式 | 时效 | 适用 |
|------|------|------|
| Coupang Rocket Delivery | 当日达/次日达 | 本土店、入仓商品 |
| CGF（威海仓/东莞仓） | 1-3天 | 跨境店批量备货 |
| CGF Lite | 3-7天 | 跨境店自发货 |
| 国际快递（DHL/FedEx等） | 3-7天 | 自发货卖家 |

- 韩国政府正在构建数字化综合物流系统，计划到2026年建立AI通关平台
- 中国卖家地理位置优势明显，威海到韩国海运时间短

### 支付

| 方式 | 说明 |
|------|------|
| 韩国本地银行账户 | 本土店必需 |
| Payoneer | 跨境收款常用 |
| PingPong/连连支付 | 多店铺管理，结汇费率低 |
| 对公美金账户 | Gmarket等平台支持 |

- 韩国银行推进CBDC（央行数字货币）"Project Han River"，2025年Q2民间测试
- 采用ISO 20022标准，跨境支付效率持续提升
- KYC/AML合规日趋严格，注册务必使用真实企业资料

## 六、关键合规红线

1. **必须指定韩国国内代理人**（境外卖家）
2. **VAT 10% 必须缴纳**，无免税门槛
3. **进口不走包税**，否则VAT无法抵扣
4. **货款与清关成本必须一致**
5. **电子发票强制**，未申报即罚款
6. **结算周期≤40天**，违反可追责
7. **KC认证** 对部分品类是硬性要求
8. **个人信息保护** 必须合规（PIPA）
