### 【问题案例1】卖家评分因快递延误被扣为0，如何快速恢复
**场景描述**：卖家一直维持100分的卖家评分，某天突然因「配送延误」被扣为0分。实际卖家已按时发货，是快递公司配送延迟导致包裹比预计晚到一天。
**问题分析**：
- 쿠팡的卖家评分系统以「预计配送日」为准，而非卖家实际发货日
- 快递公司原因导致的延误，系统不会自动排除，直接算在卖家头上
- 这种设计让卖家和平台都浪费大量时间在事后申诉上
**解决方案**：
1. 登录 Wing 卖家后台，找到具体延误订单的订单号和包裹ID（묶음배송번호）
2. 截图保存自己实际发货的时间证据（发货记录、快递揽收截图）
3. 通过卖家评分排除申请链接提交申诉：https://helpseller.coupang.com/hc/ko/requests/new?ticket_form_id=360000545712
4. 选择「판매자점수 제외 - 정시배송완료」，填写订单号和包裹ID
5. 附上发货时间截图，提交后通常数日内处理完毕
**关键要点**：
- 平时养成截图保存发货记录的习惯，申诉时需要证据
- 这是系统设计缺陷，不是卖家过错，遇到时不要慌张，按流程申诉即可恢复
- 频繁遇到同一快递公司的延误问题，考虑更换合作快递
**原文链接**：https://nomadel.tistory.com/entry/쿠팡-정시발송했는데-판매자-점수가-갑자기-0이-되었다

### 【问题案例2】AI自动广告乱加关键词，卖家平均浪费高达1900万韩元广告费
**场景描述**：某卖家使用쿠팡自动广告（AI 스마트 광고/매출최적화 광고）后发现，自己卖的是「皮鞋」，系统却自动匹配了「运动鞋」关键词；卖「衬衫」的匹配了「卫衣」关键词，广告费持续流失。
**问题分析**：
- 쿠팡AI自动扩展关键词时，语义相近但品类不同的词也会被加入
- 自动广告（除手动广告外）不会自动排除无效关键词，需要卖家手动管理
- 很多小卖家没时间逐条分析关键词，导致广告费长期被无效点击吃掉
- 调查显示，单个卖家因无效关键词最大损失高达1,900万韩元
**解决方案**：
1. 每周至少检查一次自动广告的「搜索词报告」（광고보고서）
2. 把无关、转化率低的关键词加入「제외키워드」（否定关键词）
3. 使用第三方工具（如세이비）批量分析「吃钱关键词」，一键排除
4. 大词（流量高但转化低）不要盲目加价，优先投「购买意图明确的长尾词」
5. 自动广告启动初期（前3-5天）必须每天检查并清理无效词
**关键要点**：
- 自动广告不是「开了就不管」，前两周的关键词筛选决定后续效率
- 手动广告虽然设置麻烦，但通常ROAS效率更高，两者应并行使用
- 大词的点击单价高但成交率低，守住否定关键词列表比抢大词更重要
**原文链接**：https://openads.co.kr/content/contentDetail?contsId=16237

### 【问题案例3】「直权退款」让卖家货财两空——反品未收回就被自动退款
**场景描述**：卖家A某天在反品列表中发现数十笔自己从未处理过的退款，原来是쿠팡以「卖家过错」为由直权退款。卖家既没收到退货，也联系不上买家，钱和货都损失了。
**问题分析**：
- 2021年3月起，쿠팡规定：买家以「卖家过错」申请反品，若4个工作日内未完成回收，系统直权退款
- 10万韩元以下商品几乎秒退，无需卖家确认
- 卖家常常事后才发现，此时买家已失联，货也追不回来
- 部分买家利用此制度恶意退款（「不问马退款」악용）
**解决方案**：
1. 反品通知到达后，第一时间在Wing后台点击「确认完成」（확인완료）
2. 1个工作日内必须完成回收指示（회수지시），2个工作日内完成回收
3. 若来不及回收，쿠팡会派专送快递员上门回收，但费用由卖家承担
4. 若已被直权退款且未收回货物：
   - 在「쿠팡확인요청」中申请补偿（회수한 경우7日内，未회수的14营业日内可申请）
   - 若被拒，168小时内可再次申请
5. 防恶用：商品详情页明确标注尺寸/规格，减少「卖家过错」类反品
**关键要点**：
- 反品处理速度是生命线，拖延一天就可能货财两空
- 一定要定期检查反品列表，不能等发现异常再去追
- 代销/无库存卖家更脆弱——上游供应商不配合回收时，损失全由自己承担
**原文链接**：https://www.greened.kr/news/articleView.html?idxno=288119

### 【问题案例4】로켓그로스入库被拒TOP5，一单被拒损失2000韩元+时间成本
**场景描述**：新手卖家将商品送入쿠팡物流中心（FC）时频繁被拒收，来回运输浪费时间和运费，还耽误上架销售节奏。
**问题分析**：
- 入库被拒的主要原因集中在：包装规范、条码、保质期等基础问题
- 每次被拒的返送费约2,000韩元/件，且需重新准备再次入仓
- 保质期管理失误可能导致整批货报废
**解决方案**：
1. 入库前逐项自检清单：
   - [ ] 条码清晰贴附、可扫描（바코드 미부착/불량是最常见拒收原因）
   - [ ] 外包装尺寸/材质符合该类目入仓标准（포장 규격 미준수）
   - [ ] 保质期剩余70%以上（유통기한 잔여 70% 미만将被拒）
   - [ ] 实际送货数量与申报一致（상품 수량 불일치）
   - [ ] 标签信息（品名、规格、产地等）与系统录入完全一致（라벨 정보 오류）
2. 首次入仓建议先送少量「测试批次」，确认流程无误后再大批量送
3. 食品/化妆品类额外注意：成分标注、进口报关文件是否齐全
**关键要点**：
- 返送费是小钱，但耽误上架时间是大损失——新品上架后5-7天是「最新性分数」黄金期
- 代销卖家务必让供应商提供准确保质期信息，不能凭经验估算
- 建议制作入库自检SOP表，每次入仓前打印核对
**原文链接**：https://ssjum.com/marketplace-coupang.html

### 【问题案例5】海外食品卖家被全面停售——平台政策突变应对不及
**场景描述**：2025年6月，쿠팡突然通知：通过로켓그로스销售的海外食品（中国等海外卖家进口的食品）全面停止新注册、入仓及销售。已入仓的海外食品也被停售。大量中国卖家和海外代购卖家措手不及。
**问题分析**：
- 近期进口食品中频繁出现违反韩国国内法的情况（食品添加剂超标、未经许可的成分等）
- 食药处和海关加强了对进口食品的查处，쿠팡为规避平台责任采取「先停后查」
- 政策仅通过个别通知传达，未公开公告，很多卖家是发现商品被下架后才得知
- 此次是「暂时性」措施，但쿠팡明确表示可能扩大到婴幼儿、美妆等敏感类目
**解决方案**：
1. 已受影响的卖家：
   - 立即清点库存，准备 alternative 销售渠道（其他平台、自发货等）
   - 整理现有商品的进口报关文件、成分分析报告，等待平台后续指引
2. 经营进口/海外商品的卖家应：
   - 关注食药处「海外直购食品阻断列表」更新
   - 确保所有成分、标签、保质期标注符合韩国法规
   - 避免销售未经韩国许可的功能性成分或保健品
3. 分散风险：不要把全部库存压在单一平台，特别是依赖로켓그로스的模式
**关键要点**：
- 平台政策变化不会提前打招呼，敏感类目卖家必须预留Plan B
- 쿠팡对「食品安全」是零容忍，一旦违规可能波及账户整体
- 未来婴幼儿用品、美妆类也可能面临类似整顿，建议提前合规自查
**原文链接**：https://m.etnews.com/20250610000186

### 【问题案例6】代销卖家退货踩坑——供应商失联、地址变更、运费暴增
**场景描述**：一位在도매매代销的卖家遇到买家要求换货（商品故障）。联系上游供应商时，发现：商品已显示断货、退货地址与发货地址不一致、供应商客服电话无人接听，最终自己承担了6,000韩元运费才解决。
**问题分析**：
- 代销模式本质是「信息差生意」，但对供应链控制力极弱
- 쿠팡的退货/换货时效要求（1个工作日回收指示、2个工作日完成回收）与上游供应商的响应速度不匹配
- 很多供应商对小额代销卖家不重视，态度消极甚至失联
- 退货地址变更若未及时发现，卖家只能自费寄送到新地址
**解决方案**：
1. 选择供应商时，把「售后响应速度」作为核心考核指标，不要只看价格
2. 日常维护供应商的多个联系方式（客服电话、手机、官网、카카오톡等）
3. 定期确认供应商的退货地址是否有变更，同步更新到自己的SOP
4. 在쿠팡后台处理退货时，务必要求供应商提供回收运单号并及时回填到「반품관리」
5. 买家发送的商品故障照片/视频必须保存，既是给供应商的证据，也是防范恶意退货
**关键要点**：
- 代销卖家的时间成本极高——一个退货处理可能消耗整个上午
- 不要把所有SKU押在一个供应商身上，至少要有一两个备用供应商
- 情绪管理很重要：和供应商争执只会消耗自己，解决问题是第一优先级
**原文链接**：https://organizing.tistory.com/entry/도매매에서-쿠팡에-위탁판매한-상품-교환-및-반품-방법

### 【运营技巧】新品上架「黄金5-7天」广告集中爆破法
**适用场景**：新品刚上架、评论数为0或很少、需要快速获得曝光和转化数据的阶段
**具体操作**：
1. 上架当天立即开启广告，设定日预算30,000韩元（쿠팡推荐初始预算）
2. 前5-7天是「最新性分数」窗口期，此期间쿠팡算法会给予额外曝光权重
3. 广告策略：
   - 同时使用「手动성과광고」+「매출최적화광고」
   - 手动广告：所有关键词竞价统一设为200韩元（无建议竞价时100韩元），两周后根据报告调整
   - 关闭「전체매출더하기」（非搜索区域曝光），这个功能像弹窗广告，效率低
4. 配合价格策略：上架初期做10-20%折扣，提升点击率和转化率
5. 上架前确保：详情页优化完毕、主图符合规范（白色背景、无营销文案）、至少有少量评价基础
**效果预期**：
- 在黄金窗口期内，用较少广告费获得较高自然曝光
- 快速积累转化数据，让쿠팡算法识别该商品为「高转化潜力」
- 为后续长期排名奠定基础
**注意事项**：
- 如果详情页粗糙、主图违规，黄金期的流量会被浪费，甚至导致广告审核被拒
- 不要盲目加大预算——有卖家预算增10倍后，无效曝光剧增，ROAS反而下降
- 手动广告的关键词必须和商品强相关，无关词会带来无效点击

### 【运营技巧】쿠팡 SEO 2025新规则：从「关键词堆砌」到「语义优化」
**适用场景**：所有需要提升自然搜索排名的卖家，尤其是依赖搜索流量的标品类目
**具体操作**：
1. 放弃旧思维：不要再把同一个关键词重复堆砌在商品名中（2025年起反而可能被限流）
2. 商品名公式：搜索词 + 类目词 + 商品名 + 搜索选项 = 系统识别搜索词
3. 引入「子关键词」（서브키워드）策略：
   - 分析季节/场景/人群需求，在商品名中加入具体使用场景
   - 例：「선풍기」→「여름침실무소음선풍기」「사무실책상탁상선풍기」
4. 从竞争对手差评中找SEO素材：
   - 看类目第一名商品的差评
   - 如果差评集中反映「噪音大」「安装难」等问题
   - 在自己的商品名和详情页中突出「静音」「免安装」等卖点词
5. 移动端优先：
   - 쿠팡70%以上流量来自移动端
   - 商品名前20个字必须包含核心关键词和最大卖点
   - 详情页前3屏决定跳出率，核心信息前置
**效果预期**：
- 自然搜索排名更持久（有案例从20天排名维持延长到76天）
- 转化率提升（精准流量带来的是真正有购买意图的用户）
- ROAS从250%提升到820%的实测案例存在
**注意事项**：
- 健康功能食品类目严禁使用「治疗」「功效」等医疗相关词汇，否则广告被拒+账户受限
- 关键词必须与商品实际属性匹配，虚假宣传会导致差评率和退货率双高
- 不要抄袭竞品的商品名——쿠팡算法会识别雷同内容并降权
**原文链接**：https://oscsnm.com/coupang-seo-optimization-guide/

### 【今日总结】

- **核心洞察**：
  1. 쿠팡的「卖家评分」和「直权退款」机制对卖家极不友好，但都有明确的申诉/补偿通道——关键是反应要快，不能拖。
  2. 2025-2026年쿠팡算法明显转向「AI自动+语义理解」，传统关键词堆砌失效，精准场景词和转化数据才是排名核心。
  3. 代销/无库存模式虽然启动成本低，但售后链条脆弱——供应商失联一次，时间+金钱+情绪三重损失。

- **实操建议**：
  1. 今天就把自己的广告后台打开，检查自动广告的「搜索词报告」，把近7天点击高但0转化的词加入否定关键词。
  2. 如果你经营的是海外进口或敏感类目（食品、婴幼儿、美妆），本周内做一轮合规自查，准备好替代销售渠道。
  3. 制作一份「反品处理SOP」贴在显眼位置：1个工作日内必须完成回收指示，同步记录每笔反品的商品状态照片。
