## 模块一：韩国电商实操日报（Coupang 运营深度案例）

### 【问题案例1】Coupang 退货无法收回却被强制退款处理，卖家同时损失货物和资金

**场景描述**：
卖家在退货受理后等待商品回收，但 Coupang 在营业日60小时后以"保障退款(보장환불)"政策强制退款处理。卖家未能回收商品就被扣除退款金额。

**问题分析**：
- Coupang 的"保障退款(보장환불)"政策：客户在发货指示/配送中/配送完成(배송지시/배송중/배송완료)状态下提交退货申请后，若超过营业日60小时仍未处理退款，无论是否回收商品，Coupang 都会优先退款
- 客户改变主意不想退货但未取消退货申请，或故意不寄回商品的情况较多
- Coupang 安全号码(안심번호)过期后无法直接联系客户

**解决方案**：
1. 致电 Coupang 客服中心(1600-9879)获取"收件人真实号码"或"下单人真实号码"
2. 直接联系客户请求取消退货，或告知退货商品回收地址
3. 客户不接电话也不寄回退货商品时：
   - 向 Coupang 申请"回收支援"（订单/配送 → 退货管理 → 入库运单号 → 回收运单号注册）
   - 在咨询留言板发布回收支援请求
   - 若 Coupang 联系客户后仍无法回收，Coupang 将进行重新结算处理

**关键要点**：
- 退货回收必须先"注册回收运单号(회수 송장 등록)"，Coupang 才能介入
- 客户联系方式必须在安全号码(안심번호)过期前（退货受理后30天内）尽快获取
- 可通过"Coupang 确认请求(쿠팡확인요청)"申请补偿，但未回收商品需在14个营业日内申请（2022年9月改善后的政策）

### 【问题案例2】Rocket Growth(로켓그로스) 仓储费(보관료)暴涨…库存周转慢的商品面临亏损(역마진)风险

**场景描述**：
入驻 Rocket Growth(로켓그로스) 的卖家在月末结算时发现物流费比预期大幅扣减。保管期较长的商品仓储费(보관료)吞噬了利润。

**问题分析**：
- Coupang Rocket Growth(로켓그로스) 仓储费根据商品尺寸、重量、滞留期计算
- 2025年1月6日起免费保管期缩短：配饰/服装/鞋类45天，其他品类30天（此前为60天）
- 长期保管附加费：保管超过90天时按基本费用的1.5倍计费
- 旺季（11~12月）仓储费增加10%~20%
- 库存周转慢的商品仓储费会抵消净利润甚至产生亏损(역마진)

**解决方案**：
1. 入库前确认各商品尺寸报告 → 预估仓储费
2. 定价时将"广告费 + 入出库费 + 退库费 + 仓储费(보관료)"全部纳入计算利润
3. 库存周转率分析：以2周销量为基准维持适当库存（推荐）
4. 长期库存应对：
   - 超过90天的商品开展折扣促销快速消化
   - 卖家直接申请退库（每月20单内免费，超出后每单300韩元）
   - 批量退库节省费用
5. 活用分类别免费保管期差异：服装/鞋/配饰45天免费，积极利用

**关键要点**：
- 仓储费(보관료)从"每日25~50韩元/CBM(立方米)"起算，但随商品大小和保管期呈几何级增长
- 入库被拒原因TOP5：条码(바코드)未贴/不良、包装规格未达标、保质期剩余不足70%、商品数量不符、标签信息错误 → 被拒时退货运费（每单2,000韩元+）也由卖家承担
- 利润率30%以下的低利润商品在 Coupang 难以盈利

### 【问题案例3】Coupang 广告月投300万韩元但 ROAS(广告投资回报率)仅80%…依赖自动广告的卖家失败案例

**场景描述**：
一位卖家在 Coupang 自动广告(자동 광고)上月投入300万韩元，但 ROAS（广告支出回报率）仅达80%，只消耗广告费造成损失。这是依赖自动广告(자동 광고)导致无效关键词浪费预算的案例。

**问题分析**：
- Coupang 自动广告(자동 광고)由 AI 自动筛选关键词，但也会在购买意图低的关键词（如"免费"、"样品"）上曝光造成浪费
- 自动广告(자동 광고)中无法直接设置排除关键词(제외 키워드)
- 广告开启后放任不管只会消耗预算而销量原地踏步
- 对缺乏商品竞争力的产品（评价少、详情页薄弱）投广告也是浪费

**解决方案**：
1. 自动广告(자동 광고) → 手动广告(수동 광고) 转换策略：
   - 初期3~5天用自动广告(자동 광고)收集数据（发掘潜在关键词）
   - 仅将实际购买转化率高的关键词转入手动广告(수동 광고)活动
   - 购买转化率0%的关键词立即登记为排除关键词(제외 키워드)（每活动最多500个）
2. ROAS 分析标准：
   - ROAS 100%以下关键词：仅消耗广告费 → 考虑排除
   - ROAS 300%以上关键词：高效 → 逐步上调出价
3. 预算分配策略：70%用于验证效果的手动广告(수동 광고)，30%用于发掘新关键词的自动广告(자동 광고)
4. 每周分析广告成效并调整出价/关键词/定向
5. 时段预算分配：晚6点~9点黄金时段分配150%预算 → ROAS 可提升30~40%

**关键要点**：
- 2026年 Coupang 广告缩略图政策强化：必须白色背景，插入"免费配送"/"最低价"/"限量销售"等营销文案时广告审批被拒并可能账户处罚
- 健康功能食品品类：使用"治疗"、"功效"等医疗相关关键词时广告审批被拒 + 可能账户制裁
- 关键词重复设置注意：同一关键词对多个商品广告会导致内部竞争使出价上涨效率下降

### 【问题案例4】详情页(상세페이지)薄弱导致转化率(전환율)不足5%…卖家忽视的图片/移动端优化

**场景描述**：
手工果酱品牌"自然蕴含的果酱(자연담은청)"初期在 Coupang 销售不佳。详情页(상세페이지)仅以商品照片和功效罗列的方式制作，导致移动端跳出率高，购买转化率(전환율)仅2%。

**问题分析**：
- Coupang 用户80%以上使用移动端购物 → 移动端优化为必需
- 详情页(상세페이지)若只是简单图片罗列，客户停留时间短跳出率增加
- 前3秒内没有抓住客户视线的钩子(훅/hook)就无法促成购买
- 详情页(상세페이지)质量分数低会导致 Coupang 搜索曝光排名下降

**解决方案**：
1. 首屏"钩子(훅)"策略：
   - 在详情页(상세페이지)顶部放置高质量图片，明确展示最强优势和客户可获得的核心利益
   - 例："为疲惫的你3秒充电！"
2. 故事化 + 视觉强化：
   - 以故事化形式呈现商品诞生背景、制造过程、使用后记
   - 高清照片 + 短视频片段 + 信息图活用（文字为主页面相比混合图片/视频的页面停留时间增加40%）
3. 在详情页(상세페이지)内布置 FAQ：
   - 将客户常问问题放在详情页(상세페이지)内即时解答疑惑
   - 减少购买前的犹豫
4. 强化 CTA（行动号召/Call-to-Action）：
   - 明确标注"现在购买享免费配送"、"前100名特别折扣"等促进购买转化(전환율)的引导文案
5. 利用评价数据分析：
   - 从实际购买者评价中提取高频关键词反映到详情页(상세페이지)
   - 负面评价指出的问题在详情页(상세페이지)中预先解释/改进

**关键要点**：
- Coupang 数据分析显示，详情页(상세페이지)质量分数高的产品：转化率(전환율)平均高2.3倍，退货率低35%，评价撰写率高40%
- 图片规范：最小1000×1000px以上，背景白色/透明推荐，商品占比80%以上
- 商品名 SEO：[品牌]+[品类核心关键词]+[主要特征]+[规格/数量]，最多100字
- 使用 AI 工具（Canva、Jeditor）可将制作时间从原来2天缩短至0.5天

### 【问题案例5】Coupang 配送延迟 → 卖家责任退货(판매자 귀책 반품)…快递原因也由卖家承担全部责任

**场景描述**：
卖家按出库预定日发货，但因快递公司原因发生配送延迟。买家以"配送延迟"为卖家责任(판매자 귀책)理由申请退货，Coupang 强制退款。配送费也由卖家承担。

**问题分析**：
- Coupang 对买家以"卖家责任(판매자 귀책)"理由申请退货时，若营业日4天（60小时）内退货商品未被回收则强制退款
- 未在预计配送日送达则由卖家承担损失
- Coupang 系统告知越快配送销量越高，诱导缩短预计配送日 → 卖家被迫设短
- 春节连休等快递公司原因导致配送延迟时，卖家责任(판매자 귀책)退货申请也不少

**解决方案**：
1. 预计配送日设置：不被 Coupang "推荐快速配送"诱导，设置充足的交货期
   - 尤其连休/旺季前后要放宽预计配送日
2. 出库前质量检查：不良率超过2%可能被停止销售
   - 建立出库前质量检查流程
3. 退货应对：退货受理时立即"注册回收运单号(회수 송장 등록)"使 Coupang 可介入
   - 直接联系客户说明配送延迟原因并请求谅解
4. 异议申请：通过"Coupang 确认请求(쿠팡확인요청)"申请补偿（商品回收时7日内，未回收时14营业日内）
   - 附证明资料（配送追踪记录、快递公司延迟公告等）

**关键要点**：
- Coupang 对未遵守配送承诺会处罚 → 设置充足交货期为必需
- 买家即使非卖家责任也选择"缺货"、"破损"、"商品错发"等申请退款时，Coupang 可能只听买家一面之词就强制退款 → 异议申请是唯一救济手段
- 退货率管理疏忽时，根据2024年起强化的优秀卖家徽章政策，商品曝光本身会减少

### 【问题案例6】Coupang 入库被拒(입고 거절)且退货运费2,000韩元+由卖家承担…条码(바코드)/包装规格未达标

- 入库延迟导致库存缺货曝光下降及销售机会损失

**解决方案**：
1. 入库前检查清单：
   - 条码(바코드)质量确认：扫描测试完成后发货
   - 包装规格：使用符合 Coupang 物流中心规格的箱子/标签

2. 入库前确认"各商品尺寸报告"
3. 小量测试入库：大量入库前先用小量测试入库确认规格/条码(바코드)无问题

**关键要点**：
- 有保质期的商品仅可入库保质期剩余6个月以上的商品
- 免仓储费(보관료)期限：服装/鞋/配饰每次入库后30天（2025年4月后45天）免费，其他品类即时计费
- 入库条码(바코드)可使用国际标准条码(EAN/UPC)或 Coupang 自有条码(바코드)
- 包装箱必须贴附"Coupang Rocket Growth(쿠팡 로켓그로스)"标识标签

### 【运营技巧】Coupang 搜索优化(SEO/검색 최적화)实战：商品名 + 详情页(상세페이지) + 评价 三位一体策略

**适用场景**：
- 在 Coupang 新注册商品的新卖家
- 商品好但搜索曝光不足导致无销量
- 想提升现有商品搜索排名

**具体操作**：

**第一阶段：商品名优化（搜索核心）**
- 商品名撰写公式：`[核心关键词] + [产品名] + [属性/用途] + [差异点]`
- 例："[安眠枕头] 记忆棉 / 颈椎支撑 / 改善睡眠品质单品"
- 商品名最多100字，核心关键词前置
- 避免过度特殊符号或重复关键词（关键词堆砌会导致排名反而下降）
- 类似关键词组合：同时使用"睡眠枕头"和"安眠枕头"

**第二阶段：完善搜索标签(검색어 태그)**
- 填满20个搜索标签(검색어 태그)（尽量填满）
- 活用分类别热门搜索词
- 包含长尾关键词（竞争少但购买转化率高）

**第三阶段：详情页(상세페이지)内自然布置关键词**
- 以文字重复产品名/效果/使用方法（自然融入）
- 通过 FAQ、使用法、对比表等增加停留时间
- 相比单纯图片罗列，以信息为中心构成

**第四阶段：评价(후기)获取策略**
- 初期获取10条以上带图评价对搜索成绩影响大
- 随商品附上评价活动卡（非强迫性引导）
- 设置购买后14天自动评价请求提醒
- 食品类口味评价照片、美妆类使用前后对比照片尤其有效

**第五阶段：主图点击率(대표 이미지 CTR)优化**
- 使用高清（1000px以上）、明亮图片
- 插入"效果中心文案"（例："不起球！完美防水"）
- 推荐白色背景，商品占比80%以上

**效果预期**：
- 仅详情页(상세페이지)优化即可提升转化率(전환율)30%以上
- 搜索上位曝光时销量比平时增加5~10倍（尤其被选中参加促销时）
- 获取评价后曝光排名上升 → 形成良性循环

**注意事项**：
- 禁用词注意："最高"→"高满意度"、"完美"→"仔细的"、"第一"→"销售上位"等替代
- 健康功能食品：使用"治疗"、"功效"等医疗相关表述时广告审批被拒 + 账户制裁
- 获取评价时使用"提供金钱"等强迫性表述违反政策
- 所有商品保持卖家信息一致（搜索算法将卖家识别为一个实体非常重要）

### 【今日总结 — 韩国电商模块】

**核心洞察**：
1. **Coupang 的"保障退款(보장환불)"政策对卖家设计不利** — 退货回收必须先"注册回收运单号(회수 송장 등록)"，客户联系方式必须在安全号码(안심번호)过期前尽快获取。可通过"Coupang 确认请求(쿠팡확인요청)"申请补偿但有时间限制（回收时7天，未回收时14营业日）。
2. **不精确理解 Rocket Growth(로켓그로스) 物流费用结构会产生亏损(역마진)** — 仓储费(보관료)（30~45天后计费）、退货回收费（每月20单超出后计费）、退库费（每月20单超出后每单300韩元）等必须全部反映在售价中才能确保收益性。
3. **Coupang 搜索算法看"销售速度 + 退货率 + 评价分数"三位一体** — SEO 优化需同时管理商品名/搜索标签(검색어태그)/详情页(상세페이지)/评价才有效，单纯投入广告费难以实现可持续增长。

**实操建议**：
1. 检查现有商品搜索标签(검색어 태그)20个是否全部填满 — 空标签今天立即用分类别热门搜索词填满
2. 在 Coupang 广告中心排除 ROAS 100%以下关键词 — 今天做周分析时如有无效关键词立即登记为排除关键词(제외 키워드)阻断预算浪费
3. 如为 Rocket Growth(로켓그로스) 入驻卖家，检查保管期30/45天临近商品 — 长期保管商品开展折扣促销引导库存消化，防止仓储费(보관료)暴涨

### 三、法律法规框架

**核心法律体系**：
1. **《电子商务等领域消费者保护法》**（2002年制定，多次修订）
   - 2026年1月20日公布修正案，**2026年7月21日生效**
   - 当前最需关注的立法动态
2. **《电子商务法》**（2016）
3. **《个人信息保护法》(PIPA)**（2020）
4. **《公平标签和广告法》**（2014）
5. **《标准合同条例法》**（2007）
6. **《消费者框架法》**（2017）
7. **《电子金融交易法》**（2017）
8. **《垄断规制和公平交易法》**
9. **《大规模分销中的公平交易法》**

**2024-2026年重大修订内容**：

#### 1. 暗黑模式规制（2024年修订，2025年2月14日生效）
- 免费试用转付费需事先取得消费者同意
- 禁止结算末端才披露费用
- 禁止默认预选额外购买选项
- 禁止用按钮大小/颜色制造误导
- 禁止无正当理由设置复杂退订流程

#### 2. 海外平台国内代理人制度（2026年7月21日生效）
触发条件（满足其一）：
- 上一年度对韩销售额达**1万亿韩元**以上
- 上一年度末前三个月月均韩国访问人数达**100万人**以上
- 因涉嫌违法被监管机关要求提交资料

义务：指定本地代理人，负责投诉处理、争议应对、资料提交、监管沟通

#### 3. 个人卖家实名核验
- 平台必须确认个人卖家身份信息
- 纠纷时须向消费者提供必要信息
- 个人卖家不能再完全匿名经营

#### 4. 评价机制透明化
- 须说明谁可以评价、展示多久、评分标准
- 须公开删除评价的条件
- 须提供消费者异议渠道

**广告合规要点**：
- 禁用"第一/最佳"等绝对化用语（单次罚款₩2000万）
- 网红营销必须标注"广告"（韩语：광고）
- 虚假/夸大/欺骗性/诽谤性广告均禁止

### 四、税务条款详解

**韩国本土税务（注册公司后）**：

| 税种 | 税率 | 备注 |
|------|------|------|
| **增值税(VAT/부가가치세)** | 10% | 可抵扣进项 |
| **法人税(법인세)** | 10%-25% | 按利润阶梯征收 |
| **进口关税** | 0%-20% | 依商品类别不同 |

**税收优惠政策**：
- **前3年免法人税(법인세)**，所得税减免50%
- 年利润汇出超$50万需央行预审（周期30天）
- 技术服务费名义汇出：税率12%（优于股息税25%）

**跨境电商进口税（中国→韩国）**：
- **综合税公式**：关税 + 进口环节增值税 + 进口环节消费税
- 限额内优惠：关税0%，增值税+消费税按70%征收
- 中国标准：单次限值5,000元，年度限值26,000元

**注册韩国公司成本估算**：

| 项目 | 金额 |
|------|------|
| 最低注册资本 | 1亿韩元（实务可操作3,000-5,000万韩元） |
| 一次性注册费 | 600-1,500万韩元（3-8万人民币） |
| **年度维护成本** | **1,200-2,500万韩元（6.5-13.5万人民币）** |

| 虚拟办公室 | 120-240万韩元/年 |

> 建议月销稳定在5万美元以上再考虑注册韩国公司。

### 五、产品合规（KC认证）

**KC认证(케이씨 인증) 概述**：
- 全称：韩国安全认证（Korea Certification）
- 2009年1月1日起强制实施
- 覆盖730+种产品
- 认证机构：KTR、KTL、KTC

**认证类型**：
1. **强制性安全认证**（危险性高）
2. **自律性安全确认**
3. **供应商自我确认**（危险性低）

**覆盖品类**：
- 电子电器（AC50V-1000V）：冰箱、洗衣机、显示器等
- 儿童用品：玩具、童装、婴儿推车等
- 生活用品：灯具、纺织品等
- 化妆品：需 MFDS 注册，功能性化妆品需上市前审批
- 食品：MFDS 注册，符合《进口食品安全管理特别法》

**化妆品进口流程**：
1. 确定韩国责任人(MAH/한국 책임자)
2. 配方及标签合规审核
3. 准备自由销售证明、制造证书
4. KPTA（韩国医药品进出口协会/한국의약품수출입협회）申报

## 模块三：自媒体运营学习笔记

### 一、自媒体运营核心策略

#### 1.1 定位：细分赛道是突破口
- 新手最大错误：今天发美食、明天发职场，方向混乱
- 正确逻辑：先定用户 → 再定内容 → 最后选平台
- 用户画像三问法：问需求、问属性、问场景
- 垂直度权重在2025年上升了20%，平台更青睐专注账号

#### 1.2 内容创作的黄金三要素
1. **开头抓痛点（0-3秒法则）**：直接戳用户焦虑，拒绝铺垫
2. **内容给具体价值**：不说"要好好做早餐"，说"上班族做早餐记住3个提前…"
3. **引导互动**：主动提问题，设计投票式话题，评论区埋观点冲突型评论

#### 1.3 发布时机

| 平台 | 最佳时段 |
|------|---------|
| 抖音/视频号 | 早7-9点、午12-14点、晚19-22点 |
| 小红书 | 午12-14点、晚20-22点 |
| 公众号 | 晚20-22点 |

### 二、2025平台算法核心逻辑

#### 2.1 抖音：从"打标签"到"行为预测"
- 核心公式：**预测用户行为概率 × 行为价值权重 = 推荐优先级**
- 不再依赖标签匹配，而是通过神经网络直接预估用户对每条内容的互动可能性
- **完播率权重下降30%**，收藏/复访/追更成为新核心指标
- 中长视频价值回归（案例：450分钟《红楼梦》解读5天千万点赞）
- 流量池机制：初始200-500人 → 赛马晋级 → 跨域拓展

#### 2.2 小红书：CES 评分 + 阶梯推荐
- **CES = 点赞(1分) + 收藏(1分) + 评论(4分) + 转发(4分) + 关注(8分)**
- 2025年新增隐性指标：完播率、高价值评论（≥8字、含场景描述的评论权重×3）
- 原创声明成流量入场券，未开原创可能被限流
- 内容质量分（CQS）：原创率权重60%，每100字需含1个有效信息点
- 标签匹配依然是核心，标题/正文/话题需高度一致

#### 2.3 视频号：社交推荐权重提升30%
- 流量 = 私域流量 + 推荐算法
- "朋友♡"栏前置，社交背书成为最大流量杠杆
- 私域冷启动 → 社交裂变 → 公域放大
- 内容设计要植入"社交动力"：观点共鸣、身份认同、实用价值

#### 2.4 三大平台共性结论
> **"流量不是平台给的，而是用户给的"**  
> 核心已从"迎合算法"转向"满足用户需求"。

### 三、变现模式全景

#### 3.1 五大主流变现方式

| 模式 | 适合人群 | 优点 | 缺点 |
|------|---------|------|------|
| 广告变现 | 有粉丝基础的账号 | 来钱快、操作简单 | 依赖粉丝量 |
| 带货变现 | 有选品/销售能力 | 收入天花板高 | 需供应链能力 |
| 知识付费 | 有专业知识 | 利润率高、用户粘性强 | 需信任积累 |
| 平台分成 | 内容产能强 | 被动收入、长期稳定 | 收入相对较低 |
| 私域变现 | 有产品/服务 | 用户价值高、复购率高 | 运营成本高 |

#### 3.2 各平台变现优势
- **小红书**：广告接单首选，"买手电商"闭环成熟
- **公众号/知乎**：知识付费最佳，私域流量核心
- **抖音/视频号**：带货变现首选，直播电商成熟
- **B站**：知识付费类UP主广告占比达45%

#### 3.3 2025变现新趋势
- 流量主门槛降低：公众号从500粉降到100粉
- 微信小店+推客 = 零囤货纯分享赚佣金
- 品牌定制内容竞价模式兴起
- 垂直领域专业账号更容易获得品牌青睐
- 一人公司年营收过百万正在崛起

#### 3.4 变现选择建议
- 泛娱乐流量 → 主攻广告和带货
- 知识类流量 → 付费专栏或社群变现
- 零基础新人 → 优先打赏或分销带货，边学边做
- 粉丝黏性高 → 尝试付费课程、咨询服务等深度变现

### 四、2025必做三件事

### 五、关键金句记录
