### 【问题案例1】쿠팡 판매자 귀책 반품 처리 실전
**场景描述**：新手셀러가 터치 방한장갑을 판매 중, 고객이 "상품 설명과 실제 사이즈가 다르다"는 이유로 판매자 귀책 반품을 신청했고 배송비도 판매자 부담으로 처리되어 당황함.
**问题分析**：상품 상세 페이지의 사이즈 표기가 애매하여 고객이 오해할 수 있는 여지를 제공한 것이 판매자 귀책 사유. 단순 변심과 판매자 귀책의 판단 기준 불명확.
**解决方案**：
1. 판매자 귀책으로 인정하고 수용 (감정 소모 시간 절약)
2. 쿠팡 반품 관리 화면에서 반품 상품 확인
3. 공급사(도매매)에 해당 상품 반품 접수 (반품 사유는 '상품 자체 문제'로 기술 시 승인 용이)
4. 공급사에서 반품 운송장 발급 → 쿠팡 반품 관리에 운송장 번호 등록
5. 공급사가 고객에게 직접 방문 회수 및 검수 → 공급사에서 환불 → 쿠팡 자동 반품 완료 처리
**关键要点**：
- 반품 사유가 애매할 때 AI에게 상황 설명하여 판단 기준을 명확히 할 것 (시간 절약)
- 도매매 반품 사유는 '판매처 오기재'보다 '상품 자체 문제'로 작성 시 승인 용이
- 반품 발생 후 즉시 상세 페이지 수정하여 재발 방지 (실측 사이즈 이미지 추가)

### 【问题案例2】쿠팡 계정 정지 후 소명 실패 → 재소명 성공 사례
**场景描述**：가전제품 셀러가 '위조품 의심'으로 계정 정지 통보를 받고 첫 소명에 실패했으나, 전문가와 함께 체계적인 재소명으로 계정 복구 성공.
**问题分析**：소명 실패의 90%는 정확한 사유 분석과 객관적인 증빙 자료 부족에서 비롯됨. 첫 소명 시 단순 "정품입니다" 주장만으로는 부족.
**解决方案**：
1. 냉철한 자기 진단: 쿠팡의 반박/거절 사유 꼼꼼히 확인
2. 추가 증거 확보: 정품 인증서, 해외 구매대행 계약서, 제조사 공식 이메일 내역, 세관 수입 신고 필증
3. 내부 프로세스 개선 계획 구체적으로 제시 (예: 변경된 업무 매뉴얼, 직원 교육 자료)
4. 정책 재검토: 쿠팡 판매자 이용약관 정독하여 위반 사항 정확히 파악
5. 전문가 상담 후 체계적으로 재소명 제출
**关键要点**：
- 지재권 침해 소명 시 구매 영수증 + 제조사 계약서 + 권리사 공식 승인서 등 강력한 증거 필요
- 감정적 호소가 아닌 논리적 해결 방안 제시 필수
- 반복적인 정책 위반 시 소명 성공률 현저히 낮아짐

### 【问题案例3】쿠팡 환불 미회수 보상 신청 기간 놓침
**场景描述**：쿠팡 보장환불로 인해 고객은 환불받았으나 상품을 회수하지 않음. 셀러는 자동 정산될 줄 알았으나, 자동으로 정산되지 않아 보상 신청 기간을 놓침.
**问题分析**：쿠팡이 3회 회수 시도 후 실패 처리된 후, 보상 신청은 영업일 5일째부터 168시간(7일) 내 가능. 셀러가 직접 온라인 문의로 신청해야 함.
**解决方案**：
1. 주문/배송 → 반품관리에서 상품 입고 상태 확인 (미입고 상태 시 회수 지원 요청 링크 확인)
2. 고객관리 → 고객센터문의에서 처리 상태 확인 (처리완료 일자 확인)
3. 영업일 5일째부터 신청 가능: 처리완료일 + 영업일 5일째부터 168시간(7일) 내
4. 쿠팡 셀러센터 온라인 문의로 보상 신청 접수
5. 반려 시 기간 조정 후 재신청
**关键要点**：
- 보상 신청은 자동으로 되지 않음, 셀러가 직접 신청해야 함
- 영업일 5일째부터 168시간 내 신청 가능 (주말/공휴일 제외)
- 쿠팡 고객센터 1577-7011로 문의하여 상태 확인 가능

### 【问题案例4】택배사 배송 지연으로 판매자 점수 0점 됨
**场景描述**：셀러가 정시 발송을 했으나 택배사 배송 지연으로 인해 판매자 점수 배송 부분이 0점으로 하락. 쿠팡의 판매자 점수 패널티 적용으로 불이익을 받음.
**问题分析**：쿠팡의 판매자 점수 시스템이 배송 도착일 기준으로 판매자를 패널티 처리. 택배사의 사정으로 인한 지연도 판매자에게 불이익.
**解决方案**：
1. 쿠팡 윙에서 해당 배송 건의 상세 정보 확인 (정시 발송 기록 캡처)
2. 판매자 점수 제외 요청 경로로 온라인 문의: https://helpseller.coupang.com/hc/ko/requests/new?ticket_form_id=360000545712
3. 주문번호, 박스ID(묶음배송번호) 및 정시발송 캡처 첨부
4. '판매자점수 제외 - 정시배송완료' 유형으로 문의
5. 처리 결과 확인 (답변 도착 시 확인)
**关键要点**：
- 판매자 점수 제외 요청은 정시 발송 증거(캡처)가 필수
- 배송 지연이 택배사 사정이더라도, 셀러가 직접 소명 요청해야 함
- 쿠팡 셀러센터 온라인 문의를 적극 활용할 것 (월 10~20회 활용 권장)

### 【问题案例5】로켓그로스 보관료 폭탄 - 재고 회전 관리 실패
**场景描述**：잡화 판매 셀러가 로켓그로스로 운영 중, 재고 회전이 느려 무료 보관 기간(약 30일) 이후 보관료가 발생. 월 평균 보관비 96,000원 발생하여 마진 압박.
**问题分析**：2025년 1월 쿠팡 로켓그로스 물류 비용 개편으로 무료 보관 기간이 기존 60일에서 약 30일로 단축. 재고 회전이 느린 상품은 보관료가 이익을 잡아먹음.
**解决方案**：
1. SKU 최적화: 5종 상품에 집중하여 관리 효율성 높임
2. 재고 소진 주기 분석 → 평균 회전일수 28일 이내로 맞춤 관리
3. 쿠팡 윙의 재고 알림 기능 활용: 설정 수량 이하로 내려가면 자동 알림
4. Google Sheets + 쿠팡 API 활용한 실시간 재고 모니터링 (ERP 연동)
5. 프로모션 기간 동안 재고 최대한 소진하여 물류비 절감
**关键要点**：
- 로켓그로스 보관료: 일 25~50원/CBM, 무료 보관 기간 약 30일
- 재고 회전이 느린 상품은 보관료가 마진을 잡아먹음 → 저마진 상품은 로켓그로스 피할 것
- 매월 셀러센터 정산 내역 꼼꼼히 검토하여 이상 징후 빠르게 파악
**原文链接**：[https://returneeds.com/blog/online-seller-guide/쿠팡-셀러-필독-2025-쿠팡-로켓그로스-요금제-개편-정보/](https://returneeds.com/blog/online-seller-guide/%EC%BF%A0%ED%8C%A1-%EC%85%80%EB%9F%AC-%ED%95%84%EB%8F%85-2025-%EC%BF%A0%ED%8C%A1-%EB%A1%9C%EC%BC%93%EA%B7%B8%EB%A1%9C%EC%8A%A4-%EC%9A%94%EA%B8%88%EC%A0%9C-%EA%B0%9C%ED%8E%B8-%EC%A0%95%EB%B3%B4/)

### 【问题案例6】쿠팡 자동 광고 키워드 오매칭으로 월 1900만원 손해
**场景描述**：한 셀러가 쿠팡 AI 자동 광고를 의존하여 운영 중, '구두' 상품에 '운동화' 키워드가 매칭되고 '셔츠'에 '맨투맨'이 매칭되는 등 불필요한 키워드로 광고비가 낭비됨.
**问题分析**：쿠팡은 수동 광고를 제외하고는 별도로 키워드 제외를 해야 함. AI가 자동으로 추가한 키워드 중 상품과 관련 없는 키워드가 많음. 한 셀러는 최대 1,900만원까지 손해를 봄.
**解决方案**：
1. 쿠팡 광고 관리자 → 키워드 리포트에서 자동 캠페인의 키워드 확인
2. 클릭 수 많지만 전환율이 낮은 키워드(CTR 높고 CVR 낮은) 선별
3. ROAS 100% 이하 키워드 제외 고려 (광고비만 소진)
4. 경쟁사 브랜드 키워드(닥터자르트, 설화수 등) 제외
5. 자동 캠페인 → 수동 캠페인으로 전환 후 제외 키워드 직접 설정
**关键要点**：
- 쿠팡 자동 광고는 반드시 키워드 제외 관리가 필요함 (수동 광고 제외)
- ROAS 100% 이하, 전환율 1% 미만 키워드는 제외 필수
- 너무 많은 키워드 제외 시 트래픽 감소 → 유사 키워드로 보완 테스트

### 【运营技巧】쿠팡 상품명/상세페이지 최적화로 초기 노출 확보
**适用场景**：쿠팡 입점 초기, 리뷰가 0개일 때 검색 상위 노출을 노리는 셀러
**具体操作**：
1. 상품명에 핵심 키워드 2~3개 반드시 포함
   - 잘못된 예: "따뜻한 겨울 기모 후드"
   - 잘 되는 예: "[국내생산/무료배송] 남녀공용 오버핏 기모 후드티 / 빅사이즈 겨울 필수템"
2. 대표 이미지에 '특징 문구' 1줄 넣기 (예: [국내생산], [무료배송], [당일발송])
3. 쿠팡 검색 알고리즘 최적화: 상품명 키워드 + 판매량 + 리뷰 수·점수 + 배송 속도
4. 모바일 최적화 (80% 모바일 접속): 세로 스크롤 기반, 핵심 정보 상단 배치
5. 후기 요청: 자동발송 시스템 이용 또는 포장 내 메시지 삽입 (구매 후 14일 후 자동 리뷰 요청 알림)
6. 초기 판매는 마진보다 '리뷰 확보'에 집중 (리뷰 30개 미만이면 구매 전환율 2% 이하)
**效果预期**：
- 검색 상위 노출 확률 상승
- 1~2건 판매 후 자동으로 검색 상위권 진입 가능
- 리뷰 30~50개 확보 시 전환율 2~3배 상승
**注意事项**：
- 썸네일에 '무료배송', '최저가', '한정판매' 등 마케팅 문구 넣으면 광고 승인 거부됨 (주의)
- 건강기능식품 카테고리에서 '치료', '효능' 등 의료 관련 키워드 사용 시 계정 제재 가능
- 식품은 맛 리뷰 사진이, 뷰티는 사용 전후 비교 사진이 특히 효과적

### 【今日总结】
- **核心洞察1**: 쿠팡은 판매자에게 불리한 구조적 문제가 많음 (보장환불, 판매자 점수, 반품 비용). 셀러가 직접 소명 요청과 보상 신청을 주기적으로 관리해야 함. '자동으로 처리될 것'이라는 기대는 금물.
- **核心洞察2**: 로켓그로스의 무료 보관 기간이 60일→30일로 단축되었고, 반품 회수비/재입고비 신설됨. 저마진·대형 상품은 로켓그로스보다 마켓플레이스(직접 배송)가 유리할 수 있음. 상품 특성별 유연한 전략 필요.
- **核心洞察3**: 광고 키워드 최적화는 매일 ROAS/CPC/전환율 확인이 필수. 쿠팡 AI 자동 광고에 의존하면 상품과 무관한 키워드로 광고비가 낭비됨. 수동 캠페인으로 전환 후 제외 키워드 체계적으로 관리해야 함.
- **实操建议**: 
  1. 오늘 바로 쿠팡 광고 관리자에 접속하여 키워드 리포트에서 ROAS 100% 이하 키워드 10개 제외할 것
  2. 반품 관리 화면에서 미입고 상태인 보장환불 건이 있는지 확인, 처리완료일 5영업일 후 보상 신청 기간 놓치지 않게 캘린더에 등록
  3. 로켓그로스 운영 중인 상품의 재고 회전일수를 계산하여 30일 초과 상품은 할인 프로모션 진행으로 보관료 절감
