### 【问题案例1】쿠팡(酷澎) 保障退款(보장환불)政策导致卖家双重损失

**场景描述**：
客户提交退货申请后并未将商品退回，但酷澎(Coupang/쿠팡)在60小时后自动执行"保障退款(보장환불)"政策，导致卖家同时失去货物和钱款。特别是客户因变心而不想退货、但未取消退货申请的情况十分常见。

**问题分析**：
- 酷澎(쿠팡)为追求客户满意度，无论是否实际回收商品，60小时后自动退款
- 卖家既无法回收商品，又无法收回退款，产生双重损失
- 客户变心后不想退货、但未取消退货申请的情况频发

**解决方案**：
1. 致电酷澎(쿠팡)客服中心(1600-9879)获取收货人/订购人真实号码
   - 路径：输入企业代码 → 1号(마켓플레이스/市集平台咨询) → 2号(안심번호/安全号码咨询) → 1号(同意使用个人信息) → 输入订单号# → 1号/2号(号码指引)
2. 直接与客户通话，引导取消退货或提供商品回收地址
3. 申请回收支持：订单/配送 → 退货管理 → 入库运单号 → 注册回收运单 → 在留言板申请回收支持
4. 3次回收失败后，酷澎(쿠팡)方会自动进行重新结算(정산)（但需在处理完成日基准营业日第5日起的168小时/7日内在线申请补偿）

**关键要点**：
- 补偿申请期限：处理完成日基准营业日第5日起168小时(7日)内可申请
- 安全号码(안심번호)会被废弃，因此退货问题发生时需立即联系客服
- 申请回收支持后仍回收失败时，酷澎(쿠팡)会重新结算处理

### 【问题案例2】酷澎(쿠팡) 职权退款(직권환불)处理导致卖家在不知情的情况下批量退货

**场景描述**：
卖家未直接处理的数十件退货被酷澎(쿠팡)以职权退款(직권환불)方式处理，卖家事后才得知。

**问题分析**：
- 2021年3月起，酷澎(쿠팡)实施新政策：卖家责任退货受理后，若营业日4天内退货商品未被回收，则自动进行职权退款批准处理
- 未向卖家提供职权退款的单独通知
- 退款完成后与客户失联，退货回收变得更加困难

**解决方案**：
1. 养成每天定期检查退货记录的习惯
2. 对职权退款有异议时，向酷澎(쿠팡)纠纷调解中心申请
3. 强化退货回收物流追踪：退货受理后立即确认回收日程并联系快递公司
4. 建立退货管理SOP：构建24小时内响应通知的体系

**关键要点**：
- 酷澎(쿠팡)与其他开放市集(오픈마켓)不同，卖家无法在回收商品并确认物品后暂停退款处理
- 职权退款处理后，商品回收情况仍需卖家自行追踪
- 若担心异议申请后搜索曝光排名下降等不利影响，需采取战略性应对

### 【问题案例3】火箭成长(로켓그로스/Rocket Growth)初期过量入库导致500万韩元损失

**场景描述**：
制造商误解"库存多才能成为畅销品(베스트셀러)"，将月预计销量100件的3倍即300件作为初期入库量，但实际销量仅月100件，导致保管费(보관비)累积 + 临近保质期商品报废处理，共损失500万韩元。

**问题分析**：
- 对初期入库量抱有过高期待，且不熟悉物流费用结构
- 火箭成长(로켓그로스)保管费：按类别免费保管期后，每日25~50韩元/CBM收取
- 保质期剩余70%以下的商品会被拒绝入库或产生反送费(반송비)（每件2,000韩元以上）由卖家承担

**解决方案**：
1. 初期入库保守化：仅入库约2周份数量
2. 观察销售趋势后逐步扩大入库量
3. 广告费(광고비)保障优先于库存保障
4. 基于周报告(주간 리포트)定期检查库存
5. 保质期管理：入库时确保保质期70%以上，应用FIFO(선입선출/先进先出)原则

**关键要点**：
- 火箭成长(로켓그로스)免费保管期：饰品/服装/鞋类45日，其他类别30日
- 过量库存同时产生：保管费负担 + 品质下降（保质期） + 算法曝光下降（缺货担忧时）
- 活用先结算(선정산)方式，并行管理库存保障与运营资金

### 【问题案例4】酷澎(쿠팡) 广告缩略图(썸네일)政策违规导致广告审批被拒及账号处罚(페널티)

**场景描述**：
在缩略图(썸네일)中插入"免费配送(무료배송)"、"最低价(최저가)"、"限量销售(한정판매)"等营销文案，导致广告审批被拒，严重时账号受到曝光限制或广告费不可退款的处罚(페널티)。

**问题分析**：
- 2025年起酷澎(쿠팡)强化缩略图(썸네일)政策：必须白色背景、全面禁止插入logo/营销文案
- 政策未遵守时，账号曝光限制、广告费不可退款等处罚(페널티)强化
- 使用医疗相关关键词（"治疗(치료)"、"功效(효능)"等）时，在健康功能食品类别中可能导致账号制裁

**解决方案**：
1. 缩略图(썸네일)制作检查清单：
   - 确认必须白色背景
   - 删除"免费配送(무료배송)"、"最低价(최저가)"、"限量销售(한정판매)"、"第一名(1등)"等营销文案
   - 遵守禁止插入logo规定
2. 医疗/健康类别关键词审查：
   - 删除"治疗(치료)"、"功效(효능)"、"治愈(완치)"等医疗相关表达
   - 替代表达："效果改善经验"、"可期待的效果"、"满意度保障"
3. 运营广告注册前3阶段审查系统（图片政策 → 标注事项 → 关键词优化）
4. 账号受制裁时立即准备申诉资料并咨询酷澎(쿠팡)合作伙伴中心

**关键要点**：
- 缩略图(썸네일)规格：1000×1000像素以上（2025年起上调）
- 存在个人事业者因设置医疗相关关键词广告而被禁止3个月广告投放、销售额下降70%的案例
- 账号处罚(페널티)记录恢复可能需要数月

### 【问题案例5】酷澎(쿠팡) 退货处理时理由分类失误导致额外负担配送费6,000韩元

**场景描述**：
将单纯变心退货错误处理为"商品不良/误配送(하자/오배송)"，导致本不应由本人承担的约6,000韩元退货运费由卖家负担。

**问题分析**：
- 酷澎(쿠팡)退货理由5种：单纯变心、不良、误配送、广告不符、自助退款(셀프 환불)
- 单纯变心：往返退货运费约6,000韩元由消费者负担（WOW会员免费）
- 不良/误配送：往返退货运费约6,000韩元由卖家(셀러)负担
- 理由分类漏掉一行即刻产生费用

**解决方案**：
1. 将退货受理时5种理由映射表固定到自有SOP中并运营检查清单
2. 明确化单纯变心 vs 不良判断标准：
   - 单纯变心：客户表达"不喜欢"、"颜色/尺寸不满"等
   - 不良：仅产品缺陷、误配送、与广告不符的情况归类为不良
3. 检验照片/视频保管6个月以上，确保"客户责任损坏"的举证资料
4. 确认请求可能次数·期限以酷澎Wing(쿠팡 윙)画面为准每次确认，资料一次性收集提交

**关键要点**：
- 退货通知放置24小时以上时，会以自助退款(셀프 환불)方式立即扣减结算，导致损失累积
- 同一SKU退货率超过月平均（3~5%以上）时，优先检查广告文案、选项标注、包装状态
- 拒绝不良退货的尝试很可能导致消费者院举报 → 迅速退款 + 修改商品页面更安全

### 【问题案例6】依赖自动广告导致月300万韩元广告费消耗且ROAS 80%损失

**场景描述**：
卖家仅依赖AI自动广告，月投入300万韩元，但ROAS仅80%，导致只有广告费支出没有收益。

**问题分析**：
- 2025年起AI基础自动关键词优化比重扩大，但无效关键词管理疏忽时仅消耗广告费
- "免费(무료)"、"样品(샘플)"等购买意图低的关键词浪费广告费
- 品牌关键词(브랜드 키워드)与一般关键词未分离运营，导致竞价价格(입찰가)效率低下
- 关键词重复设置导致内部竞争（竞价价格上升 + 效率下降）

**解决方案**：
1. 转换为手动广告活动后设置排除无效关键词：
   - 酷澎(쿠팡)广告管理器 → 关键词报告中确认点击多但转化率0%的关键词
   - 排除ROAS 100%以下的关键词
   - 排除竞争对手品牌关键词
2. 品牌关键词(브랜드 키워드)与一般关键词分离运营：
   - 品牌关键词：低竞价价格即可（已认知的客户）
   - 一般关键词：设定适当竞价价格
3. 时间段预算分配：
   - 下午6点~9点黄金时段：相比平时150%预算分配
   - 凌晨时段：调整至50%水平
4. 预算逆算公式：ROAS 300%目标时，按预计销售额的33%水平制定广告预算

**关键要点**：
- 初期2周专注数据收集，之后开始优化
- 仅关键词排除设置即可节约30%广告费
- CPC管理在售价10%以下为稳定（利润率30%基准）
- 黄金时段预算集中可使ROAS平均提升30~40%

### 【运营技巧】酷澎(쿠팡) 详情页SEO优化使转化率提升2.3倍

**适用场景**：
商品注册后搜索不曝光，或曝光但点击后购买转化率低的情况。

**具体操作**：
1. 产品名优化（最多100字）：
   ```
   [品牌(브랜드)] + [类别核心关键词] + [主要特点] + [规格/数量]
   例："OOO 胶原蛋白透明质酸精华 30ml 干性皮肤保湿安瓶"
   ```
2. 删除重复关键词：
   - 差示例："办公室加湿器 充电式加湿器 桌面加湿器"
   - 好示例："办公室桌面充电式加湿器"
3. 标签(태그) 20个全设置：
   - 用产品名中没有的词、可能搜索的词填满20格
   - 抢占客户处境或需要情境下搜索的心理关键词
   - 但必须与商品有关联（错误商品曝光时跳出率上升）
4. 构成以规格为中心的要点(bullet point) 3~5个：
   - 含量：透明质酸 1,000ppm
   - 尺寸：30ml
   - 皮肤类型：干性、复合性
   - 认证：皮肤科测试完成
5. 移动端优化：减少滚动负担，核心信息置顶
6. 明确说明使用方法，防止因误解导致的1星评价

**效果预期**：
- 详情页品质分数高的商品：转化率平均高2.3倍，退货率低35%，评价撰写率高40%
- 搜索曝光增加58%（标签优化时）
- 存在类别排名47位 → 3位上升案例（2个月内）

**注意事项**：
- 避免关键词堆砌(stuffing)：酷澎(쿠팡) AI将不自然的关键词滥用识别为垃圾信息导致排名下降
- 禁语注意："最高"、"第一"、"完美" → 替代表达："高满意度"、"销售上位"、"细致的"
- 虚假认证标志使用时立即屏蔽(blind) + 账号制裁

韩国电商领域的基础性法律，明确规定此前相关法律法规同样适用于电子商务市场监管。

**核心条款：**

- **退货费用承担**：

  - 商品与广告不符/瑕疵 → 经营者承担运费

#### 2. 2026年KFTC电商法实施细则修订（2026年7月21日生效）

1. **国内代理人义务**：无韩国地址的海外经营者需指定国内代理人（2027年2月21日生效）

   - 必须公开删除评价标准及申诉程序

### 三、税务条款详解

#### 1. 增值税 (VAT / 부가가치세)

**标准税率：10%**

| 纳税人类型 | 条件 | 税率 | 申报频率 |
|-----------|------|------|---------|
| **一般纳税人(일반과세자)** | 年营业额 > 8000万韩元 | 10% | 半年申报（7月25日、次年1月25日） |
| **简易纳税人(간이과세자)** | 年营业额 < 8000万韩元 | 1.5%-4%（按行业） | 年度申报 |
| **免税经营者(면세사업자)** | 年营业额 < 4800万韩元 | 免征 | 无需申报 |

- 开业后 **20天内** 必须向税务局登记

- 电子发票未开具或未上报罚款：供货价格的 **1%**

**跨境服务VAT：**
- 向韩国境外企业提供服务 → **零税率(0%)**
- 外国企业向韩国消费者提供数字服务 → 需简化VAT登记并缴纳
