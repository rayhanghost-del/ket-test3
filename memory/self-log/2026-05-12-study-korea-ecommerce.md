## 二、Coupang 入驻与运营要点

### 入驻条件（国际卖家）
1. **企业资质**：中国大陆/港/澳/台注册的企业营业执照（有效期≥1个月）
2. **法人身份**：护照或身份证（剩余有效期≥3个月），需手持证件自拍照
3. **银行账户**：开户证明/账户清单/开户许可证，推荐 PingPong/Payoneer 虚拟账号
4. **联系方式**：近6个月内话费账单（显示法人或公司名称）
5. **其他**：其他跨境平台近6个月交易流水（加分项）

### 费用结构
| 项目 | 比例/金额 | 备注 |
|------|-----------|------|
| 平台佣金 | 5%–10% | 按品类：电子数码5%，服装10%，化妆品9%，游戏6% |
| 物流仓储 | ~20% | 头程+仓储+尾程；配饰类12%–15%；新入驻30天免仓储 |
| 关税 | ~10% | 进口关税，根据HS编码不同 |
| 广告投流 | ~10% | 平稳期比例，新品期可能更高 |
| 退货亏损 | ~5% | 韩国消费者退货意识强 |
| **综合毛利率** | **45%–60%** | 优质商品可达60% |

### 选品参考（中国卖家优势品类）
- **女装**：本土占比49%，中国卖家仅占8.7%，客单价150–300人民币，退货率4%–5%
- **箱包**：中国卖家销售额占比高，旅行箱包单链接单日最高15万美金
- **配饰**：白牌为主，产业带优势明显（如旭平珠宝），成本20–30元，售价可达82万/天

### 物流模式
1. **自配送**：卖家自行处理，时效3–7天为佳
2. **Coupang Rocket仓**：备货至韩国官方仓，享受Rocket Delivery标识，流量加权
3. **第三方海外仓**：灵活，但无平台流量加权

> ⚠️ 注意：Coupang对物流时效要求极高， listing上需注明预计配送时间。

## 三、韩国电商法律法规

### 核心法律框架
| 法律 | 核心内容 | 对卖家的影响 |
|------|----------|--------------|
| **《电子商务基本法》** (2007年颁布，多次修订) | 电子合同效力、交易记录保存≥5年、7天无理由退货、信息透明度 | 必须提供完整产品信息，保留交易记录 |
| **《个人信息保护法》(PIPA)** | 明确同意原则、最小化收集、数据加密与安全、泄露追责 | 收集用户信息前须明示目的并获同意 |
| **《公平标签和广告法》** | 禁止虚假、夸大、欺骗性、诽谤性广告 | 产品描述必须真实，不得使用误导性用语 |
| **《消费者框架法》** | 消费者纠纷解决、退货权利保障 | 必须配合消费者退货/退款请求 |
| **《电子金融交易法》** | 电子支付安全、可靠性 | 需确保支付系统安全 |
| **《垄断规制和公平交易法》** | 竞争和公平交易 | 不得参与价格操纵、排他性协议 |

### 跨境直购新规（2024年5月16日发布）
韩国发布"加强消费者安全和提高企业竞争力方案"，重点包括：

1. **KC认证强制要求**
   - 禁止海外直购未获KC认证的：34种儿童用品、34种电器/家用产品、12种日用化学品
   - 禁止含有害成分的化妆品、卫生用品、首饰
   - 电子产品必须有安全认证（KC标志）

2. **平台监管加强**
   - AI大数据监测海外平台
   - 要求海外平台指定**韩国国内代理人**，负责消费者损害救济
   - 未获KC认证产品将被删除销售信息

3. **个人信息保护审查**
   - 调查APP权限告知是否合规
   - 违反《个人信息保护法》将面临处罚

4. **免税与通关制度改革**
   - 考虑修订小额进口免税制度（原150美元以下免征政策已收紧）
   - 2021年7月起，**所有进口商品统一征收10%增值税**，取消免税门槛
   - 2026年将建立算法优化的危险品通关平台

> ⚠️ 关键结论：做韩国电商，**KC认证是硬门槛**，特别是儿童用品、电器、化妆品类目。没有认证，商品可能被强制下架，甚至面临平台封禁。

### 七天无理由退货
- 消费者收到商品后7日内可无理由退货
- 商家不得以任何格式条款限制此权利
- 退货流程需快速响应，否则影响店铺评分

## 四、韩国电商税务条款

### 1. 增值税（VAT）— 10%
- **标准税率**：10%，适用于绝大多数商品和服务
- **进口环节**：进口增值税 = (CIF价 + 关税) × 10%
- **销售环节**：售价通常含税，平台**不代扣代缴**，卖家自行申报缴纳
- **申报周期**：季度申报（小微企业可按季度）
- **抵扣机制**：进口环节缴纳的增值税可在销售环节抵扣（流转税性质）

> ⚠️ **重要**：韩国进口货物**不建议走双清包税**。包税清关时不会使用卖家公司抬头，缴纳的增值税无法在后续销售环节抵扣。韩国税务监管严格，货款和清关成本必须一致。

### 2. 进口关税
- 根据商品HS编码分类，税率各不相同
- 关税属于成本，**不可抵扣**
- 部分商品可能适用零关税（特定国家/地区、特定品类）

### 3. 企业所得税（法人税）
- 韩国注册公司需在税务局登记，获得税务识别号
- **税率分级**（2024–2025参考）：
  | 利润区间 | 税率 |
  |----------|------|
  | ≤ 2亿韩元（≈110万人民币） | 9% + 地方税0.9% = **9.9%** |
  | 2亿–200亿韩元 | **19.9%–22%** |
  | > 200亿韩元 | **25%** |
- 年度申报：次年4月前完成
- 实地经营公司需每月/每年提交财务报表

### 4. 跨境电商个人直购税政（韩国境内消费者角度）
- 2021年7月起，**所有海外网购商品统一征收10%增值税**
- 原150美元以下免征政策已取消
- 超过15万韩元（约110美元）的海外网购商品必征VAT

### 5. 公司注册形式建议
- **株式会社（주식회사）**：类似股份有限公司，适合中大型企业，最少2人+1监事，可发行股票
- **有限会社（유한회사）**：类似有限责任公司，适合中小企业
- 离岸公司（无实地经营）：不需交税，但需年审

## 六、学习感悟

1. **KC认证是生死线**：2024年新规后，儿童用品、电器、化妆品等类目若无KC认证，根本无法上架。这比税务合规更前置。

2. **VAT抵扣是利润关键**：不走包税、用公司抬头清关，虽然前期现金流压力大，但长期看能拿回10%的VAT抵扣，这是不小的利润空间。

3. **Coupang的 Rocket Delivery 是流量密码**：入仓意味着更高的曝光和转化率，但库存周转风险也大。选品阶段就要考虑是否适合备货到韩国。

4. **语言门槛真实存在**：Naver和Coupang的运营后台、客服、Listing优化都需要韩语。招聘韩语TOPIK-5以上的运营是刚需，不是加分项。

5. **韩国消费者退货率高**：退货亏损预算5%是行业经验值，女装类甚至更高。选品时要把退货成本算进定价模型。
