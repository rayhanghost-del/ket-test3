## 二、法律法规体系

### 核心法律框架

#### 1. 《电子商务消费者保护法》(1999年)
韩国电商领域的基础性法律，明确规定此前相关法律法规同样适用于电子商务市场监管。

**核心条款：**
- **7天无理由退货**：消费者收到商品后7天内可取消订单或退货
- **虚假宣传扩展退货期**：商品与广告不符时，收到商品后3个月内、发现之日起30天内可退货
- **退货费用承担**：
  - 消费者单纯改变心意 → 消费者承担往返运费
  - 商品与广告不符/瑕疵 → 经营者承担运费
- **海外代购特殊规定**：消费者单纯改变心意退货时，退货费最高可达商品价格的40%

#### 2. 2026年KFTC电商法实施细则修订（2026年7月21日生效）
韩国公平交易委员会(KFTC/FTC)推动的重大改革：

**四大类11种不公平条款整改：**
1. **国内代理人义务**：无韩国地址的海外经营者需指定国内代理人（2027年2月21日生效）
2. **消费者评价透明度**：
   - 必须公开评价发布权限和保留期限
   - 必须公开评分标准和各等级对应效果
   - 必须公开删除评价标准及申诉程序
3. **C2C卖家身份验证简化**：个人卖家只需验证电话号码和邮箱（此前需姓名、出生日期、地址等）
4. **加重处罚**：
   - 重复违规罚款最高增加50%，第四次违规增加100%
   - 自愿整改的罚款减免从30%降至10%

#### 3. 2026年4月FTC对七大平台的整改要求
针对 **Coupang、Naver、Kurly、SSG.com、Gmarket、11Street、Nol Universe** 的不公平条款：
- Coupang禁止用户注销账户后退还预付Coupay Money余额的问题
- 影响超过 **3360万个** 用户账户

#### 4. 平台运营合规要点
- **必须提供有效联系电话**（韩国法律强制要求）
- **电子发票(전자세금계산서)强制要求**：所有B2B交易必须通过HomeTax系统开具
- **禁止虚假评论**：2024年7月起实施"虚假评论打击计划"，违规将面临扣分或封店
- **产品安全认证**：部分商品需KC认证
- **标签要求**：中文/韩文标签

## 三、税务条款详解

### 1. 增值税 (VAT / 부가가치세)

**标准税率：10%**

| 纳税人类型 | 条件 | 税率 | 申报频率 |
|-----------|------|------|---------|
| **一般纳税人** | 年营业额 > 8000万韩元 | 10% | 半年申报（7月25日、次年1月25日） |
| **简易纳税人** | 年营业额 < 8000万韩元 | 1.5%-4%（按行业） | 年度申报 |
| **免税经营者** | 年营业额 < 4800万韩元 | 免征 | 无需申报 |

**关键规定：**
- 开业后 **20天内** 必须向税务局登记
- 未登记罚款：商品/服务价值的 **1%**
- 电子发票未开具或未上报罚款：供货价格的 **1%**
- 延迟上报（超过次月10日/7月10日）：供货价格的 **0.5%**

**跨境服务VAT：**
- 向韩国境外企业提供服务 → **零税率(0%)**
- 外国企业向韩国消费者提供数字服务 → 需简化VAT登记并缴纳
- 通过电商平台向韩国消费者销售 → 平台方需代为注册和缴纳VAT

### 2. 企业所得税 (CIT / 법인세)

**阶梯税率（2026年）：**

| 利润区间 | 税率 |
|---------|------|
| ≤ 2亿韩元 | 11% |
| 2亿 - 200亿韩元 | 递进税率 |
| 200亿 - 3000亿韩元 | 递进税率 |
| > 3000亿韩元 | 27.5% |

- 申报截止：财政年度结束后 **3个月内**（12月31日结束财年→次年3月底前）
- 大型企业需提交审计报告

### 3. 个人所得税 (PIT / 소득세)

**2026年阶梯税率：**

| 应纳税所得额 | 税率 | 含地方税合计 |
|------------|------|-------------|
| ≤ 1400万韩元 | 6% | 6.6% |
| 1400万 - 5000万韩元 | 15% | 16.5% |
| 5000万 - 8800万韩元 | 24% | 26.4% |
| 8800万 - 1.5亿韩元 | 35% | 38.5% |
| 1.5亿 - 3亿韩元 | 38% | 41.8% |
| 3亿 - 5亿韩元 | 40% | 44.0% |
| 5亿 - 10亿韩元 | 42% | 46.2% |
| > 10亿韩元 | 45% | 49.5% |

- 年度汇算：次年 **5月1日-5月31日**
- 居民标准：在韩国居住满 **183天** 或在韩国有住所

### 4. 进口环节税

| 税种 | 税率 | 说明 |
|------|------|------|
| **关税** | 0% - 30% | 按HS编码确定，平均约8% |
| **进口增值税** | 10% | 关税 + CIF价格的10% |
| **免税门槛** | - | 商品+运费 < 10万韩元免征进口税 |

**可抵扣机制：**
- 进口增值税可作为"输入增值税"在季度申报中抵扣或退还

### 5. 其他重要税种

| 税种 | 税率 | 适用对象 |
|------|------|---------|
| **个别消费税** | 10% - 90韩元/升 | 特定商品（石油、烟草、豪华消费品等） |
| **教育税** | 30%（消费税附加） | 2026年1月1日起金融保险业税率上调 |
| **财产税** | 0.07% - 5% | 土地、建筑物、房屋、船舶、飞机 |
| **综合房地产税** | 0.5% - 5% | 超额持有的土地和住宅 |
| **证券交易税** | 0.15% - 0.35% | 2026年KOSPI/KOSDAQ税率升至0.20% |

### 6. 中小企业税收优惠

- 年度电商交易量的 **0.5%** 减免税收收入
- 年营业额 < 8000万韩元 → 简易征税制度
- 年营业额 < 4800万韩元 → 增值税免税

### 7. 涉税犯罪处罚

| 违法行为 | 处罚 |
|---------|------|
| 一般偷漏税 | 2年以下有期徒刑或偷漏税额2倍以下罚款 |
| 偷漏税 ≥ 3亿韩元且 > 应纳税额30% 或 ≥ 5亿韩元 | 3年以下有期徒刑或偷漏税额3倍以下罚款 |
| 损毁/隐瞒账簿 | 2年以下有期徒刑或2000万韩元以下罚款 |
| 高额交易未开信用卡/现金收据（≥10万韩元） | 未开金额20%罚款 |

## 四、市场准入与合规要求

### 外国企业进入方式
1. **注册韩国公司** → 直接经营
2. **通过本地代理** → 税务登记和合规由代理处理
3. **跨境平台入驻** → 通过AliExpress、Temu等平台（需KYC审核）

### 必备认证与文件
- **原产地证明**
- **产品安全认证**（如KC认证，针对特定品类）
- **中文/韩文标签**
- **HS编码**（清关用）
- **发票和装箱单**

### 平台入驻要求（以Coupang为例）
- 禁止销售假冒/侵权产品（首次违规下架，第二次封店冻结资金）
- 禁止卖家直接联系CGF/CGF LITE买家
- 禁止自发货（必须使用平台物流）
- 禁止在包装中放入卖家联系方式
- 电池产品需提供有效MSDS & UN 38.8报告

### 物流与清关
- 韩国邮政2024年跨境包裹通关率 **96%**
- 平均清关时效 **3-5个工作日**
- 推荐物流：ePacket、DHL Global Mail、平台官方合作物流
- 跨境电商通关时间缩短至约 **16小时**

- **评价透明**：消费者对评价真实性高度敏感

## 六、2026年最新政策动态

1. **全球最低税(GloBE)**：韩国2022年立法，2026年6月首次申报
   - 适用于合并收入 ≥ 1万亿韩元（约7.5亿欧元）的跨国集团
   - 确保有效税率不低于 **15%**

2. **数字服务VAT强化**：
   - 2024年起：未简化登记的外国电子服务商罚款1%
   - 2025年7月起：非居民销售代理/中介需按季度提交月度交易报表

3. **教育税上调**：2026年1月1日起金融保险业教育税率上调

4. **证券交易税调整**：2026年1月1日起KOSPI/KOSDAQ税率从0.15%升至0.20%

5. **国家养老金费率上调**：2026年1月1日起从9%升至 **9.5%**

## 八、学习总结

### 核心要点
1. **合规优先**：韩国电商监管严格，7天无理由退货、电子发票、消费者评价透明度是硬性要求
2. **税务复杂**：VAT 10%是基础，但进口环节税、企业所得税、个人所得税需综合考虑
3. **平台选择**：本土平台（Coupang/Naver）流量大但竞争激烈；跨境平台（AliExpress/Temu）进入门槛低但利润空间有限
4. **本地化必要**：韩文标签、KC认证、本地客服/代理是长期经营的基础
5. **政策敏感**：2026-2027年是韩国电商监管密集调整期，需持续关注KFTC/FTC动态
