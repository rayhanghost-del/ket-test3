## 模块一：韩国电商实操日报（酷澎 Coupang 卖家运营）

### 案例1：卖家责任退货处理与批发平台退货流程

**场景描述**：新手卖家因商品尺寸表标注模糊，收到"卖家责任(판매자 귀책)"退货请求，需承担退货运费，情绪消耗大。

**问题分析**：商品说明存在歧义导致客户误购，属于卖家责任；初次处理时不清楚流程和判断标准，产生焦虑和拖延。

**解决方案**：
1. 确认退货原因，判断是否确实为卖家责任（商品描述不符/尺寸标注不清）
2. 登录酷澎卖家后台(Coupang Wing) → 在退货管理(반품관리)中确认该订单
3. 向供应商（批发采购平台 도매매）提交退货申请，退货理由选择"收到与商品描述不符的商品(판매 내용과 다른 상품 수령)"
4. 获取供应商提供的退货运单号，在酷澎退货管理中登记
5. 供应商快递上门取件并验收后，卖家获得退款，酷澎自动完成退货
6. 同时修改商品详情页(상세페이지)，补充实际测量尺寸图，防止再次发生

**关键要点**：
- 商品描述模糊时优先按卖家责任处理，避免纠纷升级
- 向供应商申请退货时，理由写"商品自身问题"而非"销售处误记"，通过率更高
- 处理完毕后务必修改商品页面，防止重复发生

### 案例2：快递公司(택배사)配送延误导致卖家评分(판매자 점수)突降为0分 — 恢复经验

**场景描述**：卖家一直维持100分卖家评分，某天配送分数突然变为0，发现是快递延误导致订单晚到一天。

**问题分析**：酷澎系统以预计到达日为基准计算配送分数，即使卖家按时发货，快递公司(택배사)延误也会被计入卖家责任，属于系统逻辑缺陷。

**解决方案**：
1. 打开相关订单详情，确认实际发货时间和快递公司配送记录
2. 截图保存发货凭证（快递揽收时间）
3. 访问 helpseller.coupang.com 申请卖家评分排除(판매자 점수 제외)
4. 选择"卖家评分排除 - 准时配送完成"表单
5. 填写订单号和包裹ID(묶음배송번호)，附上发货时间截图
6. 提交后等待处理（通常数日内恢复）

**关键要点**：
- 每月定期检查卖家评分(판매자 점수)异常波动
- 发货时保留所有时间戳截图作为申诉凭证
- 酷澎在线问询每月使用10~20次是常态，善用在线渠道节省时间

### 案例3：酷澎广告费浪费 — 未设置排除关键词(제외 키워드)导致最高损失1900万韩元

**场景描述**：自动广告中酷澎 AI 为"皮鞋(구두)"商品匹配了"运动鞋(운동화)"关键词，为"衬衫(셔츠)"匹配了"卫衣(맨투맨)"，导致大量无效点击。

**问题分析**：酷澎自动广告（AI智能广告 AI 스마트 광고、销售额优化广告 매출 최적화 광고）需要卖家主动设置排除关键词(제외 키워드)，否则AI会添加与商品无关的词汇，大量消耗广告费。

**解决方案**：
1. 登录酷澎广告管理 → 关键词报告(키워드 리포트)查看AI自动添加的关键词
2. 筛选与商品无关的关键词（如品牌名、品类错配词）
3. 将自动广告转换为手动广告活动(수동 캠페인)
4. 在手动广告中设置排除关键词(제외 키워드)：广告活动(광고 캠페인) → 添加关键词 → 排除关键词
5. 定期（建议每2周）检查新增的无关联关键词并排除
6. 重点关注点击率高(CTR)但转化率低(CVR)的词、广告投资回报率(ROAS) 100%以下的词

**关键要点**：
- 自动广告不是"开了就不管"，前3-5天必须做排除关键词(제외 키워드)清理
- 转换手动广告后，可以精细化控制关键词和出价
- 使用工具（如卖家工具 세이비）可以一键批量排除无效关键词，2周一次自动化

### 案例4：酷澎结算(정산)结构不明导致资金断流 — 提前结算(선정산)应对

**场景描述**：新手卖家发现酷澎销售后资金被锁定近两个月，广告费和进货费持续支出，现金流断裂。

**问题分析**：酷澎是以确认收货为基准的结算(구매확정 기준 정산)，即确认收货后次月23日才结算；从实际销售到拿到钱可能需要1个月以上，新手常因不了解此结构而陷入资金困境。

**解决方案**：
1. 理解结算(정산)周期：销售(판매) → 配送完成(배송완료) → 确认收货(구매확정) → 次月23日结算
2. 管理库存周转率(재고 회전율)：只入仓30日内可售完的库存，避免仓储费(보관요금)
3. 优化广告费(광고비)：暂停ROAS低的广告，集中预算到高效关键词
4. 考虑提前结算服务(선정산 서비스)：如Olla提前结算(올라선정산)，可在结算日前预支部分销售款
5. 运营初期预留2~3个月运营资金作为缓冲

**关键要点**：
- 酷澎手续费(수수료)不只是表面5~10%，加上支付手续费(결제수수료) 2.9%、增值税(부가세) 10%、物流费(물류비)，实际负担达13~18%
- 免费配送(무료배송)设置会额外加收3.3%配送手续费(배송 수수료)，新手容易忽略
- 月销售额超100万韩元加收月度服务费(월 서비스 이용료) 55,000韩元

### 案例5：火箭成长(로켓그로스)仓储费(보관료)暴增 — 按类目免费保管期未遵守

**场景描述**：2025年1月起酷澎火箭成长(로켓그로스)费用体系变更，部分卖家因不了解按类目免费保管期(카테고리별 무료 보관 기간)差异，产生意外仓储费(보관비)。

**问题分析**：仓储费(보관비)按滞留天数(체류일)阶梯收费，且不同类目免费保管期不同（配饰/服装/鞋类(악세서리/의류/신발) 45日，其他30日），超期后费用递增。大件商品或滞销品会产生巨额仓储费。

**解决方案**：
1. 入仓前查询商品所属类目的免费保管期(무료 보관 기간)
2. 基于30日/45日销售预测精确控制入仓数量
3. 使用自动化表格(자동화 시트)设定自动补货和预警
4. 每月监控库存周转率(재고 회전율)，对60日以上未动销商品考虑出库(반출)或降价清仓
5. 利用仓储费促销期间（至2026.1.31）所有类目60日免费的政策窗口

**关键要点**：
- 入库拒绝(입고 거절) TOP5原因：条形码未贴/不合格(바코드 미부착/불량)、包装规格不符(포장 규격 미준수)、保质期剩余不足70%(유통기한 잔여 70% 미만)、数量不符(수량 불일치)、标签错误(라벨 오류) — 拒绝后反送费每单2,000韩元+由卖家承担
- 仓储费(보관료)每日25~50韩元/CBM，看似小额但积少成多，滞销品会直接吞噬利润
- 使用少量多频次(소량 다회전)入仓策略最安全

### 案例6：客户应对(고객 응대)延迟 → 差评(부정 리뷰) → 卖家评分下降 → 销售额减少的恶性循环

**场景描述**：1人卖家因客服响应慢，客户不满直接留差评，导致卖家评分(판매자 점수)下降、搜索排名下滑、新客流失。

**问题分析**：酷澎将客服响应速度(CS응대 속도)和不满率(불만율)直接反映在卖家评分中，而评分又决定排名展示(상위노출)。客服不是"附加工作"而是核心运营策略。

**解决方案**：
1. 建立FAQ模板库：将配送、退换货、尺寸等20个核心问题整理为标准回复模板
2. 在商品详情页(상세페이지)提前植入预防信息："平均配送需3~5日(평균 배송 3~5일 소요)"、"洗涤时可能缩水(세탁 시 수축 가능성)"等
3. 对好评(긍정 리뷰)及时感谢回复，对差评(부정 리뷰)诚恳解释并提供解决方案
4. 使用综合客服系统(통합 CS 시스템)（如Celmate(셀메이트)、Sabangnet(사방넷)、PlayAuto(플레이오토)）集中管理多渠道咨询
5. 设置自动回复消息(자동 응답 메시지)，对常见问题秒回，复杂问题承诺24小时内回复
6. 对持续骚扰的恶意客户，向平台申请注册妨碍销售客户(판매방해 고객 등록)

**关键要点**：
- 情绪化客户优先用文字/留言渠道回复（便于留痕），避免电话口角
- 回复保持简短、信息导向，不掺杂情绪表达
- 预留销售额的1~5%作为退货预备费(반품 대비 예비비)

### 运营技巧：广告预算集中投资时机 — "新品5~7日黄金时间(신상품 5~7일 골든타임)"

**适用场景**：新品上架初期、季节性商品旺季前、大促活动前

**具体操作**：
1. 商品注册(등록)后5~7日内集中投入广告预算（新鲜度评分(최신성 점수)期间搜索排名自然偏高）
2. 每日18:00~21:00为转化黄金时段，将50%以上日预算配置于此时间段
3. 广告活动(광고 캠페인)分组：按商品(상품별)、按时段(시간대별)细分出价，非高峰时段降低出价
4. 新品期预算建议每日3~5万韩元起步，ROAS达到300%以上再考虑增额
5. 季节性/活动季(계절성/이벤트 시즌)（春节(설날)、中秋(추석)、圣诞(크리스마스)）前2周增额40~60%

**注意事项**：
- 必须先完成商品详情页(상세페이지)、评价30+个、竞争力价格后再开广告
- 广告缩略图(광고 썸네일)必须是白色背景(흰색 배경)，不可出现"免费配送(무료배송)""最低价(최저가)"等字样（2026年新政策）

### 今日核心洞察

1. **酷澎是算法平台，不是"入驻就能卖"** — 卖家评分(판매자 점수)、评价数、广告效率、库存周转率(재고 회전율)全部互相影响，一处疏忽会连锁拉低整体。1人卖家必须把客服、退货、库存当成核心KPI管理。
2. **费用结构比表面佣金复杂得多** — 表面5~10%，实际含支付手续费(결제수수료)、增值税(부가세)、免费配送(무료배송) 3.3%、月度服务费(월 서비스료)、物流费(물류비)、仓储费(보관료)后可达13~18%。入仓前必须做反向定价(역산 가격 책정)。
3. **AI自动广告是双刃剑** — 不管理排除关键词(제외 키워드)的话，AI会乱配词，烧钱无转化。前3-5天的关键词清理决定后续广告效率，2周一次巡检是底线。

## 模块二：韩国电商市场与合规知识

### 市场概况
- **市场规模**：2026年预计突破1200亿美元，全球第五大电商市场
- **电商渗透率**：超过发达国家水平，增势迅猛
- **中国卖家占比**：超38%（主要优势品类：美妆、3C、服饰、家居）

### 主流平台

| 平台 | 地位 | 关键信息 |
|------|------|----------|
| **酷澎(Coupang)** | 韩国领先平台 | 无月租/年费，佣金5%-10%；月度结算，次月第15个工作日支付；最低100万韩元GMV才发起支付；FBM配送缓冲期6天 |
| **Gmarket** | 韩国第一大平台 | 2000万+会员；此前未对中国卖家开放；审核周期2-3周；热销：旅游运输、服装、3C、食品、化妆品（增长率46.7%） |
| **11Street** | 前三平台 | 一次性代入驻费3000元；无月租/年费；自发货无限制 |

### 合规要求

**KC认证（韩国认证标志 Korea Certification Mark）**：
- 强制范围：婴幼儿及儿童产品、电子电器、照明设备、电池等
- 部分项目仅能在韩国注册的商业实体或分公司申请
- WING后台必须准确填写KC认证信息

**商标注册（2026年新规）**：
- 酷澎、Gmarket等品牌蓝标认证必须提供韩国注册商标
- 国内已注册商标在韩国不受保护，必须单独注册
- 周期：6-9个月（超高速审查可压缩至3个月）

### 法律法规要点

| 法律 | 核心内容 |
|------|----------|
| 《电子商务交易中的消费者保护法》 | 维护消费者信息安全、电子支付通知义务 |
| 《个人信息保护法》(PIPA) | 个人信息收集/使用/传播规范；泄露时需通知受害者及当局 |
| 《电子商务法》（2024年修订） | 去暗黑模式、订阅服务明确同意、禁止重复弹窗、总价透明 |

**2024-2025合规趋势**：
1. 消费者保护强化：自动续费需明确同意；禁止重复弹窗
2. 跨境电商监管收紧：2024年5月与AliExpress、Temu签署《产品安全协议》
3. 个人信息保护：PIPA规定严格同意机制，违规可刑事追责

### 税务条款

**增值税（VAT）**：
- 标准税率：10%
- 申报周期：季度申报，结束后25天内缴纳
- 进口包裹免税门槛：商品价值低于150美元免关税，**但增值税仍需缴纳**

**纳税人分类**：
- 一般纳税人：年销售额 > 8亿韩元，正常申报，进销项抵扣
- 小规模纳税人：年销售额 ≤ 8亿韩元，可选择简易计税

**跨境电商特别规定**：
- B2C：外国卖家在韩国有第一笔B2C销售即须注册增值税，负责代收代缴
- 进口关税税基：到岸价（CIF），平均税率约8%

**企业所得税**：
- 居民企业：国内外全部收入缴税
- 外国企业：韩国来源收入缴税
- 季度预缴，财年结束后3个月内完成年度申报

## 模块三：自媒体运营学习（抖音/小红书/视频号）

### 一、三大平台算法机制

#### 1. 抖音（兴趣驱动 · 公域为主）

**2026年算法核心变化**：
- 从「标签匹配」转向「用户行为预测 + 价值权重」打分机制
- 公式：视频推荐优先级 = 预测用户行为概率 × 行为价值权重
- 重点指标权重排序：**收藏 + 复访 > 完播率 > 分享率 > 关注 + 追更**

**关键洞察**：
- 抖音要的是「长尾价值内容」，不是一次性爆款
- 开头强化"含金量"，引导用户先收藏再观看
- 推荐流量占80%，搜索流量占20%但增速快
- 视频发布后进入200人测试池，完播率达标→2000人→更大流量池

**生死线指标**：完播率 > 50%，互动率 > 5%，前3秒必须抓人

---

#### 2. 小红书（搜索+社区 · 种草引擎）

**2026年算法核心（星云5.0）**：
- 从"停留时长优化"转向"价值内容匹配"
- 5大引擎协同：用户画像 + 内容理解 + 匹配排序 + 流量调控 + 商业平衡

**CES评分公式**：
```
CES = 点赞(1分) + 收藏(1分) + 评论(4分) + 转发(4分) + 关注(8分)
```

**关键阈值（2026最新）**：
- 图文CTR ≥ 2.5%，视频CTR ≥ 4%
- 互动率 ≥ 5%
- 图文停留 ≥ 25秒，视频停留 ≥ 1分10秒
- 收藏率 > 8% 是进入TOP推荐的关键

**核心差异**：
- 搜索流量占比 > 40%，长尾效应极强（内容生命周期以"年"计算）

- 标题要"具体带数字"：《3个让PPT高级感翻倍的小技巧》
- 标签要"精准分层"：3泛标签 + 3精准标签 + 2长尾标签

## 今日关键收获总结

### 韩国电商板块
1. **酷澎卖家评分是生命线** — 配送、退货、客服、库存任一环节失控都会引发连锁下跌
2. **费用结构必须精细核算** — 表面佣金5~10%，实际综合成本可达13~18%，入仓前做反向定价
3. **AI广告需人工干预** — 自动广告前3-5天必须清理排除关键词，2周巡检是底线
4. **现金流预留2~3个月** — 确认收货基准结算周期长达1月+，提前结算服务可缓解压力
5. **火箭成长仓储费可控** — 遵守按类目免费保管期，滞销品60日内必须处理

### 自媒体板块
1. **算法即用户** — 2026年三大平台算法核心都转向"以用户行为为中心"
2. **内容价值 > 流量技巧** — 收藏率、复访率成为比完播率更重要的指标
3. **变现要从第一天规划** — 不要等到粉丝多了再想变现路径
4. **AI是杠杆不是替身** — 70/30法则，AI做骨架，人工注入灵魂
5. **私域是终局** — 公域获取流量，私域沉淀价值，用户终身价值(LTV)比粉丝量更重要
