### 【问题案例1】商品搜索无曝光——不是商品问题，是数据结构断了
**场景描述**：卖家上架商品后搜索不显示、review堆了但点击率起不来、季节品到季了也没销量。很多卖家以为是商品本身不行，拼命改图降价都没用。
**问题分析**：2026年Coupang算法评估的是完整5段流程：搜索→点击→停留→购买→复购。如果初期数据（曝光/点击）、流量（广告/活动）、review这三块各自为政、没有连成一条「数据流」，算法就会判定该商品无法持续产生购买行为，从而停止给曝光。这不是“正在优化中”，而是算法已经给你判了死刑。
**解决方案**：
1. 按「搜索曝光→CTR/停留→购买转化→复购」四段搭建数据闭环
2. 上架后5~7天内利用「最新性评分」集中投放广告，用最小成本冲初始数据
3. 详情页第一屏必须包含：核心卖点3条、TOP3 FAQ、认证标志、简单使用指南
4. review积累后，把买家高频提到的关键词反哺到商品标题和标签中
5. 避免关键词堆砌，采用「品牌名+核心词+特征+规格」的自然结构
**关键要点**：
- 数据孤立比没数据更致命——算法要的是连贯行为链，不是单点优秀
- 季节品的胜负在「初段窗口期」（竞争弱、结构定生死），别等到中段才入场
- 每周修改详情页不要超过1次，频繁改动会让曝光暂时不稳定

### 【问题案例2】退货未回收，Coupang自动退款后卖家血本无归
**场景描述**：卖家发现退货商品根本没被取回，但Coupang已经自动给客户退款了。这种情况反复发生，钱货两空。
**问题分析**：这是Coupang「保证退款（보장환불）」政策导致的。客户在「配送指示/配送中/配送完成」任一状态下申请退货，若超过营业日60小时未完成退款流程，Coupang会直接先给客户退款，不管商品是否已回收。对卖家来说，这意味着：货没回来，钱先没了，而且Coupang不会自动帮你追偿。
**解决方案**：
1. **主动联系客户取消退货**：拨打Coupang客服1600-9879 → 输入企业代码 → 1号（Marketplace咨询）→ 2号（安全号码咨询）→ 1号（同意个人信息使用）→ 输入订单号# → 1号（收件人真实号码）/2号（下单人真实号码）→ 取得号码后致电客户，协商取消退货或安排退回
2. **若客户不接电话、不退货**：在「订单/配送→退货管理」中登记回收运单号，并在卖家咨询板留言请求「回收支援」。Coupang会代你联系客户确认回收日程；若仍无法回收，Coupang会自动做重新结算（재정산）
3. **若已完成保证退款且未自动重新结算**：在「处理完成日」起算营业日第5天起、168小时（7天）内，通过线上咨询提交「补偿申请」。错过窗口期会被驳回
**关键要点**：
- 安全号码有有效期，退货问题拖久了就查不到客户真实号码，必须尽早行动
- 补偿申请不是自动的，卖家必须手动在指定时间窗口内提交
- 保留发货/入库视频证据，数量纠纷和退货纠纷都需要影像自证

### 【问题案例3】广告费烧得凶，ROAS死活上不去——关键词在偷偷吃钱
**场景描述**：卖家每天广告费几万韩元哗哗流，但ROAS不到100%，卖得多亏得多。尤其是开了自动广告后，预算消耗极快。
**问题分析**：Coupang自动广告（AI智能广告/销量优化广告）会由AI自动扩展关键词，但经常出离谱匹配：比如卖「皮鞋」的，AI给匹配了「运动鞋」；卖「衬衫」的，匹配了「卫衣」。这种无关关键词带来大量无效点击，只消耗预算不产生转化。有调查表明，因未管理这类「吃钱关键词」，卖家平均浪费广告费最高可达1,900万韩元。
**解决方案**：
1. 每天进广告后台 → 关键词报告 → 筛选「CTR高但CVR低」的词，这些是流量大但不买的词，优先排除
2. 排除标准：ROAS ≤ 100% 的词、转化率为0%但花了钱的词、竞品品牌词（如与你的商品无关却匹配了「Dr.Jart+」「雪花秀」）
3. 自动广告无法直接加排除词，需先转手动 campaign 再设置排除关键词
4. 每周做一次关键词审计：按花费排序，砍掉只花钱不产出的词，保留ROAS>300%的核心词
5. 若流量因此下降，用「关联词」补回：例如排除「减肥辅助剂」后，试投「体脂减少辅助剂」等同义长尾词
**关键要点**：
- 广告不是开了就完事，前3~5天的关键词清洗决定后续效率
- 不要一次性排除太多词，先砍最差的20%，观察3天再迭代
- 大词（如「洗发水」）曝光多但转化低，小词（如「男性脱发洗发水500ml」）竞争小、购买意图强

### 【问题案例4】真实费用黑洞——名义手续费10.9%，实际负担13%~18%
**场景描述**：新手卖家按Coupang官方公布的「最高10.9%」定价，结果结算到账金额比预期少一大截，甚至个别订单算完是亏损的。
**问题分析**：2026年Coupang手续费改革后，实际负担由多层构成：①类别基本销售手续费（4~10.9%）+ ②支付手续费2.9%（2026年新增独立项）+ ③增值税10%（在①+②基础上再征）。以10,000韩元时尚商品为例：基本手续费1,050 + 支付手续费290 + 增值税134 = 1,474韩元，实际负担14.7%。再加上Rocket Growth物流费、免费配送手续费3.3%、仓储费、退货费等，轻松突破20%。更隐蔽的是：定价时没把退货双向运费算进去，高退货率品类直接吃光利润。
**解决方案**：
1. 定价必须用「逆算公式」：目标到手价 ÷ (1 - 实际总负担率) = 销售定价。建议预留至少30%毛利
2. 把费用拆成独立条目记入成本表：销售手续费、支付手续费、VAT、物流费（入仓/出仓/配送）、仓储费、退货预估费、广告费
3. 入Rocket Growth前先算清楚：2025年尺寸从3档细分为6档，每档费用不同；90天以上长期仓储费翻倍
4. 尽量把免费配送做成「选择性」而非全SKU开通，避免3.3%无条件扣除
5. 每周一检查库存：30天以上长期库存列清单、季节品在季末2周前启动折扣清货
**关键要点**：
- 免费配送是销售利器，但全店开通会让低客单商品直接亏损
- 不同平台计费基准不同：Coupang按折扣后实付金额算手续费（促销时吃亏小），Gmarket/11街按折扣前定价算（促销时吃亏大）
- 不要只看「名义手续费」，要看「实际到手率」定价

### 【问题案例5】卖家中心的7个常见死因——从结算周期到税务
**场景描述**：很多卖家运营3~6个月后突然现金流断裂，或者税务申报时被追缴税款加滞纳金，回头才发现从一开始的基础设定就错了。
**问题分析**：根据2026年最新卖家指南统计，以下7个失误是新手/中小卖家的最大陷阱：
① 没把结算周期算进现金流——Coupang默认月结算，卖出后30~60天才能拿到钱，销量越大垫资压力越大；
② 盲目使用快速结算——确实提前拿到钱，但额外手续费会像滚雪球一样吃掉毛利；
③ 入店时不核对类别手续费——表面毛利率和实际毛利率差距大；
④ 漏算退货双向运费——没把这笔费用计入定价，高退货品类直接亏；
⑤ 差评/负面review响应慢——卖家评分下降后曝光权重跟着掉；
⑥ 不做选项价差设计——只有一个价格一个规格，在比价竞争中秒败；
⑦ 税务申报漏报或错报——Coupang结算数据直接对接国税厅，漏报触发加算税。
**解决方案**：
1. 入店第一周就做「现金流模拟表」：按最坏情况（月结算+退货率15%）算需要垫多少运营资金
2. 快速结算只在「有确定性大促/补货窗口」时短期使用，平时关闭
3. 上架前到卖家中心确认具体类别的最新手续费率，并把支付手续费2.9%、VAT10%一并算入
4. 所有商品定价必须包含「退货双向运费准备金」——退货率高的品类建议按退货率×单程运费×2计入成本
5. 设置差评自动提醒（或每日早会检查），24小时内必须回复或提出解决方案
6. 每个SKU至少做2~3个选项组合（不同容量/颜色/套装），用组合装拉高客单价
7. 每月导出Coupang结算明细，与银行流水核对，确保税务申报数据一致
**关键要点**：
- 现金流断裂比没订单更致命——Coupang卖得好反而需要更多垫资
- 卖家评分直接影响搜索排名，不是「服务态度」问题，是「流量」问题
- 税务风险可以100%提前规避，只要养成每月对账习惯

### 【问题案例6】物流入库数量对不上——Coupang仓库说少了2个，百口莫辩
**场景描述**：品牌B卖家发了100个商品到Coupang物流中心，入库记录显示只有98个。过去因为单笔损失小忍了，但量大后每次少几件，一年下来损失巨大。
**问题分析**：这是B2B端的典型CS纠纷。当卖家与平台/物流商交接时，「数量争议」是最难取证的类型。Coupang的物流系统只认最终扫描数量，如果卖家没有发货前的视频/照片证据，就只能认栽。随着销量规模扩大，过去「几个而已算了」的心态会变成严重利润侵蚀。
**解决方案**：
1. **发货前拍摄**：装箱全过程录像，清晰拍到每件商品条码/数量，封箱前定格
2. **保留称重证据**：快递面单+称重记录，若数量差异大重量通常也会异常
3. **定期对账**：每周核对「发货数量 vs 入库数量 vs 实际可售库存」，发现异常立即开case
4. **争议处理**：在卖家中心提交争议时，必须附上发货视频或第三方物流交接单
5. **更进一步——把视频当营销用**：韩国有品牌D卖家在发货时同步给客户发「出库视频」，结果订单取消率下降、客服咨询减少约20%，review里甚至出现「看了视频很感动」的反馈
**关键要点**：
- 电商竞争已经打到「不可见区间的透明度」——谁能证明自己没出错，谁就能避免损失
- 出库视频不要只当「防御性证据」，给客户同步发送能直接降低取消率和客服成本
- 数量差异争议的最佳处理时间是「发现当周」，拖久了平台和物流都不认

### 【运营技巧】上架后黄金7天——用「最新性评分」低成本冲排名
**适用场景**：新品上架、季节品首发、老品重新激活
**具体操作**：
1. 商品注册后前5~7天，Coupang会赋予「最新性评分」，此期间自然排名权重较高
2. 在这7天内集中预算投放「搜索广告」+「销量优化广告」，配合限时折扣或赠品
3. 第3天检查关键词报告，立即砍掉无关词（参考案例3的方法）
4. 第5天观察CTR和转化率：若CTR<1%则换主图；若转化<2%则检查价格/选项/详情页首屏
5. 第7天后逐步降低广告占比，让自然流量接手，避免长期广告依赖
**效果预期**：有案例显示，利用黄金期集中的商品，7日后自然排名能稳定在首页20~30位，广告费可降30~50%
**注意事项**：
- 如果商品详情页、评价、价格竞争力没准备好就猛砸广告，黄金期会被浪费，后面很难翻身
- 季节品必须在季节「初段」就入场，中段再进只能打价格战

### 【今日总结】

- **核心洞察**：
  1. Coupang算法看的是「数据闭环」而非单点数据——曝光、点击、停留、购买、复购必须连成一条线，断了就掉权
  2. 卖家的隐形杀手不是没订单，而是「钱货两空」的自动退款和「13%~18%」的真实费率——定价必须逆算，不能只按名义手续费
  3. 电商已进入「证明经济」时代：发货视频、入库证据、出库影像既是防御纠纷的武器，也能变成降低取消率的营销资产

- **实操建议**：
  1. 今天就检查自己广告后台的「关键词报告」，找出近7天ROAS<100%的词，能排的先排除
  2. 重新核对自己热销品的定价表，把支付手续费2.9%、VAT10%、退货双向运费加进去，看毛利是否仍>30%
  3. 如果还在用月结算且月销量>500万韩元，评估是否切换周结算或准备更多运营资金；快速结算不是长期方案
