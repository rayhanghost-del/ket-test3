## 【问题案例1】直权退款（직권환불처리）——卖家在不知情的情况下被自动退款，货物和钱两空

**场景描述**：买家以"卖家责任"（如配送延迟、商品瑕疵等）为由申请退货，若4个营业日内退货商品未被回收，Coupang不经卖家同意直接批准退款。卖家A某在查看退货记录时，发现自己并未处理的数十件退货已被自动退款，且未收到任何通知。

**问题分析**：
1. Coupang自2021年3月起实施该政策，优先保障买家退款体验
2. 系统不主动向卖家发送直权退款通知，卖家往往在事后对账时才发现
3. 退款完成后买家与卖家联系意愿降低，退货回收变得困难
4. 部分买家滥用制度，以"配送延迟"等理由申请退款（即使实际并无问题）

**解决方案**：
1. 每日登录Wing卖家中心，主动检查"退货/换货管理"菜单，不能等通知
2. 退货商品发出后，立即在系统中标记并追踪回收状态
3. 确保退货地址和快递合同代码已正确注册，否则无法申请异议
4. 若发现直权退款，在商品入库后72小时内提交异议申请（需附照片、通话记录等证据）
5. 与买家主动联系，协商退货回收或退款撤销

**关键要点**：
- 直权退款的异议申请窗口极短（入库后72小时），逾期不受理
- 配送预计日尽量留出缓冲时间，避免因快递延迟触发买家"配送延迟"退款
- 保留所有发货和退货的快递单据、照片作为证据

## 【问题案例2】恶意差评导致销售额减半——如何用法律武器删除虚假评价

**场景描述**：某健康功能食品卖家在Coupang上销售主力产品，原本评价良好。某天出现一条恶意差评，内容为"吃了这个产品后反而长胖了"，此后该产品销售额急剧下降近50%。

**问题分析**：
1. 该差评包含可验证的虚假事实（"吃了几天就长胖"），而非单纯主观意见
2. 消费者在看到负面评价后，购买意愿大幅下降
3. 向Coupang平台申请删除差评通常被拒绝，平台以保护消费者表达自由为由
4. 卖家若采取情绪化全面反驳，反而容易陷入法律纠纷且效果不佳

**解决方案**：
1. 冷静分析差评内容，区分"主观意见"和"可验证的虚假事实"
   - 主观意见（如"味道不好"）受表达自由保护，难以删除
   - 虚假事实（如"吃了几天长胖"）属于名誉毁损/业务妨碍，可法律追究
2. 收集产品成分报告、相关科学文献等证据，证明该说法不符合常理
3. 向警方提起名誉毁损/业务妨碍控告，目标不是惩罚对方，而是删除差评
4. 警方通过调查确定嫌疑人身份后，以"删除差评"为条件进行和解谈判
5. 若嫌疑人主动联系求和解，坚持仅以删除差评为条件，不接受额外赔偿要求

**关键要点**：
- 法律策略的核心是"精准打击"——只攻击可证明为虚假的陈述，而非整条评价
- 情绪化全面反驳是失败策略，会延长纠纷时间并增加成本
- 该案例最终以嫌疑人删除差评、双方和解告终，卖家的销售额得以恢复

## 【问题案例3】自动广告AI乱加关键词——"皮鞋"匹配"运动鞋"，卖家白白浪费1900万韩元广告费

**场景描述**：多位卖家发现，使用Coupang AI智能广告或销量优化广告时，系统会自动添加与商品完全无关的关键词。例如销售"皮鞋"的商品被添加了"运动鞋"关键词，销售"衬衫"的商品被匹配了"卫衣"。有卖家因此损失高达1900万韩元广告费。

**问题分析**：
1. Coupang自动广告（除手动广告外）默认会添加扩展关键词，且不会自动排除不相关词
2. AI基于宽泛的关联性匹配，容易出现跨品类错误匹配
3. 卖家若未定期检查搜索词报告，这些"吃钱的关键词"会持续消耗预算
4. 大词（如"免费""样品"）点击量高但转化率几乎为零，广告费被大量浪费

**解决方案**：
1. 每周至少查看一次"搜索词报告"，识别高点击零转化的关键词
2. 将无关关键词立即添加至"排除关键词"列表：
   - 品类无关词（如皮鞋→运动鞋）
   - 低购买意向词（"免费""样品""试用"）
   - 竞争对手品牌名
   - 价格比较类词汇
3. 使用工具（如세이비/Savey）自动分析"吃钱的关键词"并批量排除
4. 将品牌关键词和一般关键词分开管理，品牌词可用更低出价
5. 同一关键词不要为多个商品重复投放，避免内部竞价抬高成本

**关键要点**：
- 自动广告不是"设置完就不管"，需要至少每2周进行一次关键词清理
- 某卖家使用세이비优化后，2个月内ROAS从320%提升至400%，转化率从3.4%升至4.2%
- 关键词管理的核心原则：只保留带来实际购买的关键词，其余全部排除

## 【问题案例4】Coupang物流中心入库数量争议——发货100个只入库98个，举证困难

**场景描述**：某品牌通过Coupang Rocket Growth（火箭配送）销售，向Coupang物流中心发货100件，但系统显示仅入库98件，2件"消失"。卖家要求赔偿，但因缺乏有效举证手段，多次协商未果，累计损失随销量增长而扩大。

**问题分析**：
1. 卖家发货和Coupang入库之间存在数量差异，原因可能包括运输途中丢失、扫描错误、分拣差错等
2. 过去因单笔损失金额小，卖家往往选择"算了"，但销量扩大后损失累积可观
3. Coupang方面要求卖家提供发货数量正确的证据，而普通卖家很少在发货时拍摄完整视频
4. 举证责任在卖家一方，没有证据则难以获得赔偿

**解决方案**：
1. 发货前建立标准化视频拍摄流程：
   - 拍摄待发货商品的全貌（清晰可见数量）
   - 拍摄打包过程（商品放入箱中）
   - 拍摄封箱后的快递面单（与箱内商品关联）
2. 使用Coupang指定的快递服务，保留发货底单和追踪记录
3. 收到入库差异通知后，立即提交视频证据和快递单据申请核查
4. 如差异频繁发生，考虑在包装盒内附"装箱清单"，便于物流中心核对
5. 大额发货时，购买运输保险作为额外保障

**关键要点**：
- "视频证据"是解决入库争议最有效的手段，建议在发货区安装固定摄像头
- 争议处理需要及时，拖延时间越长越难追溯
- 该案例的延伸启示：AS（售后维修）过程也应录制视频，减少与客户之间的纠纷

## 【问题案例5】直接使用供应商详情页导致搜索曝光低——Coupang算法不识别重复/通用内容

**场景描述**：大量委托销售卖家（尤其是代购/一件代发模式）直接使用供应商提供的商品详情页原样上传，结果发现商品搜索曝光极低，即使开广告也难以获得自然流量。

**问题分析**：
1. Coupang的搜索算法不仅看关键词，还会评估详情页内容的原创性和相关性
2. 供应商提供的详情页通常是通用模板，多个卖家重复使用，算法将其判定为"低质量内容"
3. 详情页未针对Coupang移动端优化（90%以上用户使用移动端购物）
4. 图片可能包含其他平台水印、价格信息，进一步降低权重

**解决方案**：
1. 至少进行3项轻量修改，让详情页"与众不同"：
   - 重写商品标题：加入Coupang搜索建议的长尾关键词（搜索框自动补全词）
   - 调整详情页结构：首屏放核心卖点+使用场景图，而非供应商的企业介绍
   - 替换或补充至少2-3张图片：添加实际使用效果图、尺寸对比图
2. 利用Coupang搜索框提取关键词：
   - 输入主关键词后按空格，记录自动补全的词汇
   - 在PC端和移动端分别提取（两者推荐顺序不同）
   - 将高频补全词自然融入商品标题和搜索标签
3. 删除供应商原页面中的其他平台价格信息、竞品链接
4. 添加FAQ模块，回答买家最关心的问题（减少咨询负担，提升转化率）

**关键要点**：
- 商品标题公式建议：长尾关键词80% + 主关键词20%，不要一上来就竞争大词
- PC端和移动端提取的关键词有差异，必须以移动端为准（90%+用户用手机）
- 详情页不是"展示商品"，而是"回答买家疑问+推动下单"的销售工具

## 【问题案例6】Coupang自营品牌（PB）低价碾压——小卖家正面价格竞争必败

**场景描述**：一位销售日用品的中小卖家发现，自己定价5000韩元的商品，Coupang PB（Private Brand，自营品牌）以3500韩元销售，且带有Rocket Delivery标识。该卖家尝试降价跟进，但利润空间被完全挤压，最终被迫停止销售该商品。

**问题分析**：
1. Coupang PB采用"超低价策略"，在生活用品、食品等品类强势扩张
2. PB商品享有Rocket Delivery天然流量优势，且价格通常低于第三方卖家成本价
3. 小卖家若正面打价格战，几乎不可能获胜——Coupang拥有规模采购优势和平台流量倾斜
4. 部分卖家因愤怒或焦虑而盲目降价，导致亏损销售，最终退出市场

**解决方案**：
1. 回避PB强势品类，选择PB未覆盖的细分利基市场（niche category）
2. 差异化策略：
   - 品牌故事+设计差异化（而非单纯功能）
   - 捆绑销售/套装组合（提高客单价，避开单品价格战）
   - 提供专业咨询和售后服务（PB通常不提供深度客服）
3. 不要在Coupang PB主导的品类中投入过多库存和广告预算
4. 定期监控目标品类的PB渗透率，及时调整选品方向

**关键要点**：
- 与Coupang PB正面价格竞争是"必输的游戏"，避开比硬拼更明智
- 数据显示，带有"Rocket"标识的商品转化率是普通商品的2倍以上——与其打价格战，不如争取让自己的商品也能获得Rocket配送资格
- 选品前务必搜索目标品类中是否有强势PB存在

## 【运营技巧】ROAS从250%飙升至820%的实战SEO优化法

**适用场景**：已开通Coupang广告但ROAS偏低（低于300%）、净利润接近零或亏损，想要系统性提升广告效率的卖家

**具体操作**：
1. 商品标题中加入"季节性子关键词"（시즌성 서브키워드）
   - 例如夏季加入"여름용""쿨링""시원한"等搜索热词
   - 通过Coupang搜索框自动补全获取实时热词
2. 强化移动端优化：
   - 首图必须是白底产品图（符合Coupang最新广告审核政策）
   - 详情页文字字号不小于14px，关键信息3秒内可见
3. 黄金时段广告集中投放：
   - 下午6点~9点为Coupang订单高峰
   - 该时段预算分配提高至平日的150%
   - 凌晨时段预算降至50%
4. 系统化积累真实评价：
   - 商品上架首月即启动体验团（체험단），目标获取10条高质量图文评价
   - 评价维持在4.2星以上，低于此阈值广告效率和排名均会下降
5. 建立"搜索→点击→停留→购买→复购"完整数据闭环，确保每个环节无断裂

**效果预期**：
- 某生活家电卖家3个月实施后：ROAS从250%→820%，净利润从60万韩元/月→230万韩元/月，上位曝光持续时间从20天延长至76天

**注意事项**：
- 不要同时使用"免费配送""最低价""限量销售"等营销文案（2026年起广告审核会拒绝）
- 健康功能食品类避免使用"治疗""疗效"等医疗相关词汇，可能导致账号被封禁3个月

## 【今日总结】

### 核心洞察
1. **退货管理是Coupang卖家的头号风险点**：直权退款制度下，卖家必须在72小时异议窗口内行动，且需要完善的证据链（照片、视频、快递单据）才能维权。被动等待等于默认损失。

2. **广告自动化是把双刃剑**：Coupang AI广告虽然省事，但会自动添加大量无关关键词，若不定期清理，广告费会像漏水一样流失。有卖家因此损失1900万韩元。关键词排除管理必须成为每周例行工作。

3. **内容原创性决定自然流量**：直接使用供应商详情页会导致Coupang算法判定为低质量内容，搜索曝光极低。即使是轻量修改（重写标题、替换几张图、加入FAQ），也能显著改善排名。

### 实操建议（明天即可应用）
1. 登录Wing卖家中心，检查最近7天的退货记录，确认是否有未注意到的直权退款；若有，立即收集证据准备异议申请。

2. 打开广告后台的"搜索词报告"，将过去30天点击量高但转化率为0的关键词全部加入排除列表——这一步可能立即节省30%以上的无效广告支出。

3. 选取1-2个核心商品，用Coupang移动端搜索框提取10个自动补全长尾词，重写商品标题并更新详情页首图，测试7天观察曝光和点击率变化。
