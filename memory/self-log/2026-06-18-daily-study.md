### 【问题案例1】판매자 귀책 반품의 첫 대응 — 사이즈 표기 오해로 배송비 부담 발생

**场景描述**：
쿠팡 셀러 파플님이 방한장갑을 판매 중, 고객으로부터 "실제 상품이 상품 설명에 써있는 것과 다름"이라는 판매자 귀책 반품 신청을 받았습니다. 고객은 여성 M/L, 남성 XL로 표기된 사이즈 안내를 보고 주문했으나 실제 상품이 너무 컸다고 주장했습니다. 반품 배송비가 판매자 부담으로 처리되어 감정 소모가 컸습니다.

**问题分析**：
- 사이즈 표기가 "여성 M/L, 남성 XL"처럼 애매하게 작성되어 고객이 오해
- 상품 상세 페이지의 정보가 실제 상품과 정확히 일치하지 않아 판매자 귀책으로 인정됨
- 초보 셀러는 판매자 귀책 vs 고객 귀책 판단 기준을 몰라 고민 시간이 길어짐

**解决方案**：
1. 판매자 귀책으로 인정하고 처리 결정 (상품 설명 오해의 소지를 제공한 경우 판매자 귀책)
2. 쿠팡 윙 → 반품 관리에서 반품 상품 확인
3. 공급업체(도매매)에 해당 상품 반품 접수
4. 공급사에서 반품 배송 접수 및 운송장 번호 발급
5. 쿠팡 반품 관리 화면에 운송장 번호 등록
6. 공급사가 상품 회수 및 검수 후 환불 → 쿠팡에서 반품 완료 자동 처리

**关键要点**：
- **사이즈 표기는 단순한 나열이 아니라 실측 사이즈를 이미지로 함께 표시**해야 함
- **반품 사유가 애매할 때는 AI(지미나이 등)에게 상황 설명 후 판단 기준을 물어보는 것이 시간 절약**
- **공급사 반품 접수 시 "상품 자체의 문제"로 사유를 작성하면 승인받기 쉬움** ("판매처 오기재"보다 유리)

### 【问题案例2】택배사 지연으로 판매자 점수가 0점이 되다 — 소명 요청 복구법

**场景描述**：
데사노 디렉터 Celina님이 항상 100점으로 관리하던 판매자 점수가 갑자기 배송 부분 0점이 되었습니다. 확인해보니 배송 예상일보다 하루 늦어진 1건 때문이었고, 실제로는 판매자가 정시에 발송했으나 택배사의 배송 지연으로 인한 것이었습니다.

**问题分析**：
- 쿠팡 시스템은 배송 예상일 기준으로 판매자 점수를 계산하며, 택배사 지연도 판매자에게 패널티 부과
- 판매자가 실제 발송 시간을 증명하지 않으면 패널티를 그대로 받게 됨
- 쿠팡의 판매자 점수는 검색 노출과 직결되므로 0점은 매출에 직접적인 타격

**解决方案**：
1. 쿠팡 윙 → 해당 배송 건의 실제 출발 시간 캡처
2. 쿠팡 판매자센터 → 온라인 문의 → 판매자 점수 제외 요청
3. 판매자 점수 제외 요청 전용 링크 접속: `https://helpseller.coupang.com/hc/ko/requests/new?ticket_form_id=360000545712`
4. 주문번호 + 박스ID(묶음배송번호) + 발송 시간 캡처 첨부하여 제출
5. 담당 부서에서 확인 후 판매자 점수 복구 처리

**关键要点**：
- **택배사 지연으로 인한 배송 지연은 판매자 점수 제외 요청 가능** (정시 발송 증명 필수)
- **발송 시간 캡처는 정기적으로 보관하는 습관이 필요** — 분쟁 시 증거 자료로 활용
- **월 10~20회 온라인 문의를 적극 활용**하는 것이 쿠팡 판매의 현실

**原文链接**：[https://nomadel.tistory.com/entry/쿠팡-정시발송했는데-판매자-점수가-갑자기-0이-되었다-판매자-점수-복구-후기](https://nomadel.tistory.com/entry/%EC%BF%A0%ED%8C%A1-%EC%A0%95%EC%8B%9C%EB%B0%9C%EC%86%A1%ED%96%88%EB%8A%94%EB%8D%B0-%ED%8C%90%EB%A7%A4%EC%9E%90-%EC%A0%90%EC%88%98%EA%B0%80-%EA%B0%91%EC%9E%90%EA%B8%B0-0%EC%9D%B4-%EB%90%98%EC%97%88%EB%8B%A4-%EB%8B%A4%EC%8B%9C-%EB%90%98%EC%82%B4%EB%A6%AC%EB%8A%94-%EB%B2%95)

### 【问题案例3】쿠팡 셀프 환불 정책 확대 — 회수 없이 환불되는 상품 대응법

**场景描述**：
2025년 12월 10일부터 쿠팡 마켓플레이스 일부 카테고리(특히 신선식품)에서 회수 없이 고객 사진 업로드만으로 환불이 처리되는 "셀프 환불" 시스템이 도입되었습니다. 셀러는 판매자가 실제 상품 상태를 직접 확인할 기회 없이 전액 환불해야 하는 상황에 직면했습니다.

**问题分析**：
- 기존: 회수 후 검수 → 환불 / 변경 후: 고객 사진 업로드 → 회수 없이 환불 처리
- 정산 차감 시점이 검수 결과 확정 후에서 직권 환불 시 즉시 차감으로 변경
- 확인 요청 재접수 횟수가 기존 영업일 168시간 이내에서 **1회로 제한**됨
- 판매자가 제출한 입증 자료(검수 사진·운송장·통화 기록)에 따라 보상 여부가 갈림

**解决方案**：
1. 쿠팡 윙에서 직권 환불 알림 수신 시 즉시 확인
2. 쿠팡 윙 안내 기한 안에 확인 요청 또는 이의제기 절차 진행
3. **매 건 검수 사진·물류 영수증·통화 기록 등 증빙 자료를 체계적으로 보관**
4. 부당 환불로 판정될 경우 쿠팡 보상 절차 신청
5. 반품 처리 SOP를 사전에 수립하여 누락 없이 대응

**关键要点**：
- **매 건 남기는 기록이 곧 확인 요청·분쟁 조정의 증거로 사용됨** — 자료 보관 습관이 생존의 열쇠
- **확인 요청 가능 횟수가 1회로 제한**되었으므로 첫 이의제기가 반려되면 거의 복구 불가
- **정확한 사유 코드와 처리 화면은 쿠팡 윙 공식 안내를 정기적으로 확인**해야 함 (정책 변경 가능성)

### 【问题案例4】로켓그로스 재고 보관료 폭탄 — 입고 후 25일이 지나면 비용 발생

**场景描述**：
로켓그로스로 입고한 상품이 카테고리별 무료 보관 기간을 초과하여 보관료가 발생했습니다. 2025년 1월부터 로켓그로스 물류 처리 비용이 전면 개편되면서, 카테고리별 무료 보관 기간이 차등 적용되고 보관료가 누적되어 정산에서 차감되었습니다.

**问题分析**：
- 악세서리/의류/신발: 45일 무료 / 기타 카테고리: 30일 무료 (2025년 3월 31일까지 60일 무료 프로모션)
- 입고 후 25일이 지난 상품이 보관료 발생 전 프로모션으로 털어낼 결단 시점
- 보관료는 상품 크기·무게·체류기간에 따라 달라져 비용 예측이 어려움
- 반품 회수비·재입고비·반출비도 추가로 발생

**解决方案**：
1. 매주 월요일 아침 재고 점검: **입고 후 25일이 지난 상품은 없는가?**
2. 보관료 발생 전 프로모션으로 해당 상품 할인 판매 결단
3. 무료 보관 기간을 고려하여 입고 계획 수립 — **카테고리별 무료 보관 차등 기간 숙지**
4. 월 20건 반품/반출 무료 처리 한도 내에서 반품/반출 물량 관리
5. 사이즈별 비용 차이를 고려하여 상품 소싱 및 구성 조정

**关键要点**：
- **보관료 면제 기간은 카테고리별로 다르게 적용**되므로 입고 전 반드시 확인
- **월 20건까지 반품 회수/재입고/반출은 무료**이므로 초과 시 비용 발생 가능성 계산
- **재고 회전율이 로켓그로스 수익성의 핵심** — 빠르게 팔리는 상품만 입고하는 것이 핵심 전략

**原文链接**：[https://www.sellerking.io/blog/쿠팡-셀러-필독-로켓그로스-비용-체계-개편-총정리-35321](https://www.sellerking.io/blog/%EC%BF%A0%ED%8C%A1-%EC%85%80%EB%9F%AC-%ED%95%84%EB%8F%85-%EB%A1%9C%EC%BC%93%EA%B7%B8%EB%A1%9C%EC%8A%A4-%EB%B9%84%EC%9A%A9-%EC%B2%B4%EA%B3%84-%EA%B0%9C%ED%8E%B8-%EC%B4%9D%EC%A0%95%EB%A6%AC-35321)

### 【问题案例5】광고 키워드 낭비 — AI 자동 키워드가 "구두"에 "운동화"를 매칭시킴

**场景描述**：
쿠팡 셀러가 AI 스마트 광고나 매출 최적화 광고를 사용 중, 자동으로 추가된 키워드를 확인하니 "구두" 상품에 "운동화"가 매칭되거나 "셔츠" 상품에 "맨투맨"이 매칭되는 등 상품과 전혀 관련 없는 키워드가 추가되어 있었습니다. 이로 인해 광고비만 소진되고 매출은 나오지 않는 상황이 발생했습니다.

**问题分析**：
- 쿠팡은 수동 광고를 제외하고는 모두 별도로 키워드 제외를 해야 함
- AI 기반 자동 키워드 최적화가 판매자의 관리 없이 실행되면 관련성 낮은 키워드에 예산 낭비
- 세이비 조사 결과, **최대 1,900만 원까지 손해를 본 셀러가 있음**
- 셀러당 버리는 평균 광고비는 상당한 금액에 달함

**解决方案**：
1. 쿠팡 광고 관리자 → 키워드 성과 분석 이동
2. 광고비는 높지만 매출이 없는 키워드 식별 및 제외
3. ROAS(광고 수익률) = (광고로 발생한 매출 ÷ 광고비) × 100 계산
4. **ROAS 100% 이하인 키워드는 광고비만 소진하므로 즉시 제외**
5. 경쟁사 브랜드 키워드(닥터자르트, 설화수 등) 확인 후 제외
6. 2주에 1번 키워드 리스트 점검 및 제외 키워드 삭제 예약 습관화

**关键要点**：
- **AI 자동 광고의 키워드는 무관련 키워드가 섞여 있으므로 초기 3-5일 동안 키워드 제외 작업이 필수**
- **CTR 1.5% 이상, ROAS 400% 이상을 목표**로 설정하고 미달 키워드는 과감히 삭제
- **네거티브 키워드(제외 키워드) 설정을 주기적으로 점검**하여 광고비 낭비 차단

**原文链接**：[https://letter.wepick.kr/510/4435624/](https://letter.wepick.kr/510/4435624/)

### 【问题案例6】CS 응대 템플릿 부재 — 미배송·파손 주장에 당황하는 셀러

**场景描述**：
쿠팡 셀러가 고객으로부터 "배달됐다고 뜨는데 받지 못했어요" 또는 "파손된 채로 왔어요"라는 CS 문의를 받았을 때, 포장 영상이 없어 구체적인 대응을 하지 못하고 "알아봐 드릴게요" 수준의 모호한 답변만 남겼습니다. 이로 인해 고객 감정이 악화되고 추가 분쟁으로 이어졌습니다.

**问题分析**：
- 셀러가 포장 영상을 보관하지 않아 증거 자료가 없으면 택배사 분실 신고 외에 할 수 있는 것이 없음
- CS 답변의 3가지 원칙(24시간 내 답변 / 사실 확인 먼저, 판단 나중 / 정중하되 명확하게)을 지키지 않으면 추가 분쟁 유발
- 배송 분쟁은 쿠팡 판매자가 가장 자주 겪는 문제 중 하나

**解决方案**：
1. **포장 영상 보관 시스템 도입** — 출고 당시 포장 상태를 영상으로 기록
2. 미배송 주장 대응 (포장 영상 있을 때):
   - "해당 주문은 [날짜]에 정상 출고되었으며, 포장 영상이 보관되어 있습니다."
   - "우선 택배사([택배사명] 고객센터: [번호])에 분실 신고를 접수해주시면, 저희도 포장 영상을 통해 적극 협조하겠습니다."
3. 파손 주장 대응 (포장 영상 있을 때):
   - "출고 당시 포장 영상을 확인한 결과, 발송 전 상품 상태는 정상이었으며 포장도 완전히 마감된 상태로 출고되었습니다."
   - "파손 사진을 보내주시면 택배사 파손 보상 청구를 함께 진행해드리겠습니다."
4. 쿠팡 고객센터(1577-7011)에 동시에 문의하여 사실 확인 요청

**关键要点**：
- **포장 영상은 배송 분쟁의 확실한 증거** — 없는 셀러의 답변은 "알아봐 드릴게요" 수준에 머물고 구매자 신뢰 상실
- **CS 답변은 24시간 이내에, 사실 확인 우선으로, 정중하되 명확하게** 작성해야 추가 분쟁 방지
- **내용물 누락 주장에 대비해 포장 영상에서 모든 상품이 포함된 것이 확인되는 시스템**이 필요

### 【运营技巧】쿠팡 상세페이지 모바일 최적화 — 80% 매출이 여기서 결정됨

**适用场景**：
- 새로운 상품을 등록할 때
- 기존 상품의 전환율이 낮아서 개선이 필요할 때
- 리뷰에서 "상품이 생각보다 작아요/커요" 등의 오해가 반복될 때

**具体操作**：
1. **모바일 환경 기준으로 상세페이지 설계** — PC 모니터가 아닌 스마트폰 화면에서 확인
2. **'골든타임' 스크롤 횟수는 3~5번으로 제한** — 너무 긴 페이지는 로딩 속도 느려지고 고객 피로도 증가
3. **폰트 크기는 무조건 16px 이상** — 본문 16px, 헤드라인 24px 이상 권장. 고객이 확대 제스처 하지 않아도 술술 읽혀야 함
4. **'통이미지'(포토샵으로 글씨 박은 이미지) 대신 '텍스트 분리' 방식 사용** — 쿠팡 검색 로봇이 내용을 읽어 SEO 상위 노출 확률 상승
5. **상세페이지 구성 순서**: 브랜드 로고 및 소개 → 대표 이미지 → 옵션표 → 주요 특장점 → 상품 정보 → 사용법 및 보관법
6. **실착 이미지, 인증 정보, 사용 환경 사진 등 카테고리별 맞춤 이미지 추가**

**效果预期**：
- 쿠팡 데이터 분석 결과, 상세페이지 품질 점수가 높은 제품은 **전환율 평균 2.3배 높음, 반품률 35% 낮음, 리뷰 작성률 40% 높음**
- 모바일 가독성이 좋은 상세페이지는 고객이 3초 내로 뒤로 가기 버튼을 누르지 않고 구매로 이어짐

**注意事项**：
- **PC에서만 확인하고 제작하면 모바일에서 텍스트가 깨지거나 로딩이 느려져 오히려 판매율이 떨어질 수 있음** — 실제 모바일 화면에서 반드시 최종 점검
- **핵심 포인트는 3가지 정도로 요점을 쉽고 직관적으로 정리** — 과도한 설명은 오히려 고객의 관심을 잃게 함
- **부정확한 정보는 반품과 문의를 유발** — 상품 데이터 입력은 꼼꼼하게
