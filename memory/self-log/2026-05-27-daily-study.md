## 【问题案例1】客户退款后不退回商品，卖家如何申请补偿？

**场景描述**：Coupang实行"保证退款"政策，客户退货后60小时自动退款。平台会代为回收3次，若客户仍不退回商品，本可自动结算补偿。但实际操作中，部分订单未自动结算，需要卖家手动申请补偿，且申请窗口期非常严格。

**问题分析**：
- 许多卖家误以为"回收3次失败后自动结算"是全自动流程
- 实际上部分订单会显示"回收支援请求"链接，需卖家主动点击申请
- 补偿申请有严格的时间窗口：处理完成后第5个工作日（不含周末）起，7日内（168小时内）可申请
- 错过窗口期则无法追回款项

**解决方案**：
1. 定期查看订单/配送 → 退货管理页面，确认商品入库状态
2. 发现"回收支援请求"链接时，立即点击申请
3. 确认处理完成日期，计算可申请期间（处理完成日+5个工作日）
4. 在7日窗口期内提交补偿申请
5. 若被驳回，确认是否在正确时间范围内，重新提交

**关键要点**：
- 不要依赖"自动结算"，必须主动确认每笔退款订单状态
- 标记日历提醒：处理完成后第5个工作日立即申请
- 补偿申请只有一次机会（168小时内），错过不可逆

## 【问题案例2】2025年Rocket Growth费用结构大改，重商品卖家利润被压缩

**场景描述**：2025年1月6日起，Coupang对Rocket Growth（卖家火箭）的费用结构进行细分化改革。原先相对简单的费用体系被拆分为配送费、保管费、退货费三项独立计费，重商品和退货率高的商品成本大幅上升。

**问题分析**：
- 费用拆分前：费用打包计算，轻/重商品差异不明显
- 费用拆分后：重商品配送费大增，每单退货产生额外费用
- 保管费免费期从60天缩短为30天（部分资料显示），库存周转慢的商品成本激增
- 许多卖家未重新核算成本，导致卖得多亏得多

**解决方案**：
1. 重新核算每件商品的完整成本结构：
   - 商品采购价 + 配送费（按重量/尺寸）+ 保管费（30天后）+ 退货费 + 平台佣金（4~10.8%）
2. 评估商品重量和退货率，淘汰或调整重商品、高退货率商品
3. 转向轻小件、低退货率品类（如日用品、小家电配件）
4. 优化库存周转，确保30天内售出，避免保管费
5. 将新增成本反映到售价中，必要时提价10~15%

**关键要点**：
- Rocket Growth不是"放上去就赚钱"，必须按新费用结构重新计算盈亏平衡点
- 重商品（家具、运动器材等）边际利润可能转负，需特别警惕
- 30天免费保管期是硬约束，滞销品必须及时打折清仓或退仓

## 【问题案例3】Coupang推出"无回收自助退款"政策，卖家面临欺诈风险

**场景描述**：2025年12月10日起，Coupang针对Marketplace（公开市场）卖家推出新政策：客户只需拍摄商品问题照片上传，平台审核后即可"无需回收商品"直接退款。该政策率先在生鲜食品领域试行，后续将扩展到其他品类。

**问题分析**：
- 客户无需退回商品即可获得全额退款
- 卖家无法亲自确认商品实际状态，被动接受平台判断
- 存在恶意客户利用照片造假骗取退款的风险（블랙컨슈머）
- 卖家申诉权限也被压缩：原先168小时内可重复申诉，现仅限1次
- 政策目的是减少客户保管瑕疵商品的不便，但将风险转嫁给卖家

**解决方案**：
1. **事前预防**：
   - 发货前拍摄完整的包装视频/照片，保留证据
   - 使用防拆封条、防伪标签，增加恶意退货难度
   - 高价值商品购买运费险或保价
2. **事后应对**：
   - 收到退款通知后立即查看原因和照片
   - 如有异议，在限定时间内提交"确认请求"申诉（仅1次机会）
   - 保留所有发货、包装证据，必要时向平台提供
3. **结构性调整**：
   - 考虑将高价值、易造假商品转为Rocket Growth模式（平台直管）
   - 对生鲜等已适用品类，重新评估利润率是否可承受损耗

**关键要点**：
- 该政策目前主要针对公开市场（Marketplace）卖家，Rocket Growth卖家影响相对较小
- 申诉机会仅1次，必须准备充分证据再提交
- 未来可能扩展到更多品类，卖家需提前建立风控体系

## 【问题案例4】Coupang SEO优化误区：关键词堆砌导致排名下降

**场景描述**：许多新手卖家为提高搜索排名，在商品名和详情页中反复堆砌热门关键词，甚至使用与商品无关的流行词。结果不仅排名未提升，反而被平台降权，客户信任度下降，退货率上升。

**问题分析**：
- Coupang算法已升级，能识别不自然的关键词堆砌
- 商品与关键词不匹配导致客户点击后快速跳出，降低转化率
- 过度优化可能触发平台惩罚，限制曝光
- 正确做法是"自然融入"而非"机械重复"

**解决方案**：
1. **商品名优化公式**（100字以内）：
   - 核心关键词（前15字最重要）+ 品牌/特性 + 主要功能 + 使用对象 + 数量/规格
   - 示例："저자극 아기 물티슈 캡형 대용량 100매 10팩"
2. **关键词研究方法**：
   - 使用Coupang搜索框自动补全功能收集关联词
   - 查看搜索结果页底部的"关联搜索词"
   - 分析排名靠前的竞品商品名结构
3. **详情页优化**：
   - 关键词密度控制在3~5%
   - 优先解决客户问题（问题→解决方案→效果）
   - 移动端优先：图片清晰、文字简洁、重点前置
4. **标签设置**：
   - 最多5个标签，选择与商品高度相关的搜索词
   - 避免宽泛词（如"好"、"便宜"），使用具体属性词

**关键要点**：
- 前15个字决定搜索排名，必须把核心关键词放在商品名最前面
- 图片必须是白色背景、无文字水印、中央构图（2025年新规定）
- 不要塞入无关关键词，宁可少而精

## 【问题案例5】库存管理失控：Rocket Growth保管费吃掉利润

**场景描述**：一位卖家将50件商品入库Rocket Growth，预期30天内售罄。但因销售预测失误，部分商品滞销超过60天，产生大量保管费。更糟的是，这些商品体积较大，保管费按CBM（立方米）计算，最终保管费超过了商品利润。

**问题分析**：
- 入库时未考虑"免费保管期"（30天）后的费用
- 未建立库存周转监控机制，滞销品发现太晚
- 大件商品保管费显著高于小件（日25~50韩元/CBM）
- 缺乏库存预警和自动补货系统

**解决方案**：
1. **入库前**：
   - 仅入库预计30天内可售出的数量
   - 计算公式：日均销量 × 30 × 1.2（安全库存系数）
2. **入库后**：
   - 每周查看库存周转报告，标记超过20天的商品
   - 第25天启动促销（限时折扣、捆绑销售）
   - 第30天决定是否退仓或降价清仓
3. **自动化工具**：
   - 使用库存管理自动化表格/系统（如Kmong上的Coupang库存管理工具）
   - 设置自动提醒：入库后20天、25天、30天分阶段预警
4. **退仓处理**：
   - 滞销超过60天的商品，评估退仓费 vs 继续保管费
   - 退仓时联系Coupang客服，确认退仓流程和费用

**关键要点**：
- Rocket Growth的"免费"只到30天，之后每天按商品尺寸计费
- 大件商品（家具、运动器材）尤其要注意，保管费呈指数级增长
- 与其被动等待，不如主动在第25天就启动促销

## 【问题案例6】CS客服响应慢导致卖家评分下降、账号风险

**场景描述**：一位卖家因日常事务繁忙，客户咨询平均回复时间为48小时以上。结果卖家评分从85分跌至65分，触发平台警告。更严重的是，部分客户因等待回复时间过长而直接申请退款，退货率上升，形成恶性循环。

**问题分析**：
- Coupang要求卖家评分保持70分以上
- 评分维度包括：订单处理速度、配送履约、CS响应速度、退货/交换处理速度
- 24小时内回复是隐性标准，超时会影响评分算法
- 低评分不仅影响曝光，严重时可能导致账号暂停

**解决方案**：
1. **建立CS响应SOP**：
   - 咨询到达后2小时内确认收到（自动回复设置）
   - 24小时内给出实质性答复或解决方案
   - 复杂问题分阶段回复，避免让客户等待
2. **高频问题预处理**：
   - 将常见问答整理到商品详情页（配送时间、尺寸表、材质说明）
   - 设置自动回复模板："感谢您的咨询，关于[常见问题]请参考详情页第X部分"
3. **使用标准回复模板**（按场景分类）：
   - 未收到货物：先确认物流单号，引导客户联系快递公司同时承诺跟进
   - 破损索赔：有包装视频时提供证据，无视频时先道歉再协商
   - 单纯变心退货：明确说明退货运费由买家承担，提供退货地址
4. **主动监控预警**：
   - 每天早中晚三次检查未回复咨询
   - 周末安排值班或设置自动回复说明回复时间

**关键要点**：
- 卖家评分70分是生死线，低于此值账号可能受限
- 不要先说"不是我的错"，先道歉再解释——这是韩国电商文化
- 包装视频是处理破损纠纷的最强证据，没有视频的卖家处于绝对劣势

## 【运营技巧】Coupang自然曝光（Organic）+ 广告并行策略

**适用场景**：新上架商品缺乏销量和评论，自然排名低；或广告费用占比过高，需要降低获客成本。

**具体操作**：
1. **第一阶段（上架1~2周）：广告引流+数据收集**
   - 投放CPC搜索广告，设置每日预算3~5万韩元
   - 重点投放核心关键词，收集点击率和转化率数据
   - 同时优化商品名、图片、详情页，确保流量进入后能转化
2. **第二阶段（上架2~4周）：SEO强化**
   - 根据广告数据，筛选转化率高的关键词
   - 将这些关键词自然融入商品名、标签、详情页
   - 积累5个以上带图评论（通过售后主动联系满意客户）
3. **第三阶段（上架1个月后）：降低广告依赖**
   - 自然排名进入前3页后，逐步降低广告出价
   - 保留核心关键词的防御性投放，防止竞品抢占
   - 转向利润率更高的长尾词自然优化
4. **长期维护**：
   - 每月更新商品详情页（添加新使用场景图片、客户好评截图）
   - 季节性关键词提前2周布局（如"夏季防晒"在4月开始优化）

**效果预期**：
- 3个月内自然流量占比从0提升至40~60%
- 广告费用占比从销售额的20~30%降至10~15%
- 商品获得稳定自然排名后，即使暂停广告也能维持基础销量

**注意事项**：
- 不要一开始就完全依赖自然曝光——没有销量数据的商品算法不会给排名
- 广告数据是SEO优化的指南针，两者必须联动
- 评论数量和质量是自然排名的核心因素之一，不可忽视

## 【今日总结】

### 核心洞察
1. **平台政策风险远大于运营技巧**：2025~2026年Coupang密集调整费用结构和退款政策（Rocket Growth费用拆分、无回收退款、保管期缩短），卖家必须建立"政策监控→成本重算→定价调整"的快速反应机制，否则政策变化直接吃掉利润。

2. **证据意识是卖家生存的底线**：从发货包装视频到客户沟通记录，韩国电商纠纷处理极度依赖证据。没有包装视频的卖家在破损/退货纠纷中几乎100%败诉。投资一个手机支架拍摄发货过程，ROI无穷大。

3. **库存周转比销量更重要**：Rocket Growth模式下，滞销=亏损。30天免费期后的保管费、退仓费、降价损失叠加，可能让一单未售出的商品产生数千韩元成本。库存管理必须做到"30天滚动监控、25天预警促销"。

### 实操建议（明天可立即应用）
1. **检查现有库存**：登录Coupang Wing，筛选入库超过25天的商品，对超过30天的商品立即制定促销或退仓计划。
2. **建立发货拍摄流程**：从今天起的每一单，录制10秒包装封口视频（展示商品完好、包装严实），保存30天。
3. **重算Rocket商品成本**：选取3~5款主力商品，按新费用结构（配送+保管+退货+佣金）重新计算盈亏平衡点，必要时调价。
4. **设置CS回复提醒**：在手机设置每天3个闹钟（10:00/14:00/18:00），检查未回复咨询，确保24小时内响应。
