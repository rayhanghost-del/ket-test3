### 【问题案例1】5万韩元以下"无需回收"退款政策——海外代购卖家的噩梦

**场景描述**：一位海外代购卖家收到顾客单纯变心反品申请，但商品金额低于5万韩元，Coupang直接判定"无需回收"并完成退款，卖家既没收到退货又损失了货款。

**问题分析**：
- 这是2022年12月Coupang针对海外代购卖家推出的政策，原为10万韩元以下，后降至5万韩元以下
- 适用于**单纯变心**也触发，非仅限于商品瑕疵
- 消费者是否拆封使用、是否真实废弃，均无验证程序
- 卖家在入驻阶段未被充分告知该政策，多数卖家是反品发生后才知晓

**解决方案**：
1. 入驻前必须确认自己的反品回收地址和快递公司合约代码是否完整注册
2. 对5万韩元以下商品，需将反品损失计入定价模型
3. 对反品率高的品类（如服装15-20%），慎重考虑是否做代购模式
4. 如认为政策不公，可通过"确认请求"（확인 요청）提出异议，但注意：2025年12月起**再申请次数限为1次**

**关键要点**：
- 该政策被卖家称为"结构性权力滥用"——平台利用优越地位将损失单方面转嫁给卖家
- 相比Naver等平台，Coupang对卖家的保护机制明显薄弱
- 海外代购卖家在入驻时务必确认反品政策细节，不能只看表面入驻优惠

### 【问题案例2】"卖家过错"反品被误标——新手卖家首次反品就踩坑

**场景描述**：新手卖家卖出第一单手套，顾客以"尺寸和商品描述不同"为由申请了"卖家过错"反品。卖家打电话沟通后发现，实际是因为尺寸标注模糊导致顾客误选，并非商品本身有问题，但系统已标记为"卖家负担配送费"。

**问题分析**：
- Coupang没有Naver那样的中间仲裁机制，卖家必须自行与顾客沟通解决
- 很多顾客不会操作反品撤销/重新申请，卖家需要主动引导或代为操作
- 判断"卖家过错"vs"顾客过错"的标准模糊，容易引感情消耗

**解决方案**：
1. 收到反品通知后，先通过安全号码联系顾客，了解真实原因
2. 如确实是顾客误操作，礼貌请求顾客：先撤销原反品 → 再以"单纯变心"重新申请
3. 若顾客不会操作，卖家自行通过Coupang Wing在线客服申请撤销：
   - 路径：Wing → 在线咨询 → 聊天咨询 → 市场相关 → 反品/取消/交换 → 反品撤销咨询 → 选择"已与顾客协商完成"
   - 输入：订单号、选项ID、数量、协商结果(Y)
4. 反品撤销后，在配送管理中以"顾客过错"重新登记反品

**关键要点**：
- **Coupang没有一键撤销按钮**，这是与其他平台最大的不同
- 撤销前务必给顾客发短信留痕，写明"已与顾客协商，将申请撤销"
- 新手卖家建议用AI工具（如Gemini）辅助判断过错归属，减少情感消耗
- 事后立刻修改商品页面，防止同类问题重复发生

### 【问题案例3】自动广告依赖症——月投300万韩元，ROAS仅80%的惨痛教训

**场景描述**：一位卖家将广告预算全部投入Coupang自动广告（AI智能广告），月投入300万韩元，结果ROAS仅80%——每投1万韩元广告只收回8000韩元销售额，越投越亏。

**问题分析**：
- 自动广告会盲目匹配大量无关关键词，如"皮鞋"匹配"运动鞋"、"衬衫"匹配"卫衣"
- 卖家不管理关键词排除列表，导致广告费持续流失
- 据第三方工具调查，部分卖家因自动广告管理不善，**最多损失1900万韩元**

**解决方案**：
1. 每日检查搜索词报告，将无转化的关键词加入排除列表（仅此一项可节省30%广告费）
2. 核心策略：从分散投放转向集中——将80%预算集中在头部20%的高效商品上
3. 手动广告与自动广告结合使用，不要100%依赖自动广告
4. 利用工具（如SellB）定期自动识别"吃钱的关键词"并批量排除
5. 新商品上架5-7天内是"新鲜度分数"期，此时集中投放广告成本最低

**关键要点**：
- 自动广告初期3-5天内必须完成无关关键词排除，否则后续亏损会持续扩大
- 大关键词（如"运动鞋"）曝光多但转化率低，小关键词（如"轻量跑步鞋 女 230"）竞争小但购买意图强
- 建议每2周进行一次全面关键词审计

### 【问题案例4】ROAS设置过高导致广告完全无曝光

**场景描述**：一个化妆品品牌初次投放Coupang广告，将ROAS目标设为600%。结果2周内广告曝光几乎为零，预算消耗率不到10%，根本无法收集数据。

**问题分析**：
- ROAS（Return On Ad Spend）= 销售额÷广告费×100
- 系统判断"600%难以达成"，于是直接不展示广告
- 新手卖家常误以为ROAS越高越好，实际上过高的目标会扼杀广告启动

**解决方案**：
1. 初期ROAS设定在**200-300%**之间，确保能拿到足够曝光和数据
2. 数据收集2周后，根据实际表现逐步上调目标
3. 日预算建议至少3万韩元以上，低于此金额AI广告无法有效运作
4. 下午6点前预算消耗达70%时，系统会自动增额40%——利用此规则确保"黄金时段"有预算

**关键要点**：
- 广告效果通常需要**2周数据收集 + 1-2个月优化**才能稳定
- 每日必查指标：ROAS达成率、CPC变化、转化率趋势、库存状况
- 广告不是万能药，商品本身竞争力（评价数量、页面质量、价格）才是基础

### 【问题案例5】产品名过度堆砌关键词，搜索曝光反而下降42%

**场景描述**：一家健康食品品牌将产品名写成"高级健康美味有机糙米"，结果搜索排名不佳。改为"有机糙米 10kg 2024年产 国产"后，搜索曝光增加42%。

**问题分析**：
- Coupang搜索算法优先"简洁和准确"，而非关键词堆砌
- 主观形容词（高级、美味、健康）不如客观信息（规格、产地、年份）有效
- 关键词重复会被算法判定为负面因素

**解决方案**：
1. 产品名公式：品牌名 + 核心关键词 + 商品特征 + 规格/数量
2. 总长度控制在100字以内（含空格）
3. 用Naver关键词工具和Coupang自动补全功能挖掘真实用户搜索词
4. 长尾关键词自然融入："大容量"、"性价比"、"免费配送"等
5. 详细页面标签（Tag）20个全设满，分类别铺设关键词

**关键要点**：
- 82%以上Coupang用户用手机访问，详细页面必须手机优先设计
- 首屏必须包含：核心优势3点、Top 3 FAQ、认证标志、简单使用指南
- 文字大小至少20pt，多用信息图而非纯文字
- 产品页面修改每周不超过1次，过于频繁会导致临时排名波动

### 【运营技巧】CS纠纷应对——包装发货视频留证法

**适用场景**：顾客声称未收到、商品破损、内容物缺失、反品商品被调包等所有可能产生纠纷的场景

**具体操作**：
1. **使用RealPacking等包装视频录制服务**，记录从拣货到贴快递单的完整过程
2. 对高价值商品，额外拍摄贴好面单的包裹在传送带上的最终状态视频
3. 将视频按订单号分类保存，至少保留3个月
4. 发生纠纷时，第一时间提供视频证据，比文字解释更有说服力

**效果预期**：
- 一位销售高价美容仪的品牌企业，使用视频证据后，**因"盒子破损"反品导致的赔偿费用大幅下降**
- 在"内容物缺失"争议中，有视频证据的卖家胜诉率远高于无证据卖家

**注意事项**：
- 无视频时，答复只能停留在"帮您查查"的模糊层面，顾客信任度低
- 有视频时，答复可以具体且自信："经确认，该订单于X日正常出库，包装视频已留存"
- 对代购/搬运卖家，特别注意：发货包裹内不要夹带原平台的订单小票（可能暴露进货价，引发顾客投诉）

### 【今日总结】

**核心洞察**：
1. **Coupang是"买家友好型"平台，卖家必须主动自保**。从反品政策到广告系统，平台设计都是优先保护消费者，卖家需要比在其他平台更主动地管理风险和证据。
2. **关键词管理是广告盈亏的分水岭**。自动广告不是"设置了就不用管"，而是"设置了必须每天管"。关键词排除比关键词添加更重要——30%的广告费可以靠排除无效关键词省下来。
