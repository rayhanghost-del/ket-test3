### 【问题案例1】쿠팡 반품 처리 — 판매자 귀책인지 고객 귀책인지 헷갈릴 때
**场景描述**：위탁판매 초보 셀러가 쿠팡에서 첫 반품을 접수했는데, "고객 변심"으로 신청됐으나 판매자 배송비 부담으로 설정돼 있어 6,000원 배송비를 떠안을 위기에 처함.
**问题分析**：쿠팡은 배송비 문제에 먼저 개입하지 않으며, 판매자가 직접 고객과 협의해야 함. 상품 설명이 모호하거나 실제와 다르면 판매자 귀책이 되고, 이 경우 무료반품 적용으로 판매자가 왕복 배송비를 부담하게 됨. 위탁판매의 경우 공급사-판매자-고객 간 3단계라 더 복잡함.
**解决方案**：
1. 쿠팡 판매자센터에서 고객 실제 휴대폰 번호 확인 (안심번호는 짧은 문자만 가능, 반품 시에는 이미 폐기된 경우가 많음)
2. 고객에게 담백하게 반품 사유 정정을 요청 — "판매자 과실이 아니므로 고객 배송비 부담으로 정정해주시면 신속 처리" 안내
3. 정정 후 도매사이트에 반품 회수 접수 → 공급사 운송장 발급 → 쿠팡 반품 관리에 운송장 등록 → 공급사가 고객에게 직접 회수
4. 공급사 검수 후 환불 → 쿠팡 자동 반품 완료 처리
**关键要点**：
- 반품 사유는 판매자/고객 중 누구의 책임인지가 배송비 부담의 분수령
- 상품 설명(특히 사이즈·색상)을 명확히 기재하고 실측 이미지 추가해 재발 방지
- 도매매 반품 사유는 "상품 자체의 문제"로 작성하면 공급사 승인이 더 쉬움

### 【问题案例2】쿠팡 직권 환불(보장환불) — 반품 상품 회수 안 됐는데 환불 완료됨
**场景描述**：판매자가 반품 상품을 회수하지도 못했는데 쿠팡이 고객에게 직권으로 환불 처리해버림. 이후 고객과 연락 두절, 물건 회수 불가, 손해 확정.
**问题分析**：쿠팡은 고객이 [배송지시·배송중·배송완료] 상태에서 반품 접수 후 영업일 60시간(약 2.5일) 내에 환불 처리가 안 되면, 회수 여부와 상관없이 "보장환불" 정책으로 쿠팡이 먼저 환불함. 판매자에게 별도 알림 없이 진행되는 경우가 많음. 판매자 귀책으로 접수된 반품은 영업일 4일 경과 시에도 직권 환불이 적용됨.
**解决方案**：
1. 보장환불 발생 후 고객과 직접 통화해 반품 의사 확인 — 단순 변심인데 반품 취소를 안 한 경우가 많음
2. 안심번호가 폐기됐다면 쿠팡 고객센터(1577-7011)에 전화해 "연락 가능한 실제 번호" 요청
3. 문의게시판에 "회수지원 요청" 글 작성 — 쿠팡이 고객에게 연락해 회수일정 조율
4. 회수가 계속 안 될 경우 별도 신청 없이 쿠팡이 재정산 처리(반품 환불금 회수)
**关键要点**：
- 반품 관리는 판매자가 능동적으로 모니터링해야 함 — 쿠팡이 먼저 알려주지 않음
- 고객센터 통해 실번호 확인과 회수지원 요청은 번거롭지만 필수
- 미회수 반품의 재정산은 자동으로 이루어지므로 너무 불안해하지 말되, 회수지원 요청은 반드시 해야 함

### 【问题案例3】쿠팡 광고 키워드 관리 실패 — AI 자동 키워드가 광고비를 낭비시킴
**场景描述**：쿠팡 자동 광고(AI 스마트 광고·매출 최적화 광고)를 사용 중인데, 상품은 '구두'인데 키워드로 '운동화'가 매칭되고, '셔츠'인데 '맨투맨'이 매칭되는 등 상품과 무관한 키워드가 추가됨. 한 셀러는 최대 1,900만 원의 광고비 손해를 봄.
**问题分析**：쿠팡의 수동 광고를 제외한 모든 자동 광고는 별도로 키워드 제외(네거티브 키워드)를 해야 함. AI가 자동으로 확장 키워드를 추가하는 과정에서 연관성이 낮은 키워드가 섞이고, 이를 방치하면 클릭은 발생하지만 전환이 안 되는 "돈 먹는 키워드"가 계속 축적됨. 특히 대형 키워드는 노출과 클릭이 많지만 전환율이 낮아 애매한 상황을 만듦.
**解决方案**：
1. 매일 광고 보고서 확인 — 상품별·키워드별 ROAS와 전환율 모니터링
2. 자동 광고 초기 3~5일 내에 무관련 키워드 제외 작업 필수
3. 주 1회 단위로 키워드 성과 분석 후 전환이 발생하지 않는 키워드는 제외 처리
4. 대형 키워드의 경우 입찰가를 점진적으로 상향하되, 전환율이 낮으면 과감히 제외
5. 구매 의도가 높은 세부 키워드(롱테일)에 예산 집중
**关键要点**：
- 수동 광고를 제외한 모든 자동 광고는 "키워드 제외"가 필수 — 쿠팡은 기본 제공하지 않음
- 광고는 상품 경쟁력 있는 제품에 투입해야 함 — 상세페이지·리뷰·가격이 부실한 상태에서 광고는 낭비
- 초기 3~5일의 키워드 정제가 전체 광고 효율을 좌우함

### 【问题案例4】쿠팡 윙(WING) 무자본 판매의 함정 — 마진 계산 실패와 60일 정산 주기
**场景描述**：부업으로 쿠팡 윙 판매를 시작한 초보 셀러가 SPEEDGO로 대량 등록 후 하루 25건 주문이 들어오자 성공을 확신했으나, 정산 받아보니 오히려 손해를 보고 있었음. 결국 400만 원 자본 소진 후 철수.
**问题分析**：300원짜리 물건을 500원에 팔면 200원 이익인 것처럼 보이지만, 쿠팡 수수료(카테고리별 4~10.9% + 결제수수료 2.9% + 부가세 10%)·배송비(고객에게 받더라도 쿠팡이 먼저 셀러에게 선차감)·광고비(쿠팡 특성상 최소 매출의 10%)를 제하고 나면 역마진. 게다가 윙 정산 주기는 60일이라 지속적인 재고 구매 자본이 필요함 — "무자본"은 환상.
**解决方案**：
1. 판매 전 역산 가격 책정 — 판매가 = (원가 + 희망 순이익) ÷ (1 - 총 수수료율)
2. 총 수수료율은 명목 수수료(예: 패션 10.5%) + 결제수수료 2.9% + 부가세 10% + 무료배송 시 3.3% + 광고비 10%+를 합산해 약 25~30% 수준으로 계산
3. 초기에는 소량 테스트 판매로 판매 가능성 확인 → 안정적이면 로켓그로스 확대
4. 정산 주기 60일을 고려한 자금 계획 수립 — 최소 2~3개월 운영비를 확보해야 지속 가능
**关键要点**：
- 쿠팡 판매 = 광고라고 생각할 정도로 광고비는 필수 비용 — 계산에 반드시 포함
- 로켓그로스 물류비까지 합하면 실제 부담은 13~18% 수준, 저마진 상품은 입점 자체가 위험
- 대량 등록은 귀찮음의 대가 — 상품 하나하나 마진 검증 후 등록해야 함

### 【问题案例5】로켓그로스(판매자로켓) 입고 거절 + 로켓배송 전환 압박
**场景描述**：로켓그로스로 월 1억 이상 수익을 올리던 판매자가 로켓배송(직매입) 전환 제안을 거절하자, 쿠팡으로부터 판매자로켓 신규 입고 중지 및 상품 등록 제한 통보를 받음. 베스트 상품 1~5위가 판매 불가 상태로 전환됨.
**问题分析**：쿠팡은 수익성 높고 재고 회전이 빠른 판매자로켓 셀러를 골라 로켓배송(1P·직매입)으로 전환시키려는 경향이 있음. 판매자로켓은 수수료+물류비가 들지만 재고는 판매자 부담, 반면 로켓배송은 쿠팡이 직매입해 재고 부담을 없애고 가격·수량 통제권을 취함. 거절 시 입고 중지·등록 제한 등의 "보복성" 조치가 발생한다는 판매자들의 증언이 다수.
**解决方案**：
1. 입고 거절 사유 TOP5를 철저히 회피 — 바코드 미부착/불량, 포장 규격 미준수, 유통기한 잔여 70% 미만, 상품 수량 불일치, 라벨 정보 오류
2. 거절 시 반송비(건당 2,000원+)는 셀러 부담이므로 입고 전 꼼꼼히 점검
3. 로켓그로스 세이버 가입 여부 분석 — 수수료 및 반품비 절감 효과가 있는지 확인
4. 쿠팡의 로켓배송 전환 제안이 왔을 경우, 마진율과 재고 통제권을 고려해 신중히 결정 — 전환 후 마진율이 15%→28%로 개선된 사례도 있지만 1P의 가격 통제 리스크도 존재함
**关键要点**：
- 입고 거절은 셀러가 예방할 수 있는 영역 — 바코드(표준바코드 또는 쿠팡바코드), 포장 규격, 유통기한 70%+를 철저히 준수
- 로켓그로스 보관료는 일 25~50원/CBM — 재고 회전이 느린 상품은 보관료가 이익을 잡아먹음
- 쿠팡과의 갑질 분쟁 시 국민신문고·변호사 상담·공정거래위원회 신고 등 대응 채널은 있지만 실제 해결은 어려운 경우가 많음

### 【问题案例6】2026년 무료배송 기준 변경 — 쿠폰·즉시할인 적용 후 금액 기준으로 변경
**场景描述**：2026년 4월 중순 쿠팡 무료배송 기준이 "쿠폰·즉시할인 적용 전 금액 19,800원 이상"에서 "적용 후 최종 결제금액 19,800원 이상"으로 변경됨. 기존에 정가 30,000원에 10,000원 쿠폰을 적용했던 상품이 무료배송 기준을 충족하지 못하게 됨.
**问题分析**：변경 전에는 높은 정가 + 대폭 쿠폰 할인 전략으로 무료배송을 유지할 수 있었으나, 변경 후에는 실제 결제금액이 기준이 됨. 와우 미가입 고객은 배송비 추가로 인한 이탈이 발생할 수 있으며, 기존에 잘 작동하던 쿠폰 전략이 무력화됨. 특히 저가 상품 위주로 운영하던 셀러에게 직접적 타격.
**解决方案**：
1. 현재 운영 중인 모든 상품의 정가와 할인 구조를 재검토
2. 무료배송 기준(19,800원)을 충족하는 최종 결제가를 유지할 수 있도록 정가·할인율 재설정
3. 와우 미가입 고객의 이탈을 막기 위해, 19,800원 미만 상품은 묶음 판매·세트 구성으로 객단가 상승
4. 무료배송 설정 시 추가 3.3% 배송 수수료가 부과됨을 고려해 마진 재계산
**关键要点**：
- 2026년 4월 기준 변경은 할인 전략 전면 재검토를 요구하는 중대 정책 변화
- 무료배송은 전략적으로 선택해야 할 옵션 — 모든 상품에 무조건 적용하면 수수료 부담이 커짐
- 와우 회원(무료배송 혜택) vs 비회원(유료배송) 구분 전략 수립 필요

### 【运营技巧】쿠팡 상세페이지 SEO + 모바일 최적화로 검색 노출과 전환율 동시 잡기
**适用场景**：신상품 런칭 초기(상품 등록 후 5~7일은 '최신성 점수' 적용), 검색 노출은 되는데 클릭·전환이 안 되는 상품, 모바일에서 상세페이지 이탈률이 높은 경우
**具体操作**：
1. 상품명 작성 — 핵심 키워드를 앞쪽에 배치, 브랜드명 + 상품 특성 + 용량/사이즈 순서. 250자 검색어 공간을 최대한 활용하되 키워드 반복은 피하고 자연스럽게
2. 썸네일 — 흰색 배경 필수(2026년 정책), 1000×1000px 이상, 로고·마케팅 문구 전면 금지, 상품 특장점이 한 눈에 들어오는 대표성 있는 이미지
3. 상세페이지 구조 — 모바일 80% 접속을 고려한 세로 스크롤 최적화
