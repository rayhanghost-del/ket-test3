### 【问题案例1】包装拆封后退货被拒——2026年Coupang退货政策大改
**场景描述**：卖家收到退货申请，商品只是外包装拆开查看，却被客服以"包装破损导致商品价值降低"为由拒绝退货，客户因此投诉。
**问题分析**：Coupang从2025年底开始大幅强化了退货检查标准。过去"不问理由免费退货"时代结束，现在连Coupang Wow会员也必须通过严格检查。核心标准是：包装是否属于"商品价值的一部分"。
**解决方案**：
1. 区分退货类型——客户原因（变心）vs 商品缺陷。缺陷类退货不受包装限制
2. 在商品页显著标注"包装破损不可退"的品类：服装（标签）、鞋子（鞋盒）、电子产品（塑封/贴纸）、CD/DVD/游戏
3. 提醒客户在退货前拍照留证：商品状态、配件、包装
4. 若退货被拒，要求客服提供具体检查照片和拒绝理由代码
**关键要点**：
- 2026年起单纯变心退货必须保持包装完好，否则大概率被拒
- 生鲜食品已试点"自助退款"（2025年12月起），上传照片即可不退货直接退款
- 频繁恶意退货的客户会被限制使用Coupang服务

### 【问题案例2】广告费烧掉300万ROAS却只有80%——自动广告依赖症
**场景描述**：某卖家每月投入300万韩元Coupang自动广告，结果ROAS仅80%，不仅没赚钱反而在赔本卖。
**问题分析**：2025年起Coupang大幅扩展了AI自动关键词优化，很多卖家误以为"全自动=最优化"。实际上自动广告在数据积累初期会大量消耗预算在不相关关键词上，如"免费"、"样品"、"二手"等无购买意图搜索词。
**解决方案**：
1. 初期采用"自动+手动"混合策略：自动广告收集数据2周，手动锁定高转化词
2. 每周下载搜索词报告，把购买转化率0%的关键词加入否定词（Negative Keywords）
3. 区分品牌词（低竞价即可）与一般关键词（需竞价竞争）
4. 时间预算分配：下午6-9点黄金时段分配150%预算，凌晨降至50%
**关键要点**：
- 纯自动广告依赖是最常见的烧钱陷阱，必须人工干预
- 品牌词和一般词必须分开管理，避免内部竞价抬高成本
- 目标ROAS应设300%以上，低于200%持续3天立即停投检查

### 【问题案例3】因回复慢导致搜索曝光暴跌40%——CS响应率陷阱
**场景描述**：1人运营的卖家周末没看手机，漏掉几个客户咨询，结果响应率跌破95%，失去"优秀卖家"徽章，接下来一周搜索曝光和销售额双双暴跌40%。
**问题分析**：2025年6月后Coupang强化了客服政策：24小时内必须响应，响应率95%+、订单处理率98%+、退货率5%以下才能获得"优秀卖家"徽章。这个徽章直接影响搜索排名和广告效率。
**解决方案**：
1. 安装Coupang Wing App并开启推送，确保24小时内即时感知新咨询
2. 建立FAQ模板库（配送、商品规格、退换货流程），但模板外必须加一句个性化回复
3. 客服回复采用3段公式：①共情道歉 ②具体解决方案 ③后续跟进邀请
4. 周末/节假日安排轮值或委托CS代运营，不能有空窗期
**关键要点**：
- "收到"、"谢谢"等无意义单字回复也会被系统判定为不合格
- 客户常问的问题必须及时更新到商品详情页，从源头减少咨询量
- CS不仅是成本中心，而是ROAS提升工具——响应率达标后平均ROAS提升30%

### 【问题案例4】入库被拒损失运费——火箭增长入仓5大失败
**场景描述**：新手卖家首批发了200件货到Coupang物流中心，结果因条形码贴错规格、包装不符合要求、保质期剩余不足70%等原因被整批拒收，承担往返运费损失+错过上新黄金期。
**问题分析**：火箭增长入仓有严格的检查标准，被拒后每件要承担2000韩元+的返送费。常见问题：条码缺失/错误、包装尺寸超标、保质期过短、数量不符、标签信息错误。
**解决方案**：
1. 入仓前自检清单：①Coupang专用条码（40×20或100×150）②包装无破损③保质期剩余70%+④数量与申报一致⑤外箱标注"Coupang退货"
2. 首次入仓建议先发20-50件测试，确认流程无误后再大批量发货
3. 使用Coupang的快递发货（自有物流揽收服务）比第三方快递更安全
4. 建立入仓证据：拍照/视频记录商品状态，纠纷时可作为凭证
**关键要点**：
- 体积大、周转慢的商品要警惕仓储费"炸弹"——日均25-50韩元/CBM
- 库存管理是火箭增长的命脉：缺货导致搜索排名下降，积压导致仓储费侵蚀利润
- 建议保持20-30%以上毛利率，否则火箭增长的综合费用会直接吃掉全部利润

### 【问题案例5】药品关键词触发广告封停3个月——健康品类禁区
**场景描述**：某健康食品卖家在广告中使用了"治疗"、"功效"等关键词，结果不仅广告被拒，整个账号被暂停广告投放权限3个月，销售额下降70%。
**问题分析**：2025年起健康食品类广告审核大幅收紧，医疗相关词汇属于绝对禁区。广告被拒多次会触发账户级惩罚，而且申诉周期很长。
**解决方案**：
1. 建立健康品类禁用词库：치료(治疗)、효능(功效)、예방(预防)、치료제(治疗剂)、약(药)等
2. 使用替代表述：用"有助于"、"帮助管理"、"营养支持"等模糊功能性描述
3. 广告素材提交前先用Coupang预审工具自查
4. 账户被封立即提交书面申诉（非简单邮件），附上产品注册证和合规声明
**关键要点**：
- 健康食品不是药品，任何暗示治疗效果的表述都违规
- 账户级惩罚的恢复期可达1-3个月，期间即使换商品也无法投放广告
- 2026年广告审核已引入AI初筛，人工申诉窗口变窄，预防比补救重要100倍

### 【问题案例6】"免费配送"文案导致广告被拒——缩略图政策踩雷
**场景描述**：卖家在商品缩略图上添加了"免费配送"、"最低价"、"限量发售"等促销文字，结果广告审核连续被拒，错过大促节点。
**问题分析**：2025年起Coupang广告缩略图政策升级：必须白色背景，严禁任何Logo或营销文案。很多卖家还在用旧版"大字报"式图片，导致审核失败。
**解决方案**：
1. 广告用缩略图必须：①纯白背景 ②无文字/Logo/水印 ③商品占画面70%以上
2. 商品详情页内的图片可以保留营销文案，但广告图必须纯净化
3. 建立两套图片素材：一套用于自然搜索/详情页（可带文案），一套专门用于广告投放
4. 被拒后不要重复提交，先修改图片再申诉，重复拒审会降低账户信任分
**关键要点**：
- 缩略图违规是2026年最常见的广告被拒原因，占审核失败的60%以上
- 违规次数累计会导致账户曝光限制和广告费不退的惩罚
- 建议直接参考Coupang官方广告图例模板，不要自行发挥

### 【运营技巧】长尾关键词抢占策略——新手逆袭老卖家的唯一路径
**适用场景**：新店铺/新商品，没有销量和评价基础，想在巨头垄断的主关键词下分一杯羹
**具体操作**：
1. 打开Coupang手机App（90%用户用手机），输入主关键词后按空格，看自动补全词——这些才是真实需求
2. 在商品名中按此结构排列：品牌名 + 长尾关键词2-3个 + 主关键词 + 规格/容量
3. 例：삼초마을 난각번호1번 동물복지 유정란 계란 40구（品牌+长尾+主词+规格）
4. 初期80%资源投入长尾词，20%试探主词。等长尾词出单积累销量后，主词排名会自动跟着上升
**效果预期**：长尾词转化率通常比主词高10倍，且竞价成本低。实测某化妆品品牌用此策略将ROAS从180%提升到470%。
**注意事项**：
- 绝不用PC端看关键词，PC和移动端关联搜索词排序完全不同
- 商品名中关键词最多重复2次，超过会被算法惩罚
- 不要一开始就想冲"尿布"、"地毯"等大词，那是大企业的战场
