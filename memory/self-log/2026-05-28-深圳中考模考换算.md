## 换算方法对比

### 方法1：直接加固定分（最常见）
503.8 + 50 + 20 = **573.8分**

**问题**：假设模考560就是中考文化分的对应部分，但模考难度通常高于中考，直接加会低估实际中考文化分的提升空间。

### 方法2：得分率换算
503.8/560 = 89.96%
89.96% × 630 = **566.7分**

**问题**：模考A+线483.5/560=86.3%，而2025年中考A+线568/610=93.1%。两套试卷难度差异巨大，得分率不能直接平移。用这个算法会严重低估高分段学生。

### 方法3：等级线定位（最合理）
- 孩子超A+线：503.8 - 483.5 = **20.3分**
- A+线到满分：560 - 483.5 = 76.5分
- 孩子在A+线之上的相对位置：20.3/76.5 = **26.5%**

2026年中考A+线预估（按2025年568分等比例+实验20分）：约**586分**
中考A+线到满分：630 - 586 = 44分
同位置换算：586 + 44×26.5% = **597.7分**

**另一种验证（用A+到A线区间）**：
- 模考A+到A线差48.5分，孩子在A+线之上42%位置
- 2025年中考A+线568，A线534，差34分
- 同位置：568 + 34×42% = 582.3
- 换算到630体系：582.3 × 630/610 = **601.4分**

## 结论

**孩子预估中考分：598-602分区间，稳A+，四大名校水平。**

如果抖音视频算出来是：
- **570左右** → 低估了，用的是得分率法或直接加法，没考虑模考难度差异
- **600左右** → 有道理，考虑了难度修正和等级定位

## 关键判断点

模考A+线86.3% vs 中考A+线93.1% —— 这7个百分点的难度差是核心变量。高分段学生在模考中"被压缩"了，直接按得分率换算会把这个压缩带到中考预估里，所以得分率法对A+以上学生不适用。看"超A+线多少"比看"得分率多少"更靠谱。
