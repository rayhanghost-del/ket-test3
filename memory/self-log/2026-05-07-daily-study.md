### 【问题案例1】2026年4月免费配送标准突变——折扣后金额计算

**场景描述**：2026年4月起，Coupang将非WOW会员的免费配送标准从"折扣前金额19,800韩元"改为"最终实际支付金额19,800韩元"。一位销售单价15,000韩元的卖家发现，原本用20%折扣吸引顾客的策略，现在导致顾客实际支付12,000韩元，无法享受免费配送，订单量骤降。

**问题分析**：
- 政策调整前：原价19,800韩元以上的商品即使打折后低于标准，仍能享受免费配送
- 政策调整后：只有实际支付金额达到19,800韩元才免运费
- 问题本质：低价高折扣的引流策略在新政策下直接失效，且WOW非会员可能流失

**解决方案**：
1. **重新设定定价结构**：确保折扣后最终支付金额仍≥19,800韩元
2. ** Bundle（捆绑）策略**：将单价15,000韩元的商品改为2件套装（30,000韩元），既满足免运费标准又提升客单价
3. **区分会员策略**：WOW会员不受新政策影响，可加大WOW会员专属优惠力度
4. **开发高单价SKU**：增加Premium产品线，将客单价整体拉高

**关键要点**：
- 这不是"数字游戏"，是定价策略的根本性重构——必须同时考虑毛利率和竞争力
- 捆绑销售是最快见效的应对方式，还能提升客单价
- 2026年新入店卖家有前90天物流·保管·退货费用全免的优惠，当前是降低初期库存风险的好时机

### 【问题案例2】广告自动模式依赖症——月投300万韩元ROAS仅80%的亏损

**场景描述**：一位卖家将月300万韩元全部投入Coupang自动广告，结果ROAS只有80%（投入100万仅回收80万），持续亏损。调查发现，广告展示给了大量"免费""样品"等低购买意图的关键词，以及与其商品无关的搜索词。

**问题分析**：
- 2025年起Coupang大幅扩大AI自动关键词优化比例，卖家管理负担减轻的同时，也失去了对关键词的精细控制
- 自动广告会广泛匹配搜索词，大量无转化点击消耗预算
- 缺乏"负面关键词（Negative Keyword）"管理导致广告费浪费

**解决方案**：
1. **混合策略启动**：初期用自动广告收集数据，发现高效关键词后切换到手动广告精细管理
2. **每周排查无效关键词**：将转化率0%的关键词立即加入排除列表
3. **品牌词与一般词分离运营**：品牌认知度高的关键词可以用较低出价获得足够效果
4. **避免内部竞争**：同一关键词不要为多个商品同时投放，否则只会推高竞价成本

**关键要点**：
- 自动广告≠放任不管。没有负面关键词管理的自动广告就是烧钱机器
- 混合策略（自动→手动）被证实能将ROAS从180%提升至470%
- 每周必须做一次关键词效率审查，转化率5%以下的词果断排除

### 【问题案例3】健康功能食品广告关键词踩雷——3个月广告禁令

**场景描述**：一位个人事业主在健康功能食品类目投放广告时使用了"치료(治疗)""효능(效能)"等医疗相关关键词，结果广告审批被拒，更严重者账号被限制3个月无法投放广告，导致月销售额下降70%。

**问题分析**：
- 2025年起Coupang对健康功能食品类目的医疗相关关键词限制更加严格
- 卖家不了解广告政策变化，误将产品功效描述词直接用作广告关键词
- 健康功能食品属于监管严格类目，平台对虚假宣传零容忍

**解决方案**：
1. **事前审查关键词**：投放前通过Coupang广告审批系统预检所有关键词
2. **替换为合规表述**：用"건강관리(健康管理)""영양보충(营养补充)"等中性词替代医疗用语
3. **建立关键词白名单**：为每个商品建立"可用关键词库"，所有投放必须来自白名单
4. **订阅政策更新**：关注Coupang卖家公告板（Wing > 공지사항）的类目政策变更

**关键要点**：
- 不仅是广告被拒，严重时会导致账号整体受限，3个月禁令足以让新品彻底死亡
- 医疗相关词汇包括但不限于：치료, 효능, 치료제, 예방, 질환 등
- 建议使用Coupang广告合作伙伴（如OSC）的政策监控服务，或自建关键词审查清单

### 【问题案例4】入库被拒——TOP5原因导致反送费损失

**场景描述**：一位新入卖家首次向Coupang物流中心入库100件商品，结果因"包装规格不合规"和"条形码不良"被拒收，承担反送费每件2,000韩元以上，同时耽误了上架时间，错过了预定的促销档期。

**问题分析**：
- 入库被拒TOP5原因：①条形码未贴/不良 ②包装规格不合规 ③保质期剩余不足70% ④商品数量不符 ⑤标签信息错误
- 新卖家往往低估入库标准的严格性，以为"商品到了就行"
- 反送费+重新包装费+时间损失=隐性成本远超预期

**解决方案**：
1. **入库前自检清单**：
   - 条形码：每个单品独立贴码，确保扫描可读
   - 包装：确认外箱尺寸/重量符合Coupang入库规格表
   - 保质期：食品/化妆品类确保剩余70%以上
   - 标签：韩文标签信息完整（品名、成分、制造商等）
2. **小批量测试入库**：首次入库建议先送10-20件测试，确认流程无误后再大批量发送
3. **使用入库代理服务**：不熟悉流程的卖家可委托有经验的3PL公司处理首次入库

**关键要点**：
- 入库被拒的反送费由卖家全额承担，且可能产生二次包装费
- 入库失败不仅损失运费，更可能错过销售旺季（如黑五、年末等）
- 2025年起部分类目入库费用已上涨，必须更新计算模型

### 【问题案例5】仓储费黑洞——慢周转商品吃掉全部利润

**场景描述**：一位销售家居用品的卖家发现，虽然每月有稳定订单，但月底结算时利润几乎为零。排查后发现，部分SKU已在Coupang物流中心存放超过90天，产生了高额仓储费（日25-50韩元/CBM），且部分商品因长期存放被加收1.5倍费用。

**问题分析**：
- 仓储费计算方式：FIFO（先进先出），按商品尺寸×重量×存放天数计算
- 60天内售出可免仓储费，但许多卖家不了解这个规则
- 服装/鞋类/配饰有30天免费期，其他类目从入库当天起即计费
- 长期滞销库存不仅产生仓储费，还可能面临Coupang的强制废弃处理（额外收费）

**解决方案**：
1. **建立库存周转监控表**：每周检查各SKU的"入库天数"，超过45天即触发预警
2. **滞销品促销清仓**：对超过60天未售出的商品立即启动限时折扣或Bundle促销
3. **精准补货**：根据过去30天销量×1.5倍备货，避免过量入库
4. **利用退货转售功能**：开启반품 재판매选项，将退货商品以折扣价重新上架，减少废弃损失
5. **月批量返库**：对确定无法售出的库存，每月集中返库（前20件免费）

**关键要点**：
- 仓储费是"沉默的杀手"，月销100万韩元的商品如果存放90天，仓储费可能吃掉10-15%利润
- 反送（月20件内免费）和退货再入库（月20件内免费）有额度限制，超量后按商品尺寸计费
- 建议入驻前先用Coupang官方费用计算器模拟所有成本：https://sell.coupang.com/ko-kr/fee-page

### 【问题案例6】详情页加载10秒——跳出率暴增50%的反面教材

**场景描述**：某生活用品品牌B公司花费200万韩元制作了华丽的3D渲染详情页，图片精美、动画炫酷。结果上线后发现页面加载时间超过10秒，移动端跳出率暴增50%，月销售额不升反降。

**问题分析**：
- 移动端流量占Coupang总流量的80%以上，但许多卖家仍以PC端思维制作详情页
- 图片过大（单张超过200KB）、过多动画、3D效果导致加载缓慢
- 3秒是移动端加载的生死线，超过3秒每增加1秒跳出率增加约20%
- 另有卖家直接复制竞争对手详情页设计，结果因版权问题被账号封停

**解决方案**：
1. **图片优化铁律**：
   - 尺寸：移动端宽度750-1000像素
   - 单张容量：200KB以下
   - 格式：WebP优先
2. **加载速度测试**：用真实手机测试详情页，目标2秒内完成加载
3. **首屏信息优先**：第一屏必须展示产品名、价格、核心卖点，不要放装饰性大图
4. **HTML文本优先**：关键描述文字用HTML文本而非图片内嵌，有利于SEO
5. **A/B测试**：同一商品制作2版详情页，各跑2周对比转化率

**关键要点**：
- 华丽≠有效。详情页的核心是"信息传递速度"，不是"视觉震撼度"
- 2026年起Coupang的AI系统能自动检测虚假广告，使用未经验证的认证标志或获奖信息最高可处1亿韩元罚款
- 字体版权也是常见雷区——某D公司因使用"免费"字体被索赔500万韩元

### 【运营技巧】商品名SEO结构——广告成败70%在商品名决定

**适用场景**：所有新上架商品、转化率低于2%的老品优化、广告ROAS持续低迷时

**具体操作**：
1. **商品名标准结构**：`品牌名 + 子关键词2-3个 + 主关键词 + 容量/规格`
   - 示例：`삼초마을 난각번호1번 동물복지 유정란 계란 40구`
   - 解析：品牌(삼초마 village) → 子关键词(난각번호1번, 동물복지, 유정란) → 主关键词(계란) → 规格(40구)
2. **关键词顺序**：主关键词尽量靠前，Coupang搜索算法重视关键词位置
3. **参考竞品**：查看同类目Best Seller前10名的商品名结构，模仿但不抄袭
4. **避免错误**：
   - ❌ 特殊符号过多
   - ❌ 重复堆砌同一个词
   - ❌ 缺少容量/规格信息
   - ❌ 使用"正品""100%"等无法验证的表述

**效果预期**：
- 商品名优化后，自然搜索曝光量可提升30-50%
- 配合广告时，CPC成本降低（质量分提升）
- 新商品在前2周内获得更好初始排名

**注意事项**：
- 不要频繁修改已稳定销售的商品名——每次修改会导致搜索排名重新计算
- 修改最佳时机：凌晨2-4点（韩国时间），此时流量最低，影响最小

### 【运营技巧】时间带预算分配——黄金时段ROAS提升40%

**适用场景**：日预算3万韩元以上的广告主、ROAS长期低于300%的账号、有明确高峰时段的品类（如食品晚餐时段、母婴用品夜间时段）

**具体操作**：
1. **分析购买高峰**：在Coupang Wing后台查看"주문 시간대 분석"，找出订单最集中的2-3个时段
2. **黄金时段加码**：
   - 晚6点~9点（晚餐后购物高峰）：预算设为平时的150%
   - 凌晨0点~2点：预算降至平时的50%
3. **工作日/周末区分**：周末上午10点~下午2点可能是另一个高峰，需单独设置
4. **Campaign分组**：将同一类商品按高峰时段分组，分别设置时间带预算

**效果预期**：
- 相同预算下ROAS平均提升30-40%
- 减少低转化时段的预算浪费
- 在竞争最激烈的黄金时段保持足够曝光

**注意事项**：
- 新账号前2周建议全天均匀投放，先收集时间带数据再优化
- 调整幅度不要超过±50%，过大波动会影响广告系统学习

### 【运营技巧】退货转售（반품 재판매）——降低退货损失的隐藏功能

**适用场景**：Rocket Growth卖家、退货率较高类目（服饰15-20%）、希望最大化退货商品价值的卖家

**具体操作**：
1. **开启路径**：쿠팡윙 > 로켓그로스 > 고객반품 관리 > 반품 재판매 옵션 → ON
2. **理解等级与折扣**：
   - 反品-未开封（미개봉）：折扣率最低，接近原价销售
   - 反品-最优（최상）：轻微折扣
   - 反品-上等（상）：中等折扣
   - 反品-中等（중）：较大折扣
3. **自定义折扣**：系统按补偿率自动设定折扣，但卖家可手动调整
4. **补偿金计算**：反品补偿金 = (销售价 - Rocket Growth费用) × 等级补偿率(3%~20%)

**效果预期**：
- 反品如果不开启转售，会自动返库，产生返库运费+再入库费
- 开启转售后，反品重新上架销售，无额外处理费用
- 适合反品率高的卖家月省数万韩元处理费

**注意事项**：
- 转售商品会在详情页显示为"반품-XX"等级，部分消费者可能介意
- 2024年1月16日前注册的商品，默认可能为OFF，需手动开启
- 反品再入库也会产生仓储费（从再入库日起重新计算）

## 【今日总结】

### 核心洞察
1. **政策即命脉**：2026年4月的免费配送标准变更不是小调整，而是整个定价策略的底层逻辑改变。所有依赖"低价高折扣"引流模式的卖家必须立即转型，捆绑销售和客单价提升是唯一出路。

2. **广告管理必须有人**：AI自动化的时代，自动广告能帮你收集数据，但不能替你决策。没有负面关键词管理和时间带分配的自动广告，等同于把钱扔进大海。每周花2小时审查广告数据，是ROI最高的2小时。

3. **入库不是终点而是风险点**：很多卖家把心思全放在选品和广告上，却忽视入库这个"最后一公里"。一次入库被拒的损失（反送费+时间成本+错过档期）可能超过当月广告预算。

### 实操建议
- **今天就做**：打开Wing后台，检查所有商品的定价是否满足"折扣后≥19,800韩元"的新标准，不满足的立即调整或改为Bundle
- **本周完成**：下载过去30天的广告搜索词报告，把所有转化率0%的关键词加入Negative Keyword列表
- **本月建立**：为每个SKU建立"入库天数"追踪表，设定45天预警线，超过即启动促销清仓
