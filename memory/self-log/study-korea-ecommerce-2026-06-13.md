

## 补充学习：KC认证、中韩税收协定、Coupang入驻实操

### 七、KC认证详解（韩国强制性安全认证）

#### 什么是KC认证
- **KC = Korea Certification**，韩国电子电气用品安全认证制度
- 依据《电器用品安全管理法》，2009年1月1日开始实施
- 韩国技术标准院（KATS）主管
- 2009年7月起统一采用KC Mark标志，替代之前的13种强制标志

#### KC认证分类（按风险等级）

| 认证类型 | 说明 | 证书有效期 | 工厂审查 |
|---------|------|----------|---------|
| **强制性安全认证** | 危险性较高的产品 | 无，需年检维持 | 首次验厂+每年跟踪审查 |
| **自律性安全确认** | 中等风险产品 | 5年 | 不需要 |
| **供应商自我确认（SDoC）** | 低风险产品 | 无证书，确认书永久有效 | 不需要 |

#### 2026年新增强制品目
- 充电桩、部分智能家电、无线充电设备、PDU等
- 注意：原自律产品可能转为强制，需核对最新目录

#### 产品范围（AC 50V~1000V电气产品）

**强制性安全认证（57品目）：**
- 电线电缆、电气开关、电容与电源滤波器
- 电气保护部件（保险丝、断路器）
- 家用绝缘变压器、稳压器
- 家用电器（36品目，额定10kW以下）
- 电动工具、音视频设备、IT办公设备（18品目）
- 照明机器

**自律性安全确认（95品目）：**
- 电气开关控制端子、部分变压器
- 家用电器（35品目）、音视频设备（34品目）
- IT办公设备（18品目）、照明机器（5品目）

**特殊要求：**
- 带无线功能（WiFi/蓝牙）的产品：**KC安全认证 + KCC无线认证**双认证
- KCC认证需向RRA（无线电研究院）申请型号核准

#### KC认证申请流程
1. 准备样品和资料递交检测机构
2. 检测机构转交KTL/KTC进行测试
3. KTL/KTC进行Safety测试，出具KC测试报告
4. 安全认证需安排验厂，后续每年年度审厂
5. 审核报告及申请文件无误后签发KC证书

**周期：** 常规4-6周（可加急，需另付费用）

#### 所需资料
1. 相关申请表
2. 产品标签（需韩文，可附加英文）
3. 产品说明书（韩文版）
4. 零部件清单
5. 派生型号清单
6. 电路图及Layout
7. 零部件证书
8. 变压器、电感等规格书
9. CB证书及报告（如有，可简化流程）

#### 费用预估
- **基础费用（无无线功能）：** $3,000~$6,000（含测试、申请、代理）
- **含无线功能（需KCC）：** $5,000~$10,000+
- **高功率或复杂产品：** 可能超过$10,000

**费用构成：**
- 安全测试（IEC 62368-1）：$1,000~$3,000
- EMC测试：$1,000~$2,500
- 代理服务费：$500~$2,000
- 工厂审查：$1,000~$3,000
- 技术文档翻译（韩文）：另计

#### 认证机构
- 韩国本土：KTL、KTC
- 国际机构：TÜV、SGS
- 证书上需标注：型号名称、制造商、额定电压（韩文+可选英文）

### 八、中韩税收协定（双重征税避免）

#### 协定核心信息
- **签署时间：** 1994年签署《中华人民共和国政府和大韩民国政府关于对所得避免双重征税和防止偷漏税的协定》
- **核心宗旨：** 避免双重征税 + 防止偷漏税
- **享受方式：** 韩国实行备案制，非居民纳税人到税务机关办理备案即可享受

#### 税收管辖权划分
- 服务贸易征税权一般归属于**居民国**，除非在来源国构成常设机构
- 常设机构判定：管理场所、分支机构、办事处、工厂等固定营业场所
- 建筑/安装/劳务工程：任何12个月连续或累计超过**6个月**即构成常设机构

#### 常设机构豁免情形
- 仅为储存、陈列或交付货物而设的固定场所
- 专为采购、搜集情报、准备性或辅助性活动而设的固定场所
- 单纯的展示店或物流中转仓在特定条件下可申请免税

#### 利润汇回：三费减免税率

| 所得类型 | 协定优惠税率 | 无协定税率 | 条件 |
|---------|------------|----------|------|
| **股息** | 5% | 更高 | 母公司直接拥有至少25%股份 |
| **股息** | 10% | 更高 | 其他情况 |
| **利息** | 10% | 更高 | - |
| **特许权使用费** | 10% | 更高 | 技术/商标/配方等 |

#### 消除双重征税方法
- 中国居民从韩国取得的所得，在韩国缴纳的税额可在中国应纳税额中**抵免**
- 抵免额不超过按中国税法计算的数额
- **税收饶让条款：** 韩国给予的减免税数额可视同已缴税额在中国抵免

#### 外派人员个税优惠
- 外派人员在12个月内在韩国停留**连续或累计不超过183天**
- 且报酬并非由韩国居民雇主或常设机构负担
- 则薪金报酬**仅在中国征税**，无需在韩国缴税

#### 争议解决
- 相互协商程序：在不符合协定规定的征税措施第一次通知之日起**3年内**提出
- 主管当局协商解决税收协定解释和适用问题

#### 风险提醒
- 未主动享受协定待遇 → 多缴税款风险
- 未申请税收饶让抵免 → 损失抵免额风险
- 对协定应税项目错误适用国内法税率 → 退税风险

### 九、Coupang入驻实操详解

#### 平台基本数据（2024-2025）
- 注册会员超过韩国人口半数
- 平均每周每用户花费超过100美金
- 日活移动用户数量是第二名的三倍
- 2024年占据韩国电商市场**50%份额**
- 2300万+活跃买家

#### 跨境店铺入驻

**入驻条件：**
- 中国大陆、港澳台注册的企业（营业执照有效期至少1个月）
- 公司类型：股份有限公司、有限责任公司、个人独资企业、合伙企业
- **不接受个体工商户**
- 有跨境电商销售经验，有一定SKU数量
- 可接收人民币/美金/港币/韩币的对公账户

**所需资料：**
1. 公司营业执照（需正规翻译公司翻译盖章）
2. 法人身份证或护照（有效期3个月以上）
3. 法人手持身份证/护照自拍
4. 银行账户证明（对公账户银行对账单/开户证明/账户清单/开户许可证/基本存款证明）
5. 联系方式有效性证明（近6个月内话费发票，显示法人或公司名）
6. 其他跨境平台有效结算证明（确认平台名、公司/法人名、销售额、销售周期、货币类型）
7. 收款账户：目前接受 **PingPong、LianLian Pay、WorldFirst、Airwallex、Payoneer**

**入驻流程：**
1. 注册Coupang Marketplace账户（英文填写）
2. 邮箱验证 → 申请成为卖家
3. 创建WING登录用户名（卖家后台管理系统）
4. 填写公司详情、联系人详情（至少1位企业主/法人）
5. 填写银行账户详情
6. 上传所有资料提交申请
7. 审核通常需**5-10个工作日**

**平台费用：**
- **注册费用：** 0成本（免费入驻）
- **月租费：** 无月租费或年费（普通卖家）；高级卖家套餐约30-50美元/月
- **佣金：** 按品类收取，5%-15%
  - 服装类：15%
  - 电子产品：8%-10%
  - 日用品/快消品：约10%
- **广告费：** CPC按点击付费，平均每次点击0.1-1美元
- **物流费：** 
  - 小型商品（1kg以内）：约1-2美元/件
  - 中型商品（5kg以内）：约3-5美元/件
  - 大型商品（10kg以上）：可能超10美元/件

#### 本土店铺入驻

**入驻条件：**
- 韩国公司主体（须拥有韩国营业执照，可以是中国法人）
- 公司注册类型：个人投资公司、境外公司投资公司、境外公司的分公司
- 公司对公账户复印件
- 网络销售许可证
- 韩国本地联系号码

**注册成功后需完成：**
1. 开设韩国企业对公银行账户（用于Coupang资金结算）
2. 办理韩国手机号（用于平台验证和日常操作）
3. 提交Coupang本土店入驻申请

**本土店优势：**
- 流量支持更多（首页推荐、促销活动、本地广告位）
- 消费者信任度更高
- 可售类目更广
- 尾程配送费折扣
- 促销活动免费参加
- 回款周期更快

**本土店费用：**
- 无月租费
- 佣金：5%-10%（比跨境店更优惠）
- 火箭仓（Rocket Fulfillment）服务费根据实际使用情况

#### 物流模式

**跨境店：**
- 自发货模式为主
- 山东威海是距离韩国较近的国内城市，有低价出韩物流
- 需保证配送时效，否则易遭投诉或退货

**本土店（火箭仓）：**
- 入库到Coupang Rocket Fulfillment仓库
- 享受火箭配送（次日达/当日达）
- 仓储费按商品存放时长和占用空间收取
- 滞销商品会增加仓储费

#### 注意事项
- 平台规则相对"原始"，对中国卖家友好
- 现阶段无需大量广告投入也能获得订单
- 退货政策宽松，退货成本可能严重影响利润
- 需缴纳10%增值税（VAT），需按时申报
- 韩国消费者不确定跨境店商品是否正品，更倾向本土店

### 十、学习总结与行动建议

#### 核心要点回顾
1. **市场：** 韩国电商全球第四，1700亿美元规模，Coupang占50%份额，消费者对物流/售后要求极高
2. **产品：** 家具、3C、运动户外、服饰是热门品类；3C需KC认证，认证周期4-6周，费用$3000-$10000+
3. **法律：** 消费者保护极强，信息披露要求严格，平台责任相对清晰，需遵守个人信息保护法（PIPA）
4. **税务：** 韩国增值税10%，中韩税收协定可避免双重征税，股息/利息/特许权使用费预提税上限10%（股息可低至5%）
5. **运营：** 本土店优势明显但需注册韩国公司；跨境店门槛低但流量和信任度受限

#### 实操建议
1. 若目标3C品类，尽早启动KC认证（需韩文说明书，周期4-6周）
2. 若长期经营，建议注册韩国本土公司开本土店
3. 税务上务必办理税收协定备案，享受协定优惠税率
4. 物流优先选择山东威海等近韩城市，缩短时效
5. 预留充足的退货处理预算，韩国退货政策宽松

#### 下一步可深入研究
- 韩国公司注册具体流程和费用
- 韩国本地银行开户要求
- 韩国消费者行为与营销偏好（KOL/KOC营销）
- 韩国各品类KC认证具体标准
- 中韩税收协定的具体备案流程
