## 一、韩国电商平台格局

截至2024年Q2，韩国前五大综合电商平台（Coupang、Gmarket、Auction、Wemakeprice、11st）合计占据本土在线零售市场份额 **78.3%**（韩国电子商务协会数据）。

### 1. Coupang（쿠팡）
- **地位**：韩国最大B2C电商平台，成立于2010年，总部首尔
- **费用**：佣金 8%~15%（按品类），物流强制使用 Coupang Fulfillment
- **结算**：T+5，月销售额门槛 100万韩元，结算手续费 5万韩元
- **入驻**：Coupang Global Seller，需公司信息+银行账户，可用 Payoneer 收款
- **物流**：威海跨境小包（新手模式）/ CGF火箭仓（深圳仓，流量扶持）
- **时效要求**：48小时未揽收→差评率上升3.7倍

### 2. Gmarket（지마켓）
- **地位**：韩国TOP级综合电商平台，成立于2000年，覆盖64%韩国用户
- **费用**：佣金 5%~15% + 交易手续费 2.5%，无月租/年费/保证金
- **结算**：配送完成8天后自动确认收货，次日结算（营业日为准）
- **结款方式**：海外卖家需设外汇账户，手动/自动申请汇款，周一或周四汇出
- **入驻流程**：申请→初审（2个工作日）→平台审核→10~12个工作日入驻
- **物流**：自发货无限制，但建议韩国本地仓

### 3. 其他平台
- **Auction**：韩国电商巨头之一
- **11st**：综合电商平台
- **Wemakeprice**：团购/折扣平台

## 二、运营核心要点

### 物流策略
- 头部卖家普遍采用 **"中国仓+韩国海外仓"双轨模式**
- 主要海外仓：菜鸟韩国保税仓（仁川）、万邑通（Incheon ICD）、Coupang Fulfillment
- 目标：**72小时内出库**，韩国消费者对履约时效容忍度极低

### 本地化运营
- **韩语详情页**：转化率比机器翻译高 **4.3倍**（Naver Shopping 2024 A/B测试）
- **韩语客服**：平台强制要求
- **直播电商（Live Commerce）**：2023年韩国直播电商GMV达3.2万亿韩元，同比增61.4%

### 选品策略
1. **数据驱动**：用 Naver Shopping、Itemscout、Coupang极客选品做关键词/竞品分析
2. **季节性**：韩国气候与国内相近，但某些运动品类（如滑雪、高尔夫）渗透率更高
3. **节假日**：新年、儿童节、开学季、中秋节、万圣节、圣诞节，需提前 **45天** 上架
4. **品类建议**：化妆品（增长率46.7%）、食品饮料（29.5%）、家电（21.9%）

### 运营模式
- **跟卖**：初级玩法，平台政策收紧易崩盘
- **铺货**：中等风险
- **精品**：长期可持续，需配合运营能力

## 三、法律法规

### 1. 《电子商务交易中消费者保护法》
- 企业须维护消费者信息安全
- 电子支付时须通知消费者
- 第三方不当使用消费者信息造成损害 → 经营者须赔偿
- 保存交易记录（广告、合同内容、履行记录）
- **处罚**：不遵守整改命令 → 3年以下有期徒刑或1亿韩元以下罚金

### 2. 《个人信息保护法》（PIPA）
- 规范个人信息的收集、使用、传播、存储、销毁
- **核心要求**：
  - 收集/使用/传播个人信息须获得同意
  - 个人信息泄露 → 须及时通知受影响个人，必要时报告当局
  - 目的达成后须销毁信息
- **处罚**：金钱赔偿、罚款、法定损害赔偿；**未经同意收集个人信息可受刑事处罚**
- 集体诉讼救济：个人数据泄露可提起集体诉讼

### 3. 2024年韩国加强海外直购监管动向
- 加强AI大数据监测，引入信息实时匹配封锁系统
- 指定海外平台国内代理人，负责消费者损害救济
- 删除未获KC认证产品的销售信息
- 考虑修订小额进口商品免税制度
- 到2026年建立电商危险品进口优化通关平台

### 4. 平台特别规则（以Gmarket为例）
- 禁止虚假交易、拍卖投标造假
- 禁止诱导直接交易（不能在详情页放外部链接、个人账号）
- 禁止重复登记、错类别登记
- 禁止使用与平台混淆的店铺名（如G마켓、지market等）
- 禁止使用作弊关键词（其他卖家名称、无关搜索词）
- 2017年8月起强制要求填写发货规定和预计发货日

## 四、税务条款

### 1. 增值税（VAT）
- **标准税率：10%**
- 进口增值税 = 10%（与关税不同，属于流转税，可抵扣）
- 平台售价一般已含10% VAT，但 **平台不代扣代缴**
- 卖家需自行申报缴纳，**每季度一次**（小微企业可按季度）

### 2. 进口关税
- 普通商品关税率：**0~5%**（按产品编码/品类/数量）
- 关税 = 进口货物成本，**不可抵扣**（与VAT不同）
- **注意**：不建议走"包税"清关，因为包关时不用韩国公司抬头，缴纳的VAT无法在后续销售中抵扣
- 税务监管严格：货款和进口清关成本必须一致

### 3. 法人税（企业所得税）
| 利润区间 | 税率 |
|---------|------|
| 不足2亿韩元（约110万RMB） | 国税9% + 地方税0.9% = **9.9%** |
| 2亿~200亿韩元 | 19.9% |
| 超过200亿韩元 | 25.2% |

- 计算公式：收入 - 货品成本 - 物流成本 - 平台/广告/杂费 = 营业利润

### 4. 税务合规要点
- 在韩国税务局注册，获取税务识别号
- 离岸公司（在韩国注册但无实地经营）→ 不需交税，但需年审
- 实地经营公司 → 每月/每年提交财务报表，进行年审
- 收款合规：单笔超$5万美元需外管局备案（中国卖家）

## 五、本周学习总结

| 维度 | 关键发现 |
|------|---------|
| 平台 | Coupang最大但要求高，Gmarket门槛较低、入驻快 |
| 物流 | 威海直发适合新手，长期必须走韩国本地仓 |
| 本地化 | 韩语客服+韩语详情页是硬性要求，直播电商增长极快 |
| 法律 | PIPA对消费者保护和数据合规要求极高，2024年起监管明显收紧 |
| 税务 | VAT 10%自行申报，进口关税0~5%不可抵扣，法人税按利润累进 |
| 风险 | 包税清关VAT无法抵扣；虚假交易/诱导直接交易处罚重 |
