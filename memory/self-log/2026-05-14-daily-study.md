### 【问题案例1】卖家责任退货处理：尺寸标注不清导致卖家承担退货运费
**场景描述**：一位销售触屏防寒手套的新手卖家收到退货通知，退货理由为"实际商品与商品说明不符"——客户表示女性M/L、男性XL的标注导致自己选错尺寸。卖家原本以为是单纯变心退货，但发现被归类为"卖家责任退货"，退货运费需卖家承担。

**问题分析**：
- 商品详情页尺寸标注存在歧义，容易造成消费者误解
- 消费者以"商品描述不符"申请退货时，系统会自动归类为卖家责任
- 新手卖家对"卖家责任"与"买家责任"的区分标准不清晰，导致情绪消耗和决策困难

**解决方案**：
1. 确认退货类型：通过Coupang Wing后台「订单/配送-退货管理」查看退货原因和运费承担方
2. 判断责任归属：若商品描述确实存在歧义或误差，应认定为卖家责任，承担运费并妥善处理
3. 处理流程（代销模式）：
   - 在Coupang确认退货商品
   - 在Domeiddo（도매매）等代销平台提交退货申请
   - 获取供应商退货运单号
   - 将运单号录入Coupang退货管理系统
   - 供应商收货检验后完成退款
4. 预防措施：立即修改详情页尺寸标注，添加实测尺寸图片，明确推荐尺码

**关键要点**：
- 商品描述模糊或存在误差时，即使消费者选错，也可能被认定为卖家责任
- 处理前可通过AI工具辅助判断责任归属，减少情绪内耗
- 代销模式下需同步在供应商平台处理退货，否则无法完成闭环

### 【问题案例2】卖家评分突然归零：快递延误导致准时配送分数归零
**场景描述**：一位始终保持100分卖家评分的卖家，某天发现配送分数突然变为0分。经核查，有一单配送比预计日期晚了一天，但卖家实际上按时发货，是快递公司配送延误导致。

**问题分析**：
- Coupang的卖家评分系统中，配送分数依据预计到达日计算，而非卖家发货日
- 快递公司配送延误也会被计入卖家评分，卖家承担不公平处罚
- 评分下降直接影响商品曝光和流量分配

**解决方案**：
1. 确认责任归属：在Wing后台点击相关配送单，确认卖家发货时间 vs 实际配送完成时间
2. 若确为快递延误，通过以下路径申请卖家评分排除：
   - 访问：https://helpseller.coupang.com/hc/ko/requests/new?ticket_form_id=360000545712
   - 选择「卖家分数排除-准时配送完成」
   - 填写订单号、箱子ID（捆绑配送编号）
   - 附上发货时间截图作为证据
3. 提交后等待处理结果（通常数日内回复邮件通知）
4. 同时监控其他订单，避免同期出现多个配送问题

**关键要点**：
- 卖家评分排除申请有专门入口，不要通过普通客服渠道浪费时间
- 务必保存发货凭证截图，作为申诉核心证据
- 选择可靠的快递合作商，定期监控其配送准时率

### 【问题案例3】关联账号被封：配偶已注销账号导致本人账号被连坐
**场景描述**：A卖家本人名下运营Coupang账号，某天突然因"与过去配偶名下已注销账号存在IP、收货地址关联"而被暂停，本人账号完全独立运营，且配偶账号已注销多年，相关资料难以查找。

**问题分析**：
- Coupang对关联账号的检测逻辑包括：同一IP、同一收货/发货地址、设备指纹等
- 夫妻同居使用同一网络属于自然现象，但平台算法可能误判为关联经营
- 40%以上的账号封停案例与关联账号问题直接相关

**解决方案**：
1. 收集基础证明材料：
   - 本人与配偶的营业执照副本
   - 双方身份证复印件
   - 户口本或婚姻关系证明（证明同居合理性）
2. 撰写详细申诉书（소명서），核心论点：
   - 承认同一居住地址和网络使用事实
   - 强调"各自的事业明确分离、独立运营"
   - 具体说明各账号主力销售商品、采购渠道、销售规模完全不同
   - 说明配偶账号已注销，本人账号为独立合法经营
3. IP关联性解释：作为夫妻使用同一住址网络是自然的，不代表共同经营
4. 通过Coupang卖家中心正式提交申诉，必要时委托专业机构协助

**关键要点**：
- 关联账号申诉的核心是"证明独立性"而非否认关联事实
- 提前保留各账号独立的经营证据（不同供应商合同、不同商品品类销售记录）
- 家庭内多人从事电商时，尽量使用不同网络、不同收货地址

### 【问题案例4】自动广告关键词失控：AI匹配无关关键词导致ROAS暴跌至80%
**场景描述**：一位卖家将月广告预算300万韩元全部投入Coupang自动广告（AI智能广告/销量优化广告），但ROAS仅为80%，广告费大幅亏损。经查发现AI自动添加的关键词与商品完全无关，如卖"皮鞋"却匹配"运动鞋"关键词。

**问题分析**：
- Coupang自动广告（除手动广告外）默认自动添加关键词，卖家需主动排除
- AI匹配逻辑基于类似商品和用户行为，但常出现语义偏差
- 卖家未定期检查关键词列表，导致无效点击持续消耗预算
- 调查显示部分卖家因自动广告关键词管理不善，最高损失达1,900万韩元

**解决方案**：
1. 定期（至少每2周一次）下载搜索词报告，分析实际触发关键词
2. 立即排除无效关键词：
   - 与商品无关的关键词（如"皮鞋"匹配"运动鞋"）
   - 转化率为0%的关键词（"免费"、"样品"等低购买意图词）
   - 品牌词（若自身无品牌认知度）
3. 使用第三方工具（如Sellvy/세이비）批量分析和自动排除：
   - 连接Coupang账号后，工具每2周自动生成需排除的关键词列表
   - 一键批量排除"吃钱的关键词"
4. 将预算重新分配：
   - 手动广告：核心购买意图关键词，精准投放
   - 自动广告：仅用于发现新关键词，设置较低预算
5. 品牌词与非品牌词分离运营，降低内部竞价冲突

**关键要点**：
- 自动广告开启后前3-5天必须完成首轮关键词排除
- 每周查看广告报告是硬性要求，不能"开了就不管"
- 手动广告与自动广告组合使用，而非完全依赖自动广告

### 【问题案例5】退货处理系统缺陷：想撤销售后却没有"撤销按钮"
**场景描述**：一位卖家遇到消费者误选退货原因（如将"单纯变心"选为"卖家责任"），或经沟通后消费者同意取消退货，但Coupang系统没有提供卖家直接撤销退货的按钮，卖家不知如何操作。

**问题分析**：
- Coupang与Naver Smart Store不同，没有提供卖家一键拒绝或撤销退货的功能
- 所有退货撤销需通过客服渠道人工处理，流程繁琐
- 若不主动撤销，退货将按原流程继续，卖家可能承担不必要的退货运费和商品损失

**解决方案**：
1. 第一步：与消费者沟通确认撤销意向
   - 发送短信："您好，该退货申请为单纯变心，目前以卖家责任受理，请重新以单纯变心提交退货"
   - 或："已通过通话解决问题，您确认继续使用商品，我将为您撤销退货申请"
2. 通过Coupang Wing在线客服提交撤销申请：
   - Wing首页 → 右上角「在线客服」
   - 右下角「聊天咨询」
   - 选择「Marketplace相关咨询」→「退货/取消/换货」
   - 选择「退货撤销咨询」→「已与顾客协商完成」
   - 填写订单号、选项ID、数量、协商结果(Y)
   - 发送后关闭窗口即可（无需等待客服连线）
3. 在「我的咨询记录」中确认处理状态
4. 处理完成后邮件通知会发送，退货管理列表中该记录会消失
5. 如需重新受理退货（改为买家责任），在「配送管理-取消/退货受理」中重新登记

**关键要点**：
- 撤销退货前务必先与消费者短信确认，保留沟通证据
- 撤销流程无需等待人工客服连线，填写表单后直接关闭即可
- 若消费者能自行撤销，优先引导消费者自助操作

### 【问题案例6】Rocket Growth仓储费暴增：库存周转慢导致利润被仓储费吃掉
**场景描述**：一位使用Coupang Rocket Growth（로켓그로스）的卖家，2025年政策变更后发现月度仓储费和退货处理费大幅增加。原本免费仓储期缩短至30-45天，滞销商品每日产生25-50韩元/CBM的仓储费，加上退货费用改为卖家承担，月度额外成本达数十万元。

**问题分析**：
- 2025年起Rocket Growth免费仓储期按品类差异化缩短（30-45天）
- 退货处理费（回收+重新入库）改为卖家承担
- 库存周转慢的商品，仓储费会侵蚀甚至超过利润
- 部分卖家因不了解新政策，仍按旧习惯大量入仓，导致亏损

**解决方案**：
1. 计算真实成本结构，对比Seller Rocket vs Rocket Growth：
   - 以售价20,000韩元、月销100个的生活用品为例：
     - Seller Rocket总成本约415,000韩元（含自付快递）
     - Rocket Growth总成本约425,000韩元（含物流费+仓储费+退货费）
   - 高周转商品选Rocket Growth，低周转商品选Seller Rocket
2. 库存周转优化策略：
   - 季节性商品：季节开始前2-3周入仓，目标季节内售罄
   - 一般生活用品：按销售速度2-3周为单位小批量分批入仓
   - 时尚服装： bestseller与新品区分管理入仓周期
3. 降低退货率的具体措施：
   - 详情页添加360度实拍图、实测尺寸、实际使用照片
   - 建立FAQ板块，前置解答常见疑问
   - 售前咨询2小时内响应，避免消费者因信息不足而误购
4. 建立监控体系：
   - 每周SKU级库存天数追踪表
   - 每月退货原因分类分析
   - 成本看板：仓储费、退货费日/周/月度趋势

**关键要点**：
- 2025年后Rocket Growth不再是"无脑选"，必须按周转速度和利润率精算
- 退货率每降低1%，可直接转化为净利润提升
- 滞销品宁可及时降价清仓，也不要继续承担仓储费

### 【运营技巧】详情页SEO优化：从客户评价中提取高转化关键词
**适用场景**：商品有基础销量和积累的评价，但搜索排名和转化率停滞不前；或新上架商品不知如何编写商品名和详情页文案。

**具体操作**：
1. 收集数据源：
   - 本商品历史评价（至少最近50条）
   - 竞品爆款商品的评价区高频词
   - Coupang搜索栏自动补全关键词
2. 使用AI工具（如ChatGPT/Gemini）进行关键词提取：
   - 输入评价文本，要求提取"消费者最在意的3个产品特性"和"描述这些特性的自然语言表达"
   - 示例输出：化妆品类→"清爽不黏腻"、"吸收快"、"保湿持久"
3. 商品名编写公式（按优先级排序）：
   - 核心搜索词 + 品牌名 + 产品特性 + 规格/容量
   - 示例：【保湿面霜】ABC品牌 玻尿酸深层补水面霜 50ml
4. 详情页结构（从上到下）：
   - 顶部横幅：核心利益点+促销信息（3秒内抓住注意力）
   - 中部说明：主要功能、使用方法、Q&A形式问答
   - 底部信息：配送说明、退换政策、关联商品推荐
5. 移动端适配检查（Coupang 70%流量来自移动端）：
   - 文字最小12pt
   - 核心信息放在图片上半部分
   - 避免荧光色和过度渐变
   - 文件大小优化确保加载速度

**效果预期**：
- 点击率提升30-50%（优质主图+精准标题）
- 转化率从1.6%提升至2.1%（详情页信息结构优化后实测数据）
- 广告ROAS提升（因质量分提高，降低竞价成本）

**注意事项**：
- 商品描述必须与实际产品一致，避免因描述不符导致退货和评分下降
- 健康功能食品类禁止使用"治疗"、"疗效"等医疗用语，否则广告被拒且可能账号受限
- 定期（每月）根据新评价更新详情页内容
