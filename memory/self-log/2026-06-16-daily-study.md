## 【问题案例1】海外代购卖家遭遇"5万韩元以下无回收退款"政策损失

**场景描述**：一位从事海外代购（직구）的卖家发现，顾客以"单纯变心"为由申请退货时，5万韩元以下的商品无需回收即可直接退款，卖家不仅收不回商品，还要承担全部损失。该卖家称这是"结构性甲方霸凌"。

**问题分析**：
- 2022年12月起， Coupang 将"无回收退款"金额从10万韩元下调至5万韩元
- 海外代购卖家因在韩国没有退货地址或有效的快递公司合约代码，系统判定商品回收困难
- 即使顾客已开封或使用商品，平台也无验证程序直接退款
- 许多卖家在发生实际退货后才得知此政策，事前未获充分告知

**解决方案**：
1. 入驻前务必确认退货政策完整条款，特别是"无回收退款"适用范围
2. 如可能，在韩国设立退货地址并注册有效的快递公司合约代码
3. 对5万韩元以下商品，评估是否值得继续销售或提高客单价至5万韩元以上
4. 定价时需将此类退货损失计入成本（建议预留5-10%的退货损失率）
5. 考虑加入 Coupang 的"回收支援计划"，让平台负责回收跟踪

**关键要点**：
- ⚠️ 5万韩元是退货政策的关键分界点，定价策略需围绕此数字设计
- ⚠️ 海外代购卖家应优先考虑可追踪的物流方案，避免被归入"无回收"类别
- ⚠️ 顾客单方面申请退货时，卖家需在平台规定期限内提出异议（확인요청）

**原文链接**：https://magazine.hankyung.com/business/article/202603304609b

## 【问题案例2】自动广告月烧300万韩元，ROAS仅80%的惨痛教训

**场景描述**：一位卖家将月广告预算300万韩元全部投入 Coupang 自动广告（AI 스마트 광고），结果ROAS仅80%（即每投100万韩元广告费，只收回80万韩元销售额），持续亏损。

**问题分析**：
- Coupang AI 会自动添加与商品无关的关键词（例如卖"皮鞋"却匹配到"运动鞋"关键词）
- 自动广告无法直接设置排除关键词，导致大量无效点击消耗预算
- 缺乏对"转化率低于1%的关键词"和"ROAS低于100%的关键词"的定期清理
- 未区分品牌关键词和普通关键词的竞价策略

**解决方案**：
1. 自动广告仅用于初期数据收集（2周左右），随后转为手动广告进行精细化管理
2. 每日查看【关键词报告】，将高点击低转化的关键词加入排除列表
3. 品牌关键词用较低竞价单独运营，普通关键词按转化率调整竞价
4. 设置时间分配策略：晚6点~9点黄金时段投入150%预算，凌晨时段降至50%
5. 日预算至少3万韩元起，低于此金额AI广告无法正常运作

**关键要点**：
- 📊 自动广告的"扩展关键词"中平均有20-30%为无效匹配，需定期检查
- 📊 ROAS目标初期设为200-300%，数据积累后再逐步提升
- 📊 关键词排除设置仅在手动广告中可用，自动广告依赖AI筛选

## 【问题案例3】Rocket Growth入库后才发现物流费用吞噬全部利润

**场景描述**：一位新入驻 Rocket Growth（로켓그로스）的卖家，销售一款中型家居用品，入库30天后发现实际到账金额比预期少了近25%，仔细核对后发现物流费用被严重低估。

**问题分析**：
- 2025年1月起 Coupang 将入出库/配送费从3档细分为6档（极小型→特大型）
- 免费保管期从60天缩短至30天（服饰/鞋类/饰品为45天），超期后产生每日保管费
- 新增返品回收费、返品再入库费、返出费，每月仅20件免费额度
- 卖家未将服务费（月销100万韩元以上收取5.5万韩元/月）计入成本

**解决方案**：
1. 入库前使用 Coupang Wing 的物流费用模拟器，按商品实际尺寸和预估销量计算总成本
2. 建立库存周转监控表，确保商品在免费保管期内售出（目标周转天数<25天）
3. 将物流成本公式写入定价模型：售价 = (原价 + 分类销售佣金 + 入出库费 + 配送费 + 预估保管费 + 返品费) / (1 - 目标利润率)
4. 滞销品在90天内果断打折清仓或申请返出，避免长期保管费累积
5. 月销售稳定后申请周结算（주정산）或快速结算（빠른정산）以改善现金流

**关键要点**：
- 💰 Rocket Growth 实际总费用 = 销售佣金(4-10.8%) + 入出库/配送费 + 保管费 + 返品相关费用 + 服务费5.5万韩元 + 附加税10%
- 💰 中型以上商品的入出库费可达1250韩元以上，配送费2100韩元以上
- 💰 反品回收/再入库/返出每月各20件免费，超出后每件约300-600韩元

**原文链接**：https://www.sellerking.io/blog/쿠팡-셀러-필독-로켓그로스-비용-개편-35321

## 【问题案例4】商品详情页"关键词堆砌"导致搜索排名下降

**场景描述**：一位健康食品卖家将商品名从"有机糙米10kg 2024年产 国产"改为"高级优质健康美味有机糙米"后，搜索曝光量反而下降42%。

**问题分析**：
- Coupang 搜索算法优先"简洁和准确"，过度关键词堆砌（키워드 스터핑）会触发降权
- 主观形容词（高级、优质、美味）对消费者搜索无帮助，反而稀释核心关键词权重
- 商品名超过100字（含空格）会被截断，移动端显示更短
- 重复使用相同关键词会造成"自我竞争"，推高竞价成本

**解决方案**：
1. 采用「品牌名 + 核心关键词 + 商品特征 + 容量/数量」的命名公式
2. 商品名控制在100字以内，核心关键词放在前部
3. 用客观信息替代主观形容词：将"高级美味"改为具体产地、年份、认证标志
4. 利用 Coupang 的"正常价"功能设置划线原价，制造折扣感
5. 标签设置20个满额，覆盖长尾关键词（如"大容量"、"性价比"、"免费配送"）

**关键要点**：
- 🔍 商品名中同一关键词最多出现2次，超过则可能被判定为违规
- 🔍 搜索量高的关键词可通过 Naver 关键词工具 + Coupang 自动补全功能挖掘
- 🔍 详情页修改频率控制在每周1次以内，过于频繁会导致曝光不稳定

**原文链接**：https://oscsnm.com/coupang-detail-page-strategy/

## 【问题案例5】因快递公司延误导致卖家评分归零及恢复过程

**场景描述**：一位卖家一直保持100分满分卖家评分，某天发现配送评分突然变为0分。核查后发现仅有一个订单因快递公司（非卖家）原因延迟1天送达，却扣除了全部配送分。

**问题分析**：
- Coupang 卖家评分系统以"预计送达日"为基准，快递公司延误也计入卖家责任
- 仅1个延迟案例就可能导致该类目评分断崖式下跌
- 评分下降直接影响商品搜索排名和曝光量
- 许多卖家不知道可以通过"卖家评分排除请求"（판매자점수 제외 요청）恢复分数

**解决方案**：
1. 发现异常后立即登录 Coupang Wing → 核查具体延迟订单的配送追踪记录
2. 确认是快递公司原因后，通过以下链接提交排除请求：https://helpseller.coupang.com/hc/ko/requests/new?ticket_form_id=360000545712
3. 提交材料：订单号（오더넘버）、箱ID（묶음배송번호）、发货时间截图
4. 选择分类"판매자점수 제외 - 정시배송완료"进行申请
5. 同步联系快递公司获取延误证明，作为辅助材料

**关键要点**：
- ⏱️ 卖家评分是搜索排名的核心因素之一，必须每日监控
- ⏱️ 建议在预计送达日前1天主动发货，预留快递公司延误缓冲期
- ⏱️ 保留所有发货凭证至少6个月，以备争议时使用

**原文链接**：https://nomadel.tistory.com/entry/쿠팡-정시발송했는데-판매자-점수가-갑자기-0이-되었다-다시-되살리는-법

## 【问题案例6】顾客以"商品描述不符"申请卖家责任退货，首次处理手足无措

**场景描述**：一位新手副业卖家销售的触控防寒手套，顾客以"实际商品与描述不符"（女性M/L、男性XL的尺码标注不清导致选错）申请退货，且被判定为"卖家责任"，需承担退货运费。

**问题分析**：
- 新手卖家对"单纯变心"和"卖家责任"的区别不清晰
- 尺码表、颜色、规格等描述不清是引发卖家责任退货的首要原因
- 卖家责任退货不仅损失运费（约6000韩元），还影响卖家评分
- 首次遇到时不知如何处理，情绪消耗大

**解决方案**：
1. 收到退货通知后，先与顾客沟通确认真实原因，判断是否为描述问题
2. 如确实是描述不清导致，爽快接受退货并承担运费（维护长期口碑）
3. 同步修改商品页面：补充详细尺码表、增加模特试穿图、添加FAQ说明
4. 处理流程：Coupang确认退货商品 → 向供应商申请退货 → 在Coupang登记退货运单号 → 供应商入库验收 → 完成退货
5. 切勿点击"退货完成"按钮，除非确认已收到商品并验收完毕

**关键要点**：
- 📦 卖家责任退货的运费（约6000韩元）由卖家承担，单纯变心则由买家承担
- 📦 退货入库时务必拍摄开箱验货视频/照片，证明商品状态
- 📦 商品描述中增加"尺码对照表"和"试穿指南"可将服饰类退货率降低15-20%

## 【运营技巧】商品首次上架的"临时图片法"

**适用场景**：新商品注册 Coupang 时，担心因图片相似被系统错误归类或与其他商品"捆绑"

**具体操作**：
1. 首次注册时，主图使用临时图片（如简单截图或带水印的预览图）
2. 提交后等待系统审核通过，确认商品未被错误归类
3. 审核通过后，再将主图替换为正式商品图
4. 此方法可避免 Coupang 的"相似商品自动捆绑"逻辑将新品与错误商品关联

**效果预期**：
- 减少因图片相似导致的商品归类错误（可减少80%的初期修改时间）
- 避免与低价竞品捆绑后被系统推荐到错误的价格区间

**注意事项**：
- 临时图片也需符合基本规范（无营销文字、白底或透明底）
- 替换正式图后观察24-48小时，确认搜索曝光正常

**原文链接**：https://www.gabiacns.com/cms/library/XrwOAm

## 【运营技巧】Coupang 商品定价的" coupon 预留法"

**适用场景**：计划长期使用优惠券、参与平台促销活动的商品

**具体操作**：
1. 确定实际目标售价（例如18,700韩元）
2. 注册价设为21,700韩元（预留约15-20%的促销空间）
3. 设置"正常价"为21,700韩元，实际销售价18,700韩元（显示为14%折扣）
4. 预留的空间用于：
   - 发放卖家优惠券
   - 参与 Coupang 官方活动（골드박스、딜等）
   - 应对竞品价格战

**效果预期**：
- 消费者"不买原价"的心理被满足，转化率提升10-15%
- 促销期间无需临时改价，避免搜索排名波动

**注意事项**：
- 预留空间不宜过大（超过30%会显得原价虚高）
- 参与 Coupang 活动时，部分折扣由平台分摊，需提前计算实际到手价

## 【今日总结】

### 核心洞察
1. **返品政策是利润杀手**：5万韩元以下商品的"无回收退款"政策、卖家责任退货运费、Rocket Growth返品处理费，这三项可将利润率吃掉10-15%。定价时必须将返品损失率纳入计算。

2. **广告不是投了就有回报**：Coupang自动广告的AI关键词匹配有大量噪音，必须定期（每2周一次）审查关键词报告，将无效关键词转为手动排除。ROAS低于100%的关键词应立即停用。

3. **卖家评分是生命线**：仅1个快递延误就可能导致评分归零，且系统默认将快递问题算在卖家头上。建立每日评分监控习惯，发现问题当天立即提交排除请求。

### 实操建议（明天可立即应用）
- [ ] 检查自己店铺中5万韩元以下商品的占比，评估是否需要调整价格策略
- [ ] 登录Coupang广告后台，导出过去14天的关键词报告，找出点击>10次但转化=0的关键词加入排除列表
- [ ] 检查Rocket Growth库存中入库超过20天的商品，对滞销品制定打折清仓计划
- [ ] 确认所有商品的尺码/规格描述是否清晰，补充试穿图或实物对比图
- [ ] 截图保存今日卖家评分页面，建立每日评分追踪记录
