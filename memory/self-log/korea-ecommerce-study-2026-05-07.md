## 二、主体准入与注册

### 外资电商准入路径（2025年）
1. **设立韩国法人实体**
   - 株式会社（주식회사）：最少2人注册，需监事，可发行证券
   - 每三年法人代表和监事需续任公证
   - 需向地方法院商业登记处注册，取得法人登记编号

2. **商业登记**
   - 向韩国国税厅（NTS）取得**事业者登记证**
   - 外国个人无签证不能在韩国注册为个体户

3. **平台入驻**
   - Coupang Global Seller Program 支持无本地实体入驻（但有限制）
   - 多数平台需韩国法人身份才能完整运营

### 关键限制
- **支付隔离**：外资电商需接入本地支付网关（KCP、Naver Pay），禁止直接处理韩元结算
- **信息保护官（DPO）**：处理超100万用户数据需设专职DPO，需通过KISA认证
- 2026年7月新规：年销售额达1万亿韩元或月均韩国用户超100万的海外平台，必须在韩国指定本地代理人

## 三、税务条款

### 增值税（VAT）
| 项目 | 内容 |
|------|------|
| 税率 | **10%**（标准税率） |
| 起征点 | 年销售额 > 4.8亿韩元（约260万人民币）需登记 |
| 申报周期 | 季度申报（每季度结束后25天内） |
| 申报系统 | Hometax（国税厅电子税务系统） |

**跨境电商特别规定：**
- **B2C**：外国卖家在韩国产生第一笔B2C销售即需注册VAT，平台可能代扣
- **B2B**：韩国买方企业按"反向征收"自行申报
- 出口退税：通过KITA申请0% VAT，需海关出口证明+提单

### 关税
| 项目 | 内容 |
|------|------|
| 起征点 | 150美元（约20万韩元）以下免征 |
| 平均税率 | 约8% |
| 高关税品类 | 农产品（大米、牛肉）、部分纺织品、汽车 |
| 低/零关税 | 电子产品、机械设备、FTA协定国商品 |

**关税计算基数**：CIF价 = 商品价格 + 国际运费 + 保险费

### 法人税（企业所得税）
| 利润区间 | 税率 |
|----------|------|
| 不足2亿韩元 | 9%（国税）+ 0.9%（地方税）= **9.9%** |
| 2亿~200亿韩元 | 19% + 1.9% |
| 200亿~3000亿韩元 | 21% + 2.1% |
| 超过3000亿韩元 | 24.2% + 2.42% |

**申报要求**：
- 每季度按上年利润预缴
- 财年结束后3个月内完成全年汇算

### 平台代扣税
- 跨境商品销售平台代扣税：**3.5%**
- **规避策略**：本土仓发货（如仁川保税仓）可免此税

### 资金出境
- 年利润汇出超**50万美元**需央行预审（周期30天）
- 技术服务费名义支付税率12% vs 股息税25%

## 四、产品准入与认证

### KC认证（强制安全认证）
| 品类 | 认证标志 | 监管机构 | 核心要求 |
|------|----------|----------|----------|
| 电子电器 | KC | KATS | 韩语说明书+安全测试 |
| 化妆品 | KFDA | MFDS | 全成分韩语标注+禁止动物测试 |
| 食品 | HACCP | MFDS | 营养表（每100g）+原产地 |
| 通用 | - | KFTC | 韩语标签+最低销售单位价格 |

**标签规范**：
- KC标志尺寸 ≥ 10mm
- 化妆品需标注开封后使用期（罐装图标+月数）
- 电器需印韩国代理商信息

**违规成本案例**：
- 未备案面膜：销毁+诉讼
- 充电宝召回：罚款8亿韩元
- 未标价：罚销售额3%

## 五、法律法规体系

### 核心法律框架
| 法律 | 主要内容 |
|------|----------|
| **《电子信息和电子商务框架法》** | 电子交易安全、用户保护、政策制定系统、仲裁委员会 |
| **《电子商务法》** | 电子信息、数字签名、域名、网络霸占、电子金融交易 |
| **《电子签名法》** | 电子签名基本规则，确保电子信息安全可靠 |
| **《电子商务消费者保护法》** | 用户权利保护、检查监督、纠正和惩罚 |
| **《个人信息保护法》（PIPA 2025）** | 全球最严数据法之一 |

### 2025-2026年重要新规
1. **KFTC处罚加码（2026年3月草案，预计7月21日生效）**
   - 违规统计周期从3年延长至5年
   - 附加金上调比例从50%提高至100%
   - 主动纠正减免上限从30%降至10%
   - 大型海外平台（年销售额1万亿韩元/月均用户100万）须在韩国指定代理人

2. **价格行为监管**
   - 最低价标注：需展示30天内最低价+计算依据，违者罚销售额3%
   - 虚假促销：折扣需基于"最近最低价"而非划线价，罚1亿韩元/次
   - 禁用"第一/最佳"等绝对化用语，罚2000万韩元/次

3. **广告合规**
   - 网红营销必须标注"광고"（广告）字样
   - 自动续费需二次确认+简易退订，违者罚5000万韩元

## 六、数据合规（PIPA 2025升级版）

### 关键要求
- **云存储**：推荐使用Naver Cloud或AWS首尔区域
- **用户删除请求**：14天内响应，需短信确认
- **数据导出**：需提供XML格式
- **同意管理**：收集、使用、提供个人信息均需取得主体同意

### 违规后果
- 信息泄露：刑事责任+行政处罚
- 罚款上限极高（按全球营业额比例计算）

## 十、实操建议

### 新手入局路径
1. 优先通过 Coupang Global Seller Program 测试市场
2. 核心品类选择：消费电子、美妆、家居（韩国消费者偏好）
3. 必须完成KC认证才能上架相关品类
4. 使用Naver Datalab / Naver Ads / Itemscout进行关键词研究
5. 初期可借助本土第三方仓配降低物流门槛

### 合规检查清单
- [ ] 韩国法人注册或平台Global Seller资质
- [ ] 事业者登记（税务识别号）
- [ ] 产品KC/MFDS认证（如适用）
- [ ] 韩语标签/说明书合规
- [ ] VAT季度申报准备
- [ ] 个人信息保护官（DPO）任命（如用户>100万）
- [ ] 价格历史追踪系统（防虚假促销）
- [ ] 退货政策韩英双语配置
