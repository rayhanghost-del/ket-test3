# 韩国电商学习笔记 - 2026-04-23

## 一、韩国电商运营知识

### 1. 主要电商平台
- **Coupang（酷澎）**：韩国最大电商平台，被称为"韩国亚马逊"
  - 入驻审核通常需要7个工作日
  - 需提交：公司营业执照（申请时间>1个月）、身份证明、银行账户证明、联系方式证明、其他跨境平台结算凭证
  - 审核通过后开通WING卖家后台管理系统

### 2. 运营基础
- 选品、上架、推广、履约、售后的完整链路
- 视觉设计：商品主图、店招图、广告图标准
- 营销方式：店铺自主营销、平台活动、联盟营销
- 物流：国际运输方式、海外仓设置
- 客户服务：询盘分析、回复技巧、纠纷处理

### 3. 韩国市场特点
- 2024年韩国CPI同比上涨，消费市场活跃
- 数字经济发展迅速，政府鼓励外商投资数字经济
- 绿色经济政策支持：碳中和、新能源等

## 二、韩国电商法律法规

### 1. 核心法律框架
| 法律名称 | 主要内容 |
|---------|---------|
| 《电子信息和电子商务框架法》 | 促进电子交易安全，保护用户，建立仲裁机制 |
| 《电子商务法》 | 涵盖电子签名、域名、网络霸占、电子金融交易等 |
| 《电子签名法》 | 确立电子签名基本规则，确保电子信息安全可靠 |
| **《电子商务消费者保护法》** | 保护消费者权益，规定检查监督、纠正和惩罚措施 |
| 《个人信息保护法》(PIPA) | 规范个人信息收集、使用、存储、销毁 |

### 2. 平台运营商责任
- 韩国无专门定义平台中介责任的法律
- 商标法未规定间接侵权责任
- 平台运营商并非自动对销售侵权产品负责（除非积极参与侵权活动）

### 3. 消费者保护要求
- 企业需采取必要措施维护消费者信息安全
- 电子支付时需通知消费者
- 对第三方不当使用消费者信息导致的损害进行赔偿
- 个人信息收集需获得同意
- 发现信息泄露需及时通知受影响者

## 三、韩国电商税务条款

### 1. 主要税种
| 税种 | 税率/说明 |
|------|----------|
| **增值税(VAT)** | 标准税率**10%** |
| 关税 | 根据商品类别和价值不同 |
| 消费税 | 特定商品（酒精、烟草、奢侈品等） |
| 法人税 | 根据应纳税所得额分级 |
| 财产税 | 土地、建筑、住宅等 |

### 2. 增值税核心规则
- 适用于大部分商品和服务销售、进口及劳务
- **出口实行零税率**：出口企业无需缴纳，可申请退还国内采购环节已缴增值税
- 跨境电商平台可能需代扣代缴

### 3. 跨境电商特殊政策
- 2025年1月1日起：外国企业通过电商平台销售需缴纳16%增值税（部分平台）
- 中小型企业可能享受税收减免
- 仓储、物流等环节有税收优惠政策

### 4. 合规要点
- 需在海关监管代码下申报（1210、9610、9710、9810等）
- 退运商品可享税收优惠政策（延至2025年12月31日）
- 建立完善的财务制度，确保数据准确性
- 加强与税务部门沟通，了解最新政策
